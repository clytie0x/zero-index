# บทที่ 0 เริ่มต้น

บทนี้ยังไม่ได้สอนเขียนโปรแกรมจริงจัง เป้าหมายคือทำให้เครื่องของน้องพร้อม และเข้าใจว่าโค้ดที่เราพิมพ์กลายเป็นโปรแกรมที่รันได้ยังไง

## ในบทนี้

| หน้า | ได้อะไร |
|---|---|
| [0.1 คอมพิวเตอร์อ่านโค้ดเรายังไง](why.md) | รู้ว่า compiler กับ interpreter ต่างกันยังไง และทำไมค่ายนี้ใช้ภาษา C |
| [0.2 ติดตั้ง Code::Blocks](install.md) | มีโปรแกรมพร้อมเขียนโค้ดในเครื่อง |
| [0.3 โปรแกรมแรก Hello World](hello.md) | เขียน รัน และอ่าน error ครั้งแรก |

## ผ่านบทนี้เมื่อ { #checklist }

- [ ] เปิด Code::Blocks สร้างไฟล์ `.c` และบันทึกในโฟลเดอร์ที่ถูกต้องได้
- [ ] รัน Hello World แล้วเห็นข้อความบนหน้าจอ
- [ ] เปลี่ยนข้อความเป็นชื่อตัวเองแล้วรันใหม่ได้
- [ ] ลบ `;` ทิ้ง แล้วบอกได้ว่า error ชี้ไปที่บรรทัดไหน
