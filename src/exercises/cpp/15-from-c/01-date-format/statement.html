ใบสมัครค่ายให้น้องกรอกวันเกิดแบบ วัน/เดือน/ปี เช่น 05/03/2010 แต่ระบบของค่ายเรียงข้อมูลตามวันที่ได้ก็ต่อเมื่อเขียนแบบ ปี-เดือน-วัน คือ 2010-03-05 ให้แปลงวันเกิดทุกรายการให้เป็นรูปแบบใหม่ โดยเลข 0 ที่อยู่ข้างหน้าต้องอยู่ครบเหมือนเดิม

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 1000)

อีก N บรรทัด บรรทัดละหนึ่งวันที่ในรูปแบบ DD/MM/YYYY ยาว 10 ตัวพอดี วันและเดือนเป็นเลขสองหลักเสมอ ปีเป็นเลขสี่หลักเสมอ ทุกวันที่เป็นวันที่ที่มีอยู่จริง

ข้อมูลออก

N บรรทัด บรรทัดที่ i คือวันที่ของบรรทัดที่ i ในรูปแบบ YYYY-MM-DD
