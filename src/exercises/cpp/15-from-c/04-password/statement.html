เว็บส่งงานของโรงเรียนให้นักเรียนตั้งรหัสผ่านใหม่ รหัสผ่านต้องผ่านกฎสี่ข้อนี้ ระบบจะตรวจตามลำดับ และบอกเฉพาะข้อแรกที่ไม่ผ่าน

  1. ยาวอย่างน้อย 8 ตัว ถ้าไม่ผ่านให้ตอบ TOO SHORT
  2. มีตัวพิมพ์ใหญ่ A ถึง Z อย่างน้อยหนึ่งตัว ถ้าไม่ผ่านให้ตอบ NO UPPERCASE
  3. มีตัวพิมพ์เล็ก a ถึง z อย่างน้อยหนึ่งตัว ถ้าไม่ผ่านให้ตอบ NO LOWERCASE
  4. มีตัวเลข 0 ถึง 9 อย่างน้อยหนึ่งตัว ถ้าไม่ผ่านให้ตอบ NO DIGIT

ถ้าผ่านครบทั้งสี่ข้อให้ตอบ OK ให้ตรวจรหัสผ่านที่นักเรียนส่งมาทั้งหมด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 1000)

อีก N บรรทัด บรรทัดละหนึ่งรหัสผ่าน ยาว 1 ถึง 50 ตัว ประกอบด้วยตัวอักษรภาษาอังกฤษ ตัวเลข และเครื่องหมาย เช่น ! @ # $ % _ - . ไม่มีช่องว่าง

ข้อมูลออก

N บรรทัด บรรทัดที่ i คือผลการตรวจรหัสผ่านที่ i
