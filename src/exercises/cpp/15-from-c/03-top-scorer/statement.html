หลังสอบย่อยวิชาคอมพิวเตอร์ ครูประจำวิชามีรายชื่อนักเรียน N คนพร้อมคะแนน ครูอยากรู้สองอย่าง คือคะแนนเฉลี่ยของห้อง และชื่อของคนที่ได้คะแนนสูงสุด ถ้ามีหลายคนได้คะแนนสูงสุดเท่ากัน ให้ตอบคนที่อยู่ก่อนในรายชื่อ

ข้อนี้คล้ายข้อใครได้รางวัลในบทที่ 11 และตั้งใจให้ฝึกย้ายโค้ดภาษา C มาเป็น C++ ให้เก็บชื่อด้วย string อ่านเขียนด้วย cin cout แทน char อาเรย์ strcpy และ printf

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 1000)

อีก N บรรทัด บรรทัดละหนึ่งคน มีชื่อและคะแนนคั่นด้วยช่องว่าง ชื่อเป็นตัวอักษรภาษาอังกฤษ ยาว 1 ถึง 20 ตัว ไม่มีช่องว่าง คะแนนเป็นจำนวนเต็มตั้งแต่ 0 ถึง 100

ข้อมูลออก
