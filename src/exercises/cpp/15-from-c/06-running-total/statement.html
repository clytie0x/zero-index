ร้านค้าสหกรณ์ของโรงเรียนจดยอดเงินเข้าออกทุกรายการตลอดปีการศึกษา รายการที่ i เป็นจำนวนเต็ม ai บาท ถ้าเป็นบวกคือเงินเข้า ถ้าเป็นลบคือเงินออก ฝ่ายบัญชีอยากเห็นยอดเงินสะสมหลังแต่ละรายการ คือหลังรายการที่ k ยอดสะสมเท่ากับ a1 + a2 + ... + ak และอยากรู้ด้วยว่าจนถึงรายการนั้น ยอดสะสมเคยต่ำที่สุดเท่าไร เพื่อดูว่าร้านเคยติดลบหนักแค่ไหน

ข้อนี้ข้อมูลเข้ามีได้ถึงหนึ่งล้านรายการ และต้องพิมพ์ออกหนึ่งล้านบรรทัด ภายในเวลา 1 วินาที

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 1000000)

บรรทัดที่สองมีจำนวนเต็ม a1 a2 ... aN คั่นด้วยช่องว่าง (-1000000000 ≤ ai ≤ 1000000000)

ข้อมูลออก

N บรรทัด บรรทัดที่ k มีจำนวนเต็มสองตัวคั่นด้วยช่องว่าง ตัวแรกคือยอดเงินสะสมหลังรายการที่ k ตัวที่สองคือยอดสะสมที่ต่ำที่สุดในบรรดายอดสะสมหลังรายการที่ 1 ถึงรายการที่ k
