ค่ายจะพิมพ์ป้ายชื่อให้นักเรียนทุกคน แต่ตอนกรอกใบสมัคร แต่ละคนพิมพ์ชื่อมาไม่เหมือนกัน บางคนพิมพ์ตัวพิมพ์ใหญ่ทั้งหมด บางคนพิมพ์ตัวพิมพ์เล็กทั้งหมด บางคนกดสลับไปมา ป้ายชื่อต้องเป็นรูปแบบเดียวกันทุกใบ คือชื่อที่ขึ้นต้นด้วยตัวพิมพ์ใหญ่และที่เหลือเป็นตัวพิมพ์เล็ก ตามด้วยช่องว่างหนึ่งช่อง ตามด้วยอักษรตัวแรกของนามสกุลเป็นตัวพิมพ์ใหญ่และจุด เช่น sOMCHAI jaidee ต้องเป็น Somchai J.

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 1000)

อีก N บรรทัด บรรทัดละหนึ่งคน มีชื่อและนามสกุลคั่นด้วยช่องว่าง ทั้งสองเป็นตัวอักษรภาษาอังกฤษล้วน ตัวพิมพ์ใหญ่หรือเล็กก็ได้ ยาวคำละ 1 ถึง 20 ตัว

ข้อมูลออก

N บรรทัด บรรทัดที่ i คือป้ายชื่อของคนที่ i
