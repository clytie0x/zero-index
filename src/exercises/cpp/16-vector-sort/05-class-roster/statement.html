โรงเรียนเปิดรับสมัครค่ายวิทยาศาสตร์ นักเรียน N คนกรอกใบสมัครเรียงตามเวลาที่ส่ง แต่ละใบมีชื่อเล่น เลขห้อง และคะแนนสอบคัดเลือก ครูต้องการพิมพ์รายชื่อเพื่อติดหน้าห้องตามกติกานี้

  • เรียงตามเลขห้องจากน้อยไปมาก
  • ในห้องเดียวกัน คะแนนมากกว่าอยู่ก่อน
  • ถ้าห้องเดียวกันและคะแนนเท่ากัน คนที่ส่งใบสมัครก่อนอยู่ก่อน

ชื่อเล่นซ้ำกันได้ เพราะนักเรียนต่างห้องอาจชื่อเดียวกัน หรือแม้แต่ในห้องเดียวกันก็มีได้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 100000)

อีก N บรรทัด เรียงตามเวลาที่ส่งใบสมัคร บรรทัดละหนึ่งคน มีชื่อเล่น เลขห้อง และคะแนน คั่นด้วยช่องว่าง ชื่อเล่นเป็นตัวพิมพ์เล็กภาษาอังกฤษยาว 1 ถึง 10 ตัว เลขห้องเป็นจำนวนเต็มตั้งแต่ 1 ถึง 20 คะแนนเป็นจำนวนเต็มตั้งแต่ 0 ถึง 100

ข้อมูลออก

N บรรทัดตามลำดับในรายชื่อ บรรทัดละหนึ่งคน มีเลขห้อง ชื่อเล่น และคะแนน คั่นด้วยช่องว่างหนึ่งช่อง
