ถนนสายหนึ่งในหมู่บ้านเป็นเส้นตรงยาว มีบ้าน N หลังตั้งอยู่ริมถนน บ้านหลังที่ i อยู่ที่ตำแหน่ง xi เมตร นับจากหลักกิโลเมตรศูนย์ ค่าติดลบคืออยู่ก่อนถึงหลัก บ้านหลายหลังอาจอยู่ตำแหน่งเดียวกันได้ เช่น ห้องแถวที่อยู่ในตึกเดียวกัน

อาสาสมัครสาธารณสุขเดินสำรวจริมถนนแล้วพบแหล่งน้ำขังที่มีลูกน้ำยุงลาย Q จุด จุดที่ j อยู่ที่ตำแหน่ง pj ทุกจุดที่พบ อาสาสมัครจะไปแจ้งบ้านที่อยู่ใกล้จุดนั้นที่สุดให้ช่วยเทน้ำทิ้ง ระยะระหว่างตำแหน่ง a กับ b คือ |a - b| ถ้ามีบ้านสองตำแหน่งที่ห่างเท่ากัน ให้ไปแจ้งบ้านที่ตำแหน่งน้อยกว่า ให้หาว่าแต่ละจุดต้องไปแจ้งบ้านที่ตำแหน่งไหน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง (1 ≤ N, Q ≤ 200000)

บรรทัดที่สองมีตำแหน่งของบ้าน N หลัง คั่นด้วยช่องว่าง แต่ละตำแหน่งเป็นจำนวนเต็มตั้งแต่ -109 ถึง 109 ไม่ได้เรียงมา

บรรทัดที่สามมีตำแหน่ง p1 ถึง pQ ของจุดที่พบลูกน้ำ คั่นด้วยช่องว่าง แต่ละตำแหน่งเป็นจำนวนเต็มตั้งแต่ -109 ถึง 109

ข้อมูลออก

Q บรรทัด บรรทัดที่ j คือตำแหน่งของบ้านที่ต้องไปแจ้งสำหรับจุดที่ j
