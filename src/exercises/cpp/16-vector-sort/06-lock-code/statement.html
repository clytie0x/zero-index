น้องลืมรหัสกุญแจตู้เก็บของ จำได้แค่ว่ารหัสใช้ตัวเลขชุดหนึ่ง ใช้ครบทุกตัวตัวละหนึ่งครั้ง แต่จำลำดับไม่ได้ และจำได้อีกอย่างว่ารหัสนั้นเป็นจำนวนที่หารด้วย K ลงตัว ตัวเลขในชุดอาจซ้ำกันได้ เช่น ชุด 1 1 2 สร้างรหัสที่ต่างกันได้แค่ 112 121 และ 211

รหัสที่มีหลายหลักขึ้นต้นด้วย 0 ไม่ได้ ถ้าชุดมีตัวเลขตัวเดียว รหัส 0 ใช้ได้

ให้หาว่ามีรหัสที่เป็นไปได้กี่แบบ และรหัสที่น้อยที่สุดคืออะไร

ข้อมูลเข้า

บรรทัดเดียว มีสตริง S ซึ่งเป็นตัวเลขในชุด เขียนติดกัน ยาว 1 ถึง 8 ตัว และจำนวนเต็ม K (1 ≤ K ≤ 106) คั่นด้วยช่องว่าง

ข้อมูลออก

บรรทัดแรกพิมพ์จำนวนรหัสที่ต่างกันทั้งหมดที่ใช้ตัวเลขครบชุดและหารด้วย K ลงตัว

บรรทัดที่สองพิมพ์รหัสที่น้อยที่สุดในบรรดารหัสเหล่านั้น ถ้าไม่มีเลยให้พิมพ์ -1
