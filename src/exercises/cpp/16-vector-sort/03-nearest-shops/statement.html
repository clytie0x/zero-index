แอปสั่งอาหารมีร้านในระบบ N ร้าน ร้านที่ i อยู่ห่างจากบ้านของน้อง di เมตร หน้าแรกของแอปจะแสดงร้านที่ใกล้ที่สุด K ร้าน เรียงจากใกล้ไปไกล ถ้าสองร้านอยู่ห่างเท่ากัน ร้านที่มีหมายเลขน้อยกว่าขึ้นก่อน ให้หาว่าหน้าแรกแสดงร้านหมายเลขอะไรบ้าง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง (1 ≤ K ≤ N ≤ 100000)

บรรทัดที่สองมีระยะทาง d1 ถึง dN ของร้านหมายเลข 1 ถึง N คั่นด้วยช่องว่าง แต่ละค่าเป็นจำนวนเต็มตั้งแต่ 0 ถึง 109

ข้อมูลออก

บรรทัดเดียว หมายเลขร้าน K ร้านตามลำดับที่แสดง คั่นด้วยช่องว่างหนึ่งช่อง
