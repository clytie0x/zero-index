แอปแต่งรูปเก็บรูปขาวดำเป็นตารางตัวเลข R แถว C คอลัมน์ แต่ละช่องคือความสว่างของจุดหนึ่งจุด ตั้งแต่ 0 (ดำ) ถึง 255 (ขาว) ให้หมุนรูปไปทางขวา 90 องศาตามเข็มนาฬิกา แถวบนสุดของรูปเดิมจะกลายเป็นคอลัมน์ขวาสุดของรูปใหม่ รูปใหม่จึงมี C แถว R คอลัมน์

ขนาดของรูปรู้ตอนรันเท่านั้น และรูปอาจผอมยาวมาก เช่น 1 แถว 200000 คอลัมน์ หรือ 200000 แถว 1 คอลัมน์

ข้อนี้ตั้งใจให้ฝึกย้ายวิธีจากข้อหมุนรูปภาพในบทที่ 7 มาเขียนด้วย C++ วิธีหมุนเหมือนเดิม ที่ต่างคือขนาดของรูป ซึ่งอาเรย์สองมิติขนาดตายตัวรับไม่ไหว ต้องใช้ vector ที่สร้างตามขนาดจริง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C คั่นด้วยช่องว่าง (1 ≤ R, C และ R × C ≤ 200000)

อีก R บรรทัด บรรทัดละ C จำนวน คือความสว่างของแต่ละแถวจากบนลงล่าง แต่ละจำนวนเป็นจำนวนเต็มตั้งแต่ 0 ถึง 255

ข้อมูลออก

รูปที่หมุนแล้ว C บรรทัด บรรทัดละ R จำนวน คั่นด้วยช่องว่างหนึ่งช่อง
