ถนนสายหนึ่งเป็นเส้นตรงยาว มีบ้าน N หลังตั้งอยู่ริมถนน บ้านหลังที่ i อยู่ที่ตำแหน่ง xi เมตร นับจากหลักกิโลเมตรศูนย์ ค่าติดลบคืออยู่ก่อนถึงหลัก บ้านหลายหลังอาจอยู่ตำแหน่งเดียวกันได้ เช่น ห้องแถวที่อยู่ในตึกเดียวกัน

การไฟฟ้าวางแผนซ่อมสายไฟ Q ครั้ง ครั้งที่ j จะดับไฟช่วงตำแหน่ง Lj ถึง Rj รวมทั้งสองปลาย ให้หาว่าแต่ละครั้งมีบ้านไฟดับกี่หลัง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง (1 ≤ N, Q ≤ 200000)

บรรทัดที่สองมีตำแหน่งของบ้าน N หลัง คั่นด้วยช่องว่าง แต่ละตำแหน่งเป็นจำนวนเต็มตั้งแต่ -109 ถึง 109

อีก Q บรรทัด บรรทัดละหนึ่งครั้ง มีจำนวนเต็ม L และ R คั่นด้วยช่องว่าง (-109 ≤ L ≤ R ≤ 109)

ข้อมูลออก

Q บรรทัด บรรทัดที่ j คือจำนวนบ้านที่ไฟดับในการซ่อมครั้งที่ j
