ช่องขายตั๋วคอนเสิร์ตเปิดขายพร้อมตั๋ว S ใบ แฟนเพลงต่อแถวเดียว แต่ละคนบอกตอนเข้าแถวว่าอยากซื้อกี่ใบ พอถึงคิว ถ้าตั๋วเหลือพอเขาจะได้ครบตามที่ขอ ถ้าเหลือไม่พอเขาจะได้เท่าที่เหลือ ซึ่งอาจเป็น 0 ใบก็ได้ แล้วออกจากแถวไป ให้จำลองช่องขายตั๋วตามคำสั่ง Q คำสั่ง แต่ละคำสั่งเป็นแบบใดแบบหนึ่งต่อไปนี้ ตอนเริ่มไม่มีใครในแถว

  • JOIN name t คนชื่อ name มาต่อท้ายแถว อยากซื้อ t ใบ
  • SELL คนหัวแถวซื้อตั๋วแล้วออกจากแถว ให้พิมพ์ชื่อของเขา ช่องว่างหนึ่งช่อง และจำนวนตั๋วที่เขาได้ ถ้าไม่มีใครในแถวให้พิมพ์ EMPTY
  • LAST พิมพ์ชื่อของคนท้ายแถว ถ้าไม่มีใครในแถวให้พิมพ์ EMPTY
  • COUNT พิมพ์จำนวนคนที่ยังอยู่ในแถว ช่องว่างหนึ่งช่อง และจำนวนตั๋วที่ยังเหลือ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม S และ Q คั่นด้วยช่องว่าง โดยที่ 0 ≤ S ≤ 1015 และ 1 ≤ Q ≤ 100000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน ชื่อ name ยาว 1 ถึง 15 ตัวอักษรภาษาอังกฤษ ไม่มีช่องว่าง และอาจซ้ำกันได้ จำนวนตั๋วที่ขอ t เป็นจำนวนเต็ม 1 ≤ t ≤ 1000000000

ข้อมูลออก

สำหรับคำสั่ง SELL LAST และ COUNT แต่ละคำสั่ง ให้พิมพ์คำตอบหนึ่งบรรทัดตามลำดับของคำสั่ง
