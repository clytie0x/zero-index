ร้านเบเกอรี่มีชั้นวางขนมปังยาวหนึ่งชั้น ขนมปังทุกชิ้นมีหมายเลขรอบอบติดไว้ ชั้นเรียงจากชิ้นที่อบนานที่สุดทางซ้าย ไปจนถึงชิ้นที่อบล่าสุดทางขวา ให้จำลองชั้นวางตามคำสั่ง Q คำสั่ง แต่ละคำสั่งเป็นแบบใดแบบหนึ่งต่อไปนี้ ตอนเริ่มชั้นว่าง

  • BAKE x ขนมปังหมายเลข x เพิ่งอบเสร็จ วางไว้ขวาสุดของชั้น
  • FOUND x พนักงานเจอขนมปังหมายเลข x ตกค้างอยู่หลังร้าน มันเก่ากว่าทุกชิ้นบนชั้น จึงวางไว้ซ้ายสุดของชั้น
  • FRESH ลูกค้าหยิบชิ้นที่ใหม่ที่สุด คือชิ้นขวาสุด ให้พิมพ์หมายเลขของมัน ถ้าชั้นว่างให้พิมพ์ EMPTY
  • SALE ร้านขายลดราคาชิ้นที่เก่าที่สุด คือชิ้นซ้ายสุด ให้พิมพ์หมายเลขของมัน ถ้าชั้นว่างให้พิมพ์ EMPTY
  • CHECK i ผู้จัดการถามว่าชิ้นที่ i นับจากซ้าย (ชิ้นซ้ายสุดคือชิ้นที่ 1) คือหมายเลขอะไร โดยไม่หยิบออก ถ้าชั้นมีขนมปังไม่ถึง i ชิ้นให้พิมพ์ NONE

ทำครบทุกคำสั่งแล้ว ให้พิมพ์จำนวนขนมปังที่ยังเหลือบนชั้น

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 200000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน โดยที่ 1 ≤ x ≤ 1000000000 และ 1 ≤ i ≤ 1000000000

ข้อมูลออก

สำหรับคำสั่ง FRESH SALE และ CHECK แต่ละคำสั่ง ให้พิมพ์คำตอบหนึ่งบรรทัดตามลำดับของคำสั่ง บรรทัดสุดท้ายพิมพ์จำนวนขนมปังที่เหลือบนชั้น
