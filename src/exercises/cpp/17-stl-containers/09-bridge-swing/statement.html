เครื่องวัดแรงสั่นสะเทือนบนสะพานบันทึกค่าเป็นจำนวนเต็มทุกมิลลิวินาที รวม N ค่า ค่าติดลบได้ เพราะสะพานแกว่งได้ทั้งสองทาง วิศวกรอยากรู้ว่าในทุกช่วง K มิลลิวินาทีติดกัน สะพานแกว่งกว้างแค่ไหน ความกว้างของการแกว่งในช่วงหนึ่งคือค่ามากสุดลบด้วยค่าน้อยสุดในช่วงนั้น

ให้หาความกว้างของการแกว่งของทุกช่วง ตั้งแต่ช่วงที่เริ่มที่ค่าแรก ไปจนถึงช่วงที่จบที่ค่าสุดท้าย รวม N - K + 1 ช่วง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ K ≤ N ≤ 1000000

บรรทัดที่สองมีจำนวนเต็ม N ตัวคั่นด้วยช่องว่าง แต่ละตัวมีค่าตั้งแต่ -2000000000 ถึง 2000000000

ข้อมูลออก

บรรทัดเดียว มีจำนวนเต็ม N - K + 1 ตัวคั่นด้วยช่องว่างหนึ่งช่อง ตัวที่ i คือความกว้างของการแกว่งในช่วงที่เริ่มที่ค่าที่ i
