เขื่อนแห่งหนึ่งวัดระดับน้ำวันละครั้ง ติดต่อกัน N วัน วันที่ i วัดได้ hi มิลลิเมตร ข่าวชอบพาดหัวว่า "ระดับน้ำวันนี้สูงสุดในรอบ X วัน" ซึ่งหมายถึงวันนี้กับอีก X - 1 วันก่อนหน้าที่ติดกัน รวม X วัน ทุกวันในช่วงนั้นมีระดับน้ำไม่เกินระดับของวันนี้ และ X มากที่สุดเท่าที่เป็นไปได้ ถ้าเมื่อวานระดับน้ำสูงกว่าวันนี้ X จะเป็น 1 เพราะนับแค่วันนี้วันเดียว

ให้หา X ของทุกวัน

ข้อนี้กลับด้านของข้อตึกที่สูงกว่าหลังแรกในบทที่ 14 ข้อนั้นมองไปทางขวา ข้อนี้มองย้อนไปทางซ้าย และนับวันที่สูงเท่ากันรวมในช่วงด้วย ตั้งใจให้ฝึกเขียน monotonic stack ด้วย stack ของ STL แล้วระวังเครื่องหมายเทียบให้ตรงกับโจทย์

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ h1 ถึง hN คั่นด้วยช่องว่าง โดยที่ 1 ≤ hi ≤ 1000000000

ข้อมูลออก

บรรทัดเดียว มีจำนวนเต็ม N ตัวคั่นด้วยช่องว่างหนึ่งช่อง ตัวที่ i คือ X ของวันที่ i
