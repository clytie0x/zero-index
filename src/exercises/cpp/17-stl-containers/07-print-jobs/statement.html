ห้องคอมพิวเตอร์มีเครื่องพิมพ์ใช้ร่วมกันหนึ่งเครื่อง วันนี้มีงานพิมพ์ส่งมา N งาน งานที่ i ส่งมาถึงที่วินาทีที่ ai และยาว pi หน้า เครื่องพิมพ์ได้วินาทีละหนึ่งหน้า เพื่อไม่ให้งานยาวงานเดียวกันคนอื่นไว้นาน เครื่องจะพิมพ์งานหนึ่งติดต่อกันได้ไม่เกิน K หน้าต่อรอบ แล้วต้องสลับไปงานอื่น เครื่องทำงานตามกฎนี้

  • งานที่ส่งมาถึงจะต่อท้ายคิว ถ้าหลายงานมาถึงเวลาเดียวกัน งานที่อยู่ก่อนในข้อมูลเข้าต่อคิวก่อน
  • เมื่อเครื่องว่าง ถ้าคิวมีงาน เครื่องหยิบงานหัวคิวมาพิมพ์ติดต่อกัน K หน้า หรือเท่าที่งานนั้นเหลือถ้าเหลือน้อยกว่า K หน้า ถ้าคิวว่าง เครื่องรอจนกว่าจะมีงานส่งมาถึง
  • เมื่อพิมพ์จบหนึ่งรอบที่วินาทีที่ T ให้งานทุกงานที่ส่งมาถึงภายในวินาทีที่ T รวมถึงที่มาถึงตรงวินาทีที่ T พอดี ต่อท้ายคิวให้เรียบร้อยก่อน จากนั้นถ้างานที่เพิ่งพิมพ์ยังเหลือหน้า งานนั้นกลับไปต่อท้ายคิว ถ้าไม่เหลือแล้ว งานนั้นเสร็จที่วินาทีที่ T

ให้หาว่างานแต่ละงานเสร็จที่วินาทีที่เท่าไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 1 ≤ K ≤ 1000000000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม ai และ pi คั่นด้วยช่องว่าง โดยที่ 0 ≤ a1 ≤ a2 ≤ ... ≤ aN ≤ 1000000000 และ 1 ≤ pi ≤ 1000000000

รับประกันว่าจำนวนรอบที่เครื่องพิมพ์ทั้งหมดรวมกันไม่เกิน 2000000 รอบ

ข้อมูลออก

N บรรทัด บรรทัดที่ i คือวินาทีที่งานที่ i พิมพ์เสร็จ
