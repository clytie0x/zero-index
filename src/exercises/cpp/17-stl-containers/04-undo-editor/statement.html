โปรแกรมพิมพ์ข้อความบนโทรศัพท์รุ่นหนึ่งพิมพ์ได้ทีละคำ และมีปุ่ม undo ให้ย้อนการแก้ไข ตอนเริ่มข้อความว่าง ผู้ใช้กดคำสั่ง Q ครั้ง แต่ละคำสั่งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • TYPE w พิมพ์คำ w ต่อท้ายข้อความ
  • DELETE ลบคำสุดท้ายของข้อความ ถ้าข้อความว่างอยู่ คำสั่งนี้ไม่มีผลอะไร และไม่นับเป็นการแก้ไข
  • UNDO ย้อนการแก้ไขครั้งล่าสุดที่ยังไม่ถูกย้อน การแก้ไขคือ TYPE หรือ DELETE ที่มีผลจริง ย้อน TYPE คือเอาคำที่พิมพ์ออก ย้อน DELETE คือเอาคำที่ถูกลบกลับมาต่อท้าย กด UNDO ติดกันหลายครั้งจะย้อนจากการแก้ไขล่าสุดไปหาเก่าสุดทีละครั้ง ถ้าไม่มีการแก้ไขเหลือให้ย้อน คำสั่งนี้ไม่มีผลอะไร คำสั่ง UNDO เองไม่ใช่การแก้ไข จึงย้อนไม่ได้
  • LAST พิมพ์คำสุดท้ายของข้อความ ถ้าข้อความว่างให้พิมพ์ EMPTY

ทำครบทุกคำสั่งแล้ว ให้พิมพ์ข้อความทั้งหมด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 200000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน คำ w ยาว 1 ถึง 10 ตัวอักษร เป็นตัวอักษรภาษาอังกฤษตัวเล็กเท่านั้น

ข้อมูลออก

สำหรับคำสั่ง LAST แต่ละคำสั่ง ให้พิมพ์คำตอบหนึ่งบรรทัดตามลำดับ

บรรทัดสุดท้ายพิมพ์ข้อความทั้งหมด คำคั่นด้วยช่องว่างหนึ่งช่อง ถ้าข้อความว่างให้พิมพ์ EMPTY
