รายการประกวดร้องเพลงออนไลน์เปิดให้ผู้เข้าประกวดส่งคลิปทีละคน กรรมการให้คะแนนทันทีที่ดูคลิปจบ ประกาศกติกาไว้ว่าผู้ที่อยู่ใน K อันดับแรกเมื่อปิดรับสมัครจะได้เข้ารอบ ทุกครั้งที่มีคะแนนใหม่ ผู้เข้าประกวดอยากรู้ว่าตอนนี้ต้องได้คะแนนอย่างน้อยเท่าไรถึงจะติด K อันดับแรก ซึ่งก็คือคะแนนของอันดับที่ K ในขณะนั้น

คะแนนที่เท่ากันนับแยกกันคนละอันดับ เช่น ถ้าคะแนนตอนนี้คือ 90 85 85 70 อันดับที่ 3 คือ 85

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง (1 ≤ K ≤ N ≤ 300000)

บรรทัดที่สองมีคะแนนของผู้เข้าประกวดคนที่ 1 ถึง N ตามลำดับที่ส่ง คั่นด้วยช่องว่าง แต่ละคะแนนเป็นจำนวนเต็มตั้งแต่ 0 ถึง 109

ข้อมูลออก

N บรรทัด บรรทัดที่ i เป็นคะแนนของอันดับที่ K หลังจากได้คะแนนของคนที่ 1 ถึง i แล้ว ถ้ายังมีผู้เข้าประกวดไม่ถึง K คน ให้พิมพ์ -1
