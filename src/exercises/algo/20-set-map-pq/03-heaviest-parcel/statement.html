โกดังพัสดุแห่งหนึ่งมีรถขนของออกไปทีละคัน รถแต่ละคันรับพัสดุได้ทีละชิ้น และหัวหน้าสั่งว่าให้ส่งชิ้นที่หนักที่สุดในโกดังออกไปก่อนเสมอ ตลอดวันมีเหตุการณ์ Q ครั้งเรียงตามเวลา แต่ละครั้งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • + w มีพัสดุหนัก w กรัมเข้ามาในโกดัง
  • - มีรถมารับของ ให้ส่งพัสดุที่หนักที่สุดในโกดังขณะนั้นออกไป ถ้าหนักเท่ากันหลายชิ้น ส่งชิ้นไหนก็ได้เพราะน้ำหนักที่พิมพ์ออกมาเท่ากัน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q (1 ≤ Q ≤ 300000)

อีก Q บรรทัด บรรทัดละหนึ่งเหตุการณ์ในรูปแบบข้างบน โดยที่ 1 ≤ w ≤ 109

ข้อมูลออก

ทุกเหตุการณ์ - ให้พิมพ์หนึ่งบรรทัด เป็นน้ำหนักของพัสดุที่ส่งออกไป ถ้าตอนนั้นโกดังว่าง ให้พิมพ์ EMPTY
