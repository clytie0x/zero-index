ห้องสอบใหญ่มีที่นั่ง N ที่ หมายเลข 1 ถึง N เรียงจากหน้าห้องไปหลังห้อง ตอนเริ่มทุกที่ว่าง ระบบจองที่นั่งรับคำสั่ง Q คำสั่งตามลำดับเวลา แต่ละคำสั่งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • B x นักเรียนคนหนึ่งขอที่นั่งหมายเลข x ถ้าที่นั่ง x ว่าง ระบบให้ที่นั่ง x ถ้าไม่ว่าง ระบบให้ที่นั่งว่างที่หมายเลขน้อยที่สุดที่มากกว่า x ถ้าไม่มีที่ว่างตั้งแต่ x ไปจนถึง N เลย นักเรียนคนนี้ไม่ได้ที่นั่ง
  • L x นักเรียนที่นั่งอยู่ที่หมายเลข x ลุกออกไป ที่นั่ง x กลับมาว่าง รับประกันว่าตอนนั้นมีคนนั่งที่ x อยู่

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง (1 ≤ N ≤ 200000, 1 ≤ Q ≤ 200000)

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งในรูปแบบข้างบน โดยที่ 1 ≤ x ≤ N

ข้อมูลออก

ทุกคำสั่ง B ให้พิมพ์หนึ่งบรรทัด เป็นหมายเลขที่นั่งที่นักเรียนได้ ถ้าไม่ได้ที่นั่ง ให้พิมพ์ 0
