ทางหลวงสายหนึ่งยาว 109 เมตร มีจุดบอกระยะตั้งแต่เมตรที่ 0 ไปจนสุดทาง บริษัทพลังงานทยอยเปิดและปิดสถานีชาร์จรถไฟฟ้าตามจุดต่างๆ ส่วนแอปนำทางต้องตอบผู้ขับขี่ว่าจากจุดที่อยู่ สถานีชาร์จที่เปิดอยู่ที่ใกล้ที่สุดห่างไปกี่เมตร จะอยู่ข้างหน้าหรือข้างหลังก็ได้

มีเหตุการณ์ Q ครั้งเรียงตามเวลา แต่ละครั้งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • + x เปิดสถานีที่เมตรที่ x รับประกันว่าตอนนั้นยังไม่มีสถานีเปิดอยู่ที่จุดนี้
  • - x ปิดสถานีที่เมตรที่ x รับประกันว่าตอนนั้นมีสถานีเปิดอยู่ที่จุดนี้
  • ? x ผู้ขับขี่อยู่ที่เมตรที่ x ถามระยะไปยังสถานีที่เปิดอยู่ที่ใกล้ที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q (1 ≤ Q ≤ 200000)

อีก Q บรรทัด บรรทัดละหนึ่งเหตุการณ์ในรูปแบบข้างบน โดยที่ 0 ≤ x ≤ 109

ข้อมูลออก

ทุกเหตุการณ์ ? ให้พิมพ์หนึ่งบรรทัด เป็นระยะไปยังสถานีที่ใกล้ที่สุด ถ้าตอนนั้นไม่มีสถานีเปิดอยู่เลย ให้พิมพ์ -1
