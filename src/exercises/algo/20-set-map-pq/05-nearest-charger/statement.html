ทางหลวงสายหนึ่งยาว 109 เมตร มีจุดบอกระยะตั้งแต่เมตรที่ 0 ไปจนสุดทาง บริษัทพลังงานทยอยเปิดและปิดหัวชาร์จรถไฟฟ้าตามจุดต่างๆ จุดเดียวกันมีหัวชาร์จได้หลายหัว เพราะสถานีใหญ่ติดตั้งหลายหัวเรียงกัน ส่วนแอปนำทางต้องตอบผู้ขับขี่ว่าจากจุดที่อยู่ หัวชาร์จที่เปิดอยู่ที่ใกล้ที่สุดห่างไปกี่เมตร จะอยู่ข้างหน้าหรือข้างหลังก็ได้

มีเหตุการณ์ Q ครั้งเรียงตามเวลา แต่ละครั้งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • + x เปิดหัวชาร์จเพิ่มหนึ่งหัวที่เมตรที่ x ที่จุดนี้อาจมีหัวที่เปิดอยู่แล้วกี่หัวก็ได้
  • - x ปิดหัวชาร์จหนึ่งหัวที่เมตรที่ x รับประกันว่าตอนนั้นมีหัวที่เปิดอยู่ที่จุดนี้อย่างน้อยหนึ่งหัว ถ้ามีหลายหัว หัวที่เหลือยังเปิดอยู่
  • ? x ผู้ขับขี่อยู่ที่เมตรที่ x ถามระยะไปยังหัวชาร์จที่เปิดอยู่ที่ใกล้ที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q (1 ≤ Q ≤ 200000)

อีก Q บรรทัด บรรทัดละหนึ่งเหตุการณ์ในรูปแบบข้างบน โดยที่ 0 ≤ x ≤ 109

ข้อมูลออก

ทุกเหตุการณ์ ? ให้พิมพ์หนึ่งบรรทัด เป็นระยะไปยังหัวชาร์จที่ใกล้ที่สุด ถ้าตอนนั้นไม่มีหัวชาร์จเปิดอยู่เลย ให้พิมพ์ -1
