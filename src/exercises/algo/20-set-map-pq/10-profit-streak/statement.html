ร้านกาแฟของสหกรณ์โรงเรียนจดกำไรของแต่ละวันไว้ N วัน วันที่ขาดทุนจดเป็นค่าติดลบ ผู้จัดการอยากรู้ว่ามีช่วงของวันที่ติดกันกี่ช่วง ที่กำไรรวมของทุกวันในช่วงนั้นเท่ากับเป้า K บาทพอดี

ช่วงหนึ่งคือวันที่ l ถึงวันที่ r เมื่อ 1 ≤ l ≤ r ≤ N สองช่วงที่ l หรือ r ต่างกันนับเป็นคนละช่วง ช่วงที่มีวันเดียวก็นับ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง (1 ≤ N ≤ 200000, -1015 ≤ K ≤ 1015)

บรรทัดที่สองมีกำไรของวันที่ 1 ถึง N คั่นด้วยช่องว่าง แต่ละค่าเป็นจำนวนเต็มตั้งแต่ -109 ถึง 109

ข้อมูลออก

จำนวนช่วงที่กำไรรวมเท่ากับ K
