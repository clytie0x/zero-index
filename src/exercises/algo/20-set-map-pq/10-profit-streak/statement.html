ร้านกาแฟของสหกรณ์โรงเรียนจดกำไรของแต่ละวันไว้ N วัน วันที่ขาดทุนจดเป็นค่าติดลบ ผู้จัดการอยากเขียนรายงานว่า "ร้านทำกำไรได้ตรงเป้า K บาทพอดีในช่วงเวลา X วันติดกัน" และอยากให้ X มากที่สุดเท่าที่ทำได้ ให้หาว่าช่วงวันติดกันที่กำไรรวมเท่ากับ K พอดี ยาวที่สุดกี่วัน

ช่วงหนึ่งคือวันที่ l ถึงวันที่ r เมื่อ 1 ≤ l ≤ r ≤ N ยาว r - l + 1 วัน ช่วงที่มีวันเดียวก็นับ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง (1 ≤ N ≤ 200000, -1015 ≤ K ≤ 1015)

บรรทัดที่สองมีกำไรของวันที่ 1 ถึง N คั่นด้วยช่องว่าง แต่ละค่าเป็นจำนวนเต็มตั้งแต่ -109 ถึง 109

ข้อมูลออก

ความยาวเป็นจำนวนวันของช่วงที่ยาวที่สุดที่กำไรรวมเท่ากับ K ถ้าไม่มีช่วงไหนเลยให้พิมพ์ 0
