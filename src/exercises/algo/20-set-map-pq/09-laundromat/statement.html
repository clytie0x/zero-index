ร้านสะดวกซักหน้ามหาวิทยาลัยมีเครื่องซักผ้า K เครื่อง หมายเลข 1 ถึง K วันนี้มีลูกค้า N คน คนที่ i มาถึงร้านเวลา ti (นาทีนับจากร้านเปิด) และต้องใช้เครื่องนาน di นาที ลูกค้าได้ใช้เครื่องตามลำดับที่มาถึงร้าน คนที่มาก่อนได้ก่อนเสมอ ถ้ามาถึงพร้อมกัน คนที่อยู่ก่อนในข้อมูลเข้าได้ก่อน

เมื่อถึงคิวของลูกค้าคนหนึ่ง เขาเริ่มซักทันทีที่มีเครื่องว่าง ถ้าตอนนั้นมีเครื่องว่างหลายเครื่อง เขาเลือกเครื่องที่หมายเลขน้อยที่สุด ถ้าไม่มีเครื่องว่างเลย เขารอจนกว่าจะมีเครื่องซักเสร็จ เครื่องที่ซักเสร็จเวลา f ว่างให้คนถัดไปใช้ได้ตั้งแต่เวลา f พอดี ลูกค้าคนที่ i ที่เริ่มซักเวลา s จะซักเสร็จเวลา s + di

ให้บอกว่าลูกค้าแต่ละคนได้เครื่องหมายเลขอะไร และซักเสร็จเวลาเท่าไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง (1 ≤ N, K ≤ 200000)

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม ti และ di คั่นด้วยช่องว่าง (0 ≤ ti ≤ 109, 1 ≤ di ≤ 109) รับประกันว่า t1 ≤ t2 ≤ ... ≤ tN

ข้อมูลออก

N บรรทัด บรรทัดที่ i มีหมายเลขเครื่องของลูกค้าคนที่ i ตามด้วยช่องว่าง แล้วตามด้วยเวลาที่ซักเสร็จ
