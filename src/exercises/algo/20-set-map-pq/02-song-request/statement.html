สถานีวิทยุของโรงเรียนเปิดให้นักเรียนส่งข้อความขอเพลงช่วงพักเที่ยง แต่ละข้อความมีรหัสเพลงหนึ่งรหัส วันนี้มีข้อความเข้ามา N ข้อความ ดีเจอยากรู้ว่าเพลงไหนมีคนขอมากที่สุด และมีคนขอกี่ครั้ง ถ้ามีหลายเพลงที่คนขอเท่ากันมากที่สุด ให้ตอบเพลงที่รหัสน้อยที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 200000)

บรรทัดที่สองมีรหัสเพลงของข้อความที่ 1 ถึง N คั่นด้วยช่องว่าง แต่ละรหัสเป็นจำนวนเต็มตั้งแต่ 1 ถึง 109

ข้อมูลออก

บรรทัดเดียว มีรหัสเพลงที่คนขอมากที่สุด ตามด้วยช่องว่าง แล้วตามด้วยจำนวนครั้งที่เพลงนั้นถูกขอ
