งานเลี้ยงรุ่นมีสมุดเยี่ยมให้แขกเขียนชื่อตอนเข้างาน แขกบางคนออกไปข้างนอกแล้วกลับเข้ามาใหม่ จึงเขียนชื่อซ้ำ บางคนเขียนสามสี่รอบ ทั้งสมุดมีชื่อเขียนไว้ N ครั้ง กรรมการอยากรู้ว่าวันนี้มีแขกมากี่คน และอยากได้รายชื่อแขกเรียงตามตัวอักษรเพื่อส่งรูปให้ทีหลัง

ชื่อเดียวกันถือว่าเป็นคนเดียวกัน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 100000)

อีก N บรรทัด บรรทัดละหนึ่งชื่อ ตามลำดับที่เขียนในสมุด แต่ละชื่อเป็นตัวอักษรภาษาอังกฤษตัวพิมพ์เล็ก a ถึง z ยาว 1 ถึง 20 ตัว

ข้อมูลออก

บรรทัดแรกพิมพ์จำนวนแขกที่ไม่ซ้ำกัน D

อีก D บรรทัดพิมพ์ชื่อแขก บรรทัดละหนึ่งชื่อ เรียงตามตัวอักษรจากน้อยไปมากแบบพจนานุกรม
