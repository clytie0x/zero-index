ห้องแล็บเคมีมีขวดสามใบไม่มีขีดบอกปริมาตร ขวด A จุได้ A มิลลิลิตร ขวด B จุ B มิลลิลิตร และขวด C จุ C มิลลิลิตร ตอนเริ่มขวดทั้งสามมีน้ำ a b และ c มิลลิลิตรตามลำดับ ไม่มีก๊อกน้ำ และห้ามเทน้ำทิ้ง สิ่งที่ทำได้มีอย่างเดียว คือเทน้ำจากขวดหนึ่งไปอีกขวดหนึ่ง จนกว่าขวดต้นทางจะหมด หรือขวดปลายทางจะเต็ม แล้วแต่อย่างไหนเกิดก่อน

สถานะคือปริมาณน้ำในสามขวด ให้หาว่าเมื่อเทกี่ครั้งก็ได้ จะไปถึงสถานะที่ต่างกันได้กี่แบบ นับสถานะเริ่มต้นด้วย และขวด A มีน้ำได้กี่มิลลิลิตรบ้าง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม A B C คั่นด้วยช่องว่าง โดยที่ 1 ≤ A, B, C ≤ 100

บรรทัดที่สองมีจำนวนเต็ม a b c คั่นด้วยช่องว่าง โดยที่ 0 ≤ a ≤ A, 0 ≤ b ≤ B และ 0 ≤ c ≤ C

ข้อมูลออก

บรรทัดแรกพิมพ์จำนวนสถานะที่ไปถึงได้ บรรทัดที่สองพิมพ์ปริมาณน้ำที่เป็นไปได้ทั้งหมดของขวด A เรียงจากน้อยไปมาก ไม่ซ้ำ คั่นด้วยช่องว่างหนึ่งช่อง
