ร้านเครื่องเขียนรับส่งของถึงบ้าน วันนี้ต้องส่งพัสดุให้ N บ้าน หมายเลข 1 ถึง N ให้ร้านเป็นจุดหมายเลข 0 คนส่งของออกจากร้าน ขับไปส่งทุกบ้าน บ้านละหนึ่งครั้ง เรียงลำดับแบบไหนก็ได้ ส่งบ้านสุดท้ายเสร็จแล้วกลับบ้านตัวเองได้เลย ไม่ต้องกลับร้าน

ระยะทางจากจุด i ไปจุด j คือ d[i][j] กิโลเมตร ถนนบางเส้นเป็นทางเดินรถทางเดียว d[i][j] จึงอาจไม่เท่ากับ d[j][i] ให้หาระยะทางรวมที่สั้นที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 9

อีก N + 1 บรรทัด บรรทัดที่ i (นับจาก 0) มีจำนวนเต็ม N + 1 ตัว คือ d[i][0] ถึง d[i][N] คั่นด้วยช่องว่าง โดยที่ d[i][i] = 0 และ 1 ≤ d[i][j] ≤ 1000 เมื่อ i ≠ j

ข้อมูลออก

ระยะทางรวมที่สั้นที่สุด
