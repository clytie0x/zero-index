สัปดาห์สอบมีเวรคุมสอบ N เวร และมีครู N คน ครูหนึ่งคนรับได้หนึ่งเวร และทุกเวรต้องมีครูรับหนึ่งคน ครูแต่ละคนเหนื่อยกับแต่ละเวรไม่เท่ากัน เพราะบ้านไกลใกล้และวิชาที่สอนต่างกัน ถ้าครูคนที่ i รับเวรที่ j จะเหนื่อย cij หน่วย ฝ่ายวิชาการอยากจัดเวรให้ความเหนื่อยรวมของครูทุกคนน้อยที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 13

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม ci1 ถึง ciN คั่นด้วยช่องว่าง โดยที่ 1 ≤ cij ≤ 1000000

ข้อมูลออก

ความเหนื่อยรวมที่น้อยที่สุด
