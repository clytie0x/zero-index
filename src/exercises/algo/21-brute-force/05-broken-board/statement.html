ชมรมหมากรุกมีกระดานขนาด N × N อยู่กระดานหนึ่ง ใช้มานานจนบางช่องแตก วางหมากไม่ได้ ประธานชมรมอยากรู้ว่าจะวางควีน N ตัวลงบนช่องที่ยังดีอยู่ โดยไม่มีควีนสองตัวไหนกินกันได้ ได้ทั้งหมดกี่แบบ ควีนกินกันได้เมื่ออยู่แถวเดียวกัน คอลัมน์เดียวกัน หรือแนวทแยงเดียวกัน ไม่ว่าจะห่างกันแค่ไหนและไม่ว่าระหว่างนั้นจะมีช่องที่แตกหรือไม่ ควีนทุกตัวเหมือนกัน สองแบบต่างกันถ้าชุดของช่องที่วางต่างกัน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 12

อีก N บรรทัด แต่ละบรรทัดเป็นข้อความยาว N ตัว ตัว . คือช่องที่ยังดี และ # คือช่องที่แตก

ข้อมูลออก

จำนวนแบบของการวางควีน N ตัว
