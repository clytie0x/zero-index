หมู่บ้านบนเกาะห่างไกลยังไม่มีไฟฟ้า บ้าน N หลัง หมายเลข 1 ถึง N บ้านหลังที่ i ตั้งอยู่ที่พิกัด (xi, yi) บนแผนที่หน่วยเมตร ทุกบ้านต้องมีไฟฟ้าใช้ ทำได้สองทาง

  • ติดแผงโซลาร์เซลล์ที่บ้านหลังที่ i ราคา si บาท
  • เดินสายไฟระหว่างบ้านสองหลัง i กับ j สายต้องเดินตามคันนาที่เป็นตารางตั้งฉาก ยาว |xi - xj| + |yi - yj| เมตร ราคาเมตรละ K บาท ไฟไหลในสายได้ทั้งสองทาง

บ้านหลังหนึ่งมีไฟใช้ถ้าติดแผงเอง หรือเดินสายต่อกันเป็นทอดๆ ไปถึงบ้านที่ติดแผงได้ ให้หาราคารวมที่น้อยที่สุดที่ทำให้ทุกบ้านมีไฟใช้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 7000 และ 1 ≤ K ≤ 1000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม xi yi และ si คั่นด้วยช่องว่าง โดยที่ 0 ≤ xi, yi ≤ 106 และ 1 ≤ si ≤ 109 บ้านหลายหลังอาจอยู่พิกัดเดียวกันได้
