แอปแชตของโรงเรียนมีผู้ใช้ N คน หมายเลข 1 ถึง N ตอนเริ่ม ผู้ใช้หมายเลข i อยู่คนเดียวในห้องแชตหมายเลข i ระบบรับคำสั่ง Q คำสั่งตามลำดับ มีสองแบบ

  • 1 a b ย้ายทุกคนในห้องที่ b อยู่ เข้าไปในห้องที่ a อยู่ ห้องที่รวมแล้วใช้หมายเลขห้องของ a ต่อไป ส่วนหมายเลขห้องเดิมของ b เลิกใช้ ถ้า a กับ b อยู่ห้องเดียวกันอยู่แล้ว ไม่มีอะไรเปลี่ยน
  • 2 a ถามว่าตอนนี้ a อยู่ห้องหมายเลขอะไร และห้องนั้นมีสมาชิกกี่คน นับ a ด้วย

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 400000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน โดยที่ 1 ≤ a, b ≤ N และ a กับ b อาจเป็นคนเดียวกันได้

ข้อมูลออก

ตอบคำสั่งแบบ 2 ตามลำดับ คำสั่งละหนึ่งบรรทัด มีหมายเลขห้อง และจำนวนสมาชิกในห้อง คั่นด้วยช่องว่าง
