แอปแชตของโรงเรียนมีผู้ใช้ N คน หมายเลข 1 ถึง N ตอนเริ่มทุกคนอยู่ในห้องแชตของตัวเองคนเดียว ระบบรับคำสั่ง Q คำสั่งตามลำดับ มีสามแบบ

  • 1 a b ห้องที่ a อยู่กับห้องที่ b อยู่รวมกันเป็นห้องเดียว ทุกคนในสองห้องนั้นอยู่ห้องใหม่ด้วยกัน ถ้า a กับ b อยู่ห้องเดียวกันอยู่แล้ว ไม่มีอะไรเปลี่ยน
  • 2 a b ถามว่าตอนนี้ a กับ b อยู่ห้องเดียวกันหรือไม่
  • 3 a ถามว่าตอนนี้ห้องที่ a อยู่มีสมาชิกกี่คน นับ a ด้วย

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 400000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน โดยที่ 1 ≤ a, b ≤ N และ a กับ b อาจเป็นคนเดียวกันได้

ข้อมูลออก

ตอบคำสั่งแบบ 2 และแบบ 3 ตามลำดับ คำสั่งละหนึ่งบรรทัด คำสั่งแบบ 2 ตอบ YES ถ้าอยู่ห้องเดียวกัน หรือ NO ถ้าไม่ คำสั่งแบบ 3 ตอบจำนวนสมาชิก
