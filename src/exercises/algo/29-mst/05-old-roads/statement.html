จังหวัดหนึ่งมีเมือง N เมือง หมายเลข 1 ถึง N มีถนนเก่าที่ใช้ได้อยู่แล้ว K เส้น แต่ยังมีบางเมืองที่ไปมาหากันไม่ได้ วิศวกรเสนอแนวถนนใหม่ M แนว แนวที่ i เชื่อมเมือง ai กับ bi ราคา ci ล้านบาท ถนนทุกเส้นวิ่งได้สองทาง

บริษัทแห่งหนึ่งรับเป็นผู้สนับสนุน จะจ่ายค่าก่อสร้างให้ถนนใหม่หนึ่งแนวที่จังหวัดเลือก จังหวัดต้องเลือกสร้างถนนใหม่บางแนว และเลือกว่าจะให้บริษัทจ่ายแนวไหน ให้ทุกเมืองไปมาหากันได้ผ่านถนนเก่าและถนนใหม่ โดยเงินที่จังหวัดต้องจ่ายเองน้อยที่สุด แนวที่บริษัทจ่ายต้องเป็นแนวที่สร้างจริง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N K และ M คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000, 0 ≤ K ≤ 200000 และ 0 ≤ M ≤ 200000

อีก K บรรทัดเป็นถนนเก่า บรรทัดละสองจำนวน คือเมืองสองเมืองที่ถนนเชื่อม

อีก M บรรทัดเป็นแนวถนนใหม่ บรรทัดที่ i มี ai bi และ ci โดยที่ 1 ≤ ci ≤ 109

ทุกถนนเชื่อมเมืองสองเมืองที่ต่างกัน และเมืองคู่เดียวกันอาจมีถนนหลายเส้น

ข้อมูลออก

เงินที่จังหวัดต้องจ่ายเองน้อยที่สุด เป็นล้านบาท ถ้าถนนเก่าต่อทุกเมืองถึงกันอยู่แล้ว ไม่ต้องสร้างอะไรเลย ให้พิมพ์ 0 ถ้าสร้างทุกแนวแล้วก็ยังไม่ครบ ให้พิมพ์ -1
