บริษัทขนส่งมีเมือง N เมือง หมายเลข 1 ถึง N และถนน M เส้น ถนนเส้นที่ i เชื่อมเมือง ai กับ bi วิ่งได้สองทาง และมีสะพานที่รับน้ำหนักได้ไม่เกิน wi ตัน รถคันหนึ่งวิ่งผ่านถนนเส้นใดได้ก็ต่อเมื่อน้ำหนักรถไม่เกินที่สะพานของถนนเส้นนั้นรับได้

ฝ่ายวางแผนมีคำถาม Q ข้อ ข้อที่ j ถามว่ารถหนัก tj ตัน วิ่งจากเมือง xj ไปเมือง yj ได้หรือไม่ ผ่านเมืองอื่นกี่เมืองก็ได้ ถ้าเมืองต้นทางกับปลายทางเป็นเมืองเดียวกัน ถือว่าไปได้เสมอ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N M และ Q คั่นด้วยช่องว่าง โดยที่ 2 ≤ N ≤ 100000, 1 ≤ M ≤ 200000 และ 1 ≤ Q ≤ 100000

อีก M บรรทัด บรรทัดที่ i มีจำนวนเต็ม ai bi และ wi โดยที่ ai ≠ bi และ 1 ≤ wi ≤ 109

อีก Q บรรทัด บรรทัดที่ j มีจำนวนเต็ม xj yj และ tj โดยที่ 1 ≤ xj, yj ≤ N และ 1 ≤ tj ≤ 109

ข้อมูลออก

Q บรรทัด ตอบตามลำดับคำถาม บรรทัดละหนึ่งข้อ พิมพ์ YES ถ้ารถวิ่งไปได้ หรือ NO ถ้าไปไม่ได้
