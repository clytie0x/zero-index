สถานีตรวจอากาศบนยอดดอยบันทึกค่าจากเซนเซอร์ไว้ N ครั้งตามลำดับเวลา นักอุตุนิยมวิทยาอยากเลือกบางครั้งออกมาโดยคงลำดับเวลาเดิม ให้ค่าที่เลือก มากกว่าค่าก่อนหน้าทุกครั้ง ค่าที่เท่ากันไม่นับว่ามากกว่า ให้หาว่าเลือกได้มากที่สุดกี่ครั้ง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือค่าที่อ่านได้ตามลำดับเวลา แต่ละค่าอยู่ระหว่าง -109 ถึง 109

ข้อมูลออก

จำนวนครั้งที่เลือกได้มากที่สุด
