ร้านผ้าไหมมีผ้าม้วนหนึ่งยาว L เซนติเมตร จะตัดเป็นชิ้นขาย มีขนาดที่ลูกค้าต้องการ N แบบ แบบที่ i ยาว li เซนติเมตร ขายได้ชิ้นละ pi บาท แต่ละแบบตัดได้กี่ชิ้นก็ได้ ขายได้หมดทุกชิ้น ส่วนที่เหลือจากการตัดขายไม่ได้ ให้หารายได้มากที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ L คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100 และ 1 ≤ L ≤ 100000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม li และ pi โดยที่ 1 ≤ li ≤ 100000 และ 1 ≤ pi ≤ 106

ข้อมูลออก

รายได้มากที่สุดเป็นบาท
