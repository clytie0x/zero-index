รถส่งนมออกจากโรงนมตอนตีห้า ต้องส่งนมให้ร้านค้า N - 1 ร้าน ร้านละหนึ่งครั้ง ส่งร้านสุดท้ายเสร็จแล้วจอดพักที่นั่นได้เลย ไม่ต้องกลับโรงนม กำหนดให้โรงนมเป็นจุดที่ 0 และร้านค้าเป็นจุดที่ 1 ถึง N - 1 ถนนในตำบลมีทั้งทางเดินรถทางเดียวและสองทาง ระยะจากจุด i ไปจุด j จึงอาจไม่เท่ากับระยะจากจุด j กลับไปจุด i ให้หาระยะทางรวมที่สั้นที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 16

อีก N บรรทัด บรรทัดที่ i (นับจาก 0) มีจำนวนเต็ม N ตัว ตัวที่ j คือระยะทางจากจุด i ไปจุด j เป็นเมตร ระยะจากจุดหนึ่งไปตัวเองเป็น 0 ระยะอื่นอยู่ระหว่าง 1 ถึง 106

ข้อมูลออก

ระยะทางรวมที่สั้นที่สุด ถ้าไม่มีร้านค้าเลย ให้ตอบ 0
