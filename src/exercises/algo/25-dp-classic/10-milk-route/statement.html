รถส่งนมออกจากโรงนมตอนตีห้า ต้องส่งนมให้ร้านค้า N - 1 ร้าน ร้านละหนึ่งครั้ง แล้วกลับมาจอดที่โรงนม กำหนดให้โรงนมเป็นจุดที่ 0 และร้านค้าเป็นจุดที่ 1 ถึง N - 1 ในจำนวนนี้มีร้านด่วน K ร้านที่ต้องได้นมก่อนเปิดร้าน รถจึงต้องส่งร้านด่วนให้ครบทุกร้านก่อน แล้วค่อยส่งร้านอื่น ร้านด่วนส่งในลำดับไหนก็ได้ ร้านอื่นก็เช่นกัน

ถนนในตำบลมีทั้งทางเดินรถทางเดียวและสองทาง ตารางในข้อมูลเข้าบอกระยะของถนนตรงจากจุด i ไปจุด j ซึ่งอาจไม่เท่ากับระยะจากจุด j กลับไปจุด i การเดินทางจากจุดหนึ่งไปอีกจุดหนึ่ง รถต้องใช้ถนนตรงของคู่นั้นตามตารางเท่านั้น ห้ามอ้อมผ่านจุดอื่น แม้ทางอ้อมจะสั้นกว่าก็ตาม ให้หาระยะทางรวมที่สั้นที่สุดของการเดินทางทั้งรอบ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 16 และ 0 ≤ K ≤ N - 1

อีก N บรรทัด บรรทัดที่ i (นับจาก 0) มีจำนวนเต็ม N ตัว ตัวที่ j คือระยะของถนนตรงจากจุด i ไปจุด j เป็นเมตร ระยะจากจุดหนึ่งไปตัวเองเป็น 0 ระยะอื่นอยู่ระหว่าง 1 ถึง 106

ถ้า K มากกว่า 0 บรรทัดสุดท้ายมีจำนวนเต็ม K ตัว คือหมายเลขร้านด่วน ไม่ซ้ำกัน แต่ละตัวอยู่ระหว่าง 1 ถึง N - 1 ถ้า K เป็น 0 จะไม่มีบรรทัดนี้

ข้อมูลออก

ระยะทางรวมที่สั้นที่สุด ถ้าไม่มีร้านค้าเลย ให้ตอบ 0
