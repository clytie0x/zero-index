หลังฝนตกหนัก สวนสาธารณะที่แบ่งเป็นตาราง R แถว C คอลัมน์มีน้ำท่วมขังบางช่อง น้องจะเดินจากช่องมุมซ้ายบนไปช่องมุมขวาล่าง ก้าวหนึ่งเดินไปช่องทางขวาหรือช่องข้างล่างที่ติดกันเท่านั้น และห้ามเหยียบช่องที่น้ำท่วม ให้นับว่ามีเส้นทางกี่เส้น จำนวนอาจใหญ่มาก ให้ตอบเศษจากการหารด้วย 1000000007

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C คั่นด้วยช่องว่าง โดยที่ 1 ≤ R, C ≤ 1000

อีก R บรรทัด แต่ละบรรทัดเป็นข้อความยาว C ตัว ประกอบด้วย . คือช่องที่เดินได้ และ # คือช่องที่น้ำท่วม ช่องมุมซ้ายบนหรือมุมขวาล่างอาจท่วมได้

ข้อมูลออก

จำนวนเส้นทาง mod 1000000007 ถ้าไม่มีเส้นทางเลยให้ตอบ 0
