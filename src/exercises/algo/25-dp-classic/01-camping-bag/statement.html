ชมรมดาราศาสตร์จะไปตั้งแคมป์ดูดาวบนดอย อุปกรณ์ทุกชิ้นต้องแบกขึ้นไปด้วยเป้ใบเดียวที่รับน้ำหนักได้ไม่เกิน W กรัม มีอุปกรณ์ให้เลือก N ชิ้น ชิ้นที่ i หนัก wi กรัม และมีคะแนนความจำเป็น vi แต่ละชิ้นมีอย่างละหนึ่งชิ้น จะเอาไปหรือไม่เอาไปก็ได้ ให้หาคะแนนความจำเป็นรวมที่มากที่สุดที่แบกไปได้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ W คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100 และ 1 ≤ W ≤ 100000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม wi และ vi โดยที่ 1 ≤ wi ≤ 100000 และ 1 ≤ vi ≤ 109

ข้อมูลออก

คะแนนความจำเป็นรวมที่มากที่สุด ถ้าไม่มีชิ้นไหนใส่ได้เลย ให้ตอบ 0
