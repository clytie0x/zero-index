สวนมะม่วงแบ่งเป็นตาราง R แถว C คอลัมน์ ช่องแถว r คอลัมน์ c มีคะแนน ar,c ช่องที่มีมะม่วงสุกเป็นค่าบวก ช่องที่มีรังมดแดงเป็นค่าติดลบ น้องเดินจากช่องมุมซ้ายบนไปช่องมุมขวาล่าง ก้าวหนึ่งไปทางขวา (R) หรือลงล่าง (D) และได้คะแนนของทุกช่องที่เดินผ่าน รวมช่องแรกกับช่องสุดท้าย ให้หาคะแนนรวมที่มากที่สุด และเส้นทางที่ได้คะแนนนั้น

ถ้ามีหลายเส้นทางที่ได้คะแนนมากที่สุดเท่ากัน ให้เลือกเส้นทางที่เมื่อเขียนเป็นข้อความแล้วมาก่อนตามลำดับพจนานุกรม คือเทียบจากตัวอักษรแรก ตัวแรกที่ต่างกัน ข้อความที่เป็น D มาก่อนข้อความที่เป็น R

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C คั่นด้วยช่องว่าง โดยที่ 1 ≤ R, C ≤ 1000 และ R + C ≥ 3

อีก R บรรทัด บรรทัดที่ r มีจำนวนเต็ม C ตัว คือ ar,1 ถึง ar,C โดยที่ -109 ≤ ar,c ≤ 109

ข้อมูลออก

บรรทัดแรกคือคะแนนรวมที่มากที่สุด

บรรทัดที่สองคือเส้นทาง เป็นข้อความยาว R + C - 2 ตัว ประกอบด้วย D กับ R
