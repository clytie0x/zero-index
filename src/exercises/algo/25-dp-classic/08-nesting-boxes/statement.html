ร้านของขวัญมีกล่องกระดาษ N ใบ ใบที่ i มีฐานกว้าง wi มิลลิเมตร ยาว hi มิลลิเมตร ทุกใบสูงเท่ากันและเปิดฝาด้านบน กล่อง A ใส่ลงในกล่อง B ได้เมื่อ wA < wB และ hA < hB ทั้งคู่ กล่องมีลายด้านหน้าจึงห้ามหมุนสลับด้านกว้างกับด้านยาว ร้านอยากซ้อนกล่องเป็นชุดเดียวให้ได้มากใบที่สุด แบบที่ใบเล็กอยู่ในใบใหญ่กว่าต่อกันเป็นชั้นๆ ให้หาว่าซ้อนได้มากที่สุดกี่ใบ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 100000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม wi และ hi โดยที่ 1 ≤ wi, hi ≤ 109 กล่องสองใบอาจมีขนาดเท่ากัน

ข้อมูลออก

จำนวนกล่องที่ซ้อนกันได้มากที่สุด
