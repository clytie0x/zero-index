ช่างประปาวางท่อเหล็ก N ท่อนเรียงต่อกันเป็นแถว ท่อนที่ i ยาว ai เซนติเมตร ต้องเชื่อมทั้งหมดให้เป็นท่อยาวท่อนเดียวโดยไม่สลับลำดับ เชื่อมได้ทีละครั้ง ครั้งหนึ่งเชื่อมท่อสองท่อนที่อยู่ติดกันในแถวให้เป็นท่อนเดียว ค่าแก๊สของการเชื่อมครั้งนั้นเท่ากับความยาวรวมของสองท่อนนั้น ท่อที่เชื่อมแล้วนำไปเชื่อมต่อได้อีก ให้หาค่าแก๊สรวมที่น้อยที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 500

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ a1 ถึง aN โดยที่ 1 ≤ ai ≤ 106

ข้อมูลออก

ค่าแก๊สรวมที่น้อยที่สุด ถ้ามีท่อท่อนเดียวไม่ต้องเชื่อม ให้ตอบ 0
