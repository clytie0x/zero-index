ร้านกาแฟจดกำไรรายวัน N วัน วันที่ขาดทุนจดเป็นค่าติดลบ เจ้าของร้านตั้งเป้าว่ากำไรรวมของช่วงวันติดกันที่ถือว่า "ปกติ" ต้องอยู่ระหว่าง L ถึง R บาท ให้นับว่ามีกี่ช่วงวันติดกันที่กำไรรวมอยู่ในเกณฑ์นี้ ช่วงวันคือคู่ l กับ r ที่ 1 ≤ l ≤ r ≤ N และกำไรรวมคือ al + al+1 + ... + ar ช่วงที่ l หรือ r ต่างกันนับเป็นคนละช่วง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N L และ R คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ -1015 ≤ L ≤ R ≤ 1015

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ a1 ถึง aN โดยที่ -109 ≤ ai ≤ 109

ข้อมูลออก

จำนวนช่วงวันที่กำไรรวมอยู่ระหว่าง L ถึง R รวมทั้งสองค่า
