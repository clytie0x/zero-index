น้องจดราคาปิดของทองคำแท่งหนึ่งบาทติดต่อกัน N วัน วันที่ i ราคา ai บาท น้องอยากรู้ว่าตลาดผันผวนแค่ไหน จึงนับว่ามีกี่คู่วัน i < j ที่ราคาวันหลังต่ำกว่าวันก่อนเกิน D บาท หรือก็คือ ai - aj > D วันสองวันไม่จำเป็นต้องติดกัน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ D คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 0 ≤ D ≤ 109

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ a1 ถึง aN โดยที่ 1 ≤ ai ≤ 109

ข้อมูลออก

จำนวนคู่วันที่ราคาลดลงเกิน D บาท
