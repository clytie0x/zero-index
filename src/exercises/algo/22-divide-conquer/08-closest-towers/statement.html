บริษัทโทรคมนาคมมีเสาสัญญาณ N ต้นบนแผนที่ ต้นที่ i อยู่ที่พิกัด (xi, yi) เสาสองต้นที่อยู่ใกล้กันมากจะรบกวนกัน วิศวกรจึงต้องการรู้ระยะห่างของคู่เสาที่อยู่ใกล้กันที่สุด เพื่อไม่ให้มีปัญหาเรื่องทศนิยม ให้ตอบเป็น กำลังสองของระยะทาง คือ (xi - xj)2 + (yi - yj)2 ที่น้อยที่สุดในบรรดาทุกคู่ i ≠ j เสาสองต้นอาจอยู่ที่พิกัดเดียวกันได้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 2 ≤ N ≤ 200000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม xi และ yi คั่นด้วยช่องว่าง โดยที่ -109 ≤ xi, yi ≤ 109

ข้อมูลออก

กำลังสองของระยะทางระหว่างคู่เสาที่ใกล้กันที่สุด
