น้องตั้งกติกาออมเงินกับตัวเองแบบทวีคูณ วันแรกหยอดกระปุก 1 บาท ทุกวันถัดไปหยอดเป็น a เท่าของวันก่อนหน้า วันที่ 1 จึงหยอด 1 บาท วันที่ 2 หยอด a บาท วันที่ 3 หยอด a2 บาท ไปเรื่อยๆ ถ้าทำครบ n วัน ในกระปุกจะมี 1 + a + a2 + ... + an-1 บาท

ตัวเลขนี้ใหญ่มาก จึงขอแค่เศษจากการหารด้วย m มีคำถามทั้งหมด T ข้อ แต่ละข้อมี a n และ m ของตัวเอง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม T โดยที่ 1 ≤ T ≤ 100

อีก T บรรทัด บรรทัดละหนึ่งคำถาม มีจำนวนเต็ม a n และ m คั่นด้วยช่องว่าง โดยที่ 1 ≤ a ≤ 109 และ 1 ≤ n ≤ 1018 และ 1 ≤ m ≤ 109 (m ไม่จำเป็นต้องเป็นจำนวนเฉพาะ)

ข้อมูลออก

T บรรทัด ตอบตามลำดับคำถาม บรรทัดละหนึ่งค่า คือ (1 + a + a2 + ... + an-1) mod m
