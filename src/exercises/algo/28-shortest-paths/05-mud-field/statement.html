ทุ่งนาหลังฝนตกแบ่งเป็นตาราง R แถว C คอลัมน์ ช่องที่ยังเดินได้มีตัวเลขบอกแรงที่ต้องใช้เมื่อก้าวเข้าไปในช่องนั้น ยิ่งโคลนลึกยิ่งใช้แรงมาก ส่วนช่องที่เป็นบ่อน้ำเดินเข้าไปไม่ได้ ชาวนาอยู่ที่ช่องซ้ายบน ต้องไปที่ช่องขวาล่าง ก้าวได้ทีละช่องไปทางบน ล่าง ซ้าย หรือขวา แรงที่ใช้ทั้งหมดคือผลรวมของตัวเลขในทุกช่องที่ก้าวเข้าไป รวมช่องซ้ายบนที่ยืนอยู่ตอนเริ่มด้วย ถ้าเดินผ่านช่องเดิมซ้ำก็ต้องใช้แรงซ้ำ ให้หาแรงรวมที่น้อยที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C คั่นด้วยช่องว่าง โดยที่ 1 ≤ R, C ≤ 500

อีก R บรรทัด บรรทัดละ C จำนวน คั่นด้วยช่องว่าง แต่ละจำนวนเป็น -1 ถ้าช่องนั้นเป็นบ่อน้ำ หรือเป็นจำนวนเต็มตั้งแต่ 1 ถึง 109 ซึ่งคือแรงที่ใช้เมื่อก้าวเข้าช่องนั้น

ข้อมูลออก

แรงรวมที่น้อยที่สุด ถ้าไปถึงช่องขวาล่างไม่ได้ หรือช่องซ้ายบนหรือขวาล่างเป็นบ่อน้ำ ให้พิมพ์ -1 ถ้าตารางมีช่องเดียว คำตอบคือตัวเลขของช่องนั้น
