ร้านชานมไข่มุกมี N สาขาเรียงตามถนนเส้นเดียว หมายเลข 1 ถึง N ระบบหลังร้านเก็บยอดขายวันนี้ของทุกสาขา ระหว่างวันมีเหตุการณ์ Q ครั้งเรียงตามเวลา แต่ละครั้งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • 1 i v สาขาที่ i ส่งยอดขายล่าสุดมา ยอดขายของสาขานี้ กลายเป็น v บาท (ไม่ใช่บวกเพิ่ม v)
  • 2 l r ผู้จัดการเขตถามว่าสาขาที่ l ถึง r รวมกันขายได้กี่บาท

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือยอดขายตอนเริ่มของสาขาที่ 1 ถึง N แต่ละตัวอยู่ระหว่าง 0 ถึง 109

อีก Q บรรทัด บรรทัดละหนึ่งเหตุการณ์ในรูปแบบข้างบน โดยที่ 1 ≤ i ≤ N, 0 ≤ v ≤ 109 และ 1 ≤ l ≤ r ≤ N

ข้อมูลออก

ทุกเหตุการณ์แบบ 2 ให้พิมพ์ยอดขายรวมหนึ่งบรรทัด
