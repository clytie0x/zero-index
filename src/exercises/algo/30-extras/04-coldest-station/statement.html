กรมอุตุนิยมวิทยาตั้งสถานีวัดอุณหภูมิไว้ N สถานีเรียงตามแนวเทือกเขา หมายเลข 1 ถึง N แต่ละสถานีรายงานอุณหภูมิล่าสุดเป็นจำนวนเต็มองศาเซลเซียส ซึ่งติดลบได้ ระหว่างคืนมีเหตุการณ์ Q ครั้งเรียงตามเวลา แต่ละครั้งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • 1 i t สถานีที่ i รายงานอุณหภูมิใหม่ เป็น t องศา
  • 2 l r นักข่าวถามว่า ตอนนี้สถานีที่ l ถึง r อุณหภูมิต่ำสุดเท่าไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คืออุณหภูมิตอนเริ่มของสถานีที่ 1 ถึง N

อีก Q บรรทัด บรรทัดละหนึ่งเหตุการณ์ในรูปแบบข้างบน โดยที่ 1 ≤ i ≤ N และ 1 ≤ l ≤ r ≤ N อุณหภูมิทุกค่าอยู่ระหว่าง -1000000000 ถึง 1000000000 (โจทย์ตั้งให้กว้างเพื่อฝึกเลือกค่าเริ่มต้นของค่าต่ำสุด)

ข้อมูลออก

ทุกเหตุการณ์แบบ 2 ให้พิมพ์อุณหภูมิต่ำสุดหนึ่งบรรทัด
