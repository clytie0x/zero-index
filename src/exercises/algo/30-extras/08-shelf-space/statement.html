โกดังของร้านหนังสือออนไลน์มีชั้นวาง N ชั้นเรียงจากหน้าโกดังไปหลังโกดัง หมายเลข 1 ถึง N ชั้นที่ i มีที่ว่างเหลือ ci เซนติเมตร กล่องพัสดุเข้ามา Q กล่องตามลำดับ กล่องที่ j หนา xj เซนติเมตร พนักงานเดินเข้าไปจากหน้าโกดัง แล้ววางกล่องบนชั้นแรกที่เจอซึ่งยังมีที่ว่างอย่างน้อย xj เซนติเมตร วางแล้วที่ว่างของชั้นนั้นลดลง xj ถ้าไม่มีชั้นไหนมีที่พอ กล่องนั้นถูกส่งไปโกดังอื่น และไม่มีชั้นไหนเปลี่ยน

ให้บอกว่าแต่ละกล่องถูกวางบนชั้นไหน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ c1 ถึง cN โดยที่ 0 ≤ ci ≤ 109

บรรทัดที่สามมีจำนวนเต็ม Q ตัว คือ x1 ถึง xQ โดยที่ 1 ≤ xj ≤ 109

ข้อมูลออก

Q บรรทัด บรรทัดที่ j เป็นหมายเลขชั้นที่วางกล่องที่ j หรือ 0 ถ้ากล่องนั้นถูกส่งไปโกดังอื่น
