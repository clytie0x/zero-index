โฮสเทลริมทะเลเปิดให้จองห้องพักล่วงหน้า N คืน หมายเลขคืนที่ 1 ถึง N ระบบจองออนไลน์รับเหตุการณ์ Q ครั้งเรียงตามเวลา แต่ละครั้งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • 1 l r g มีการจองใหม่ แขก g คนพักตั้งแต่คืนที่ l ถึงคืนที่ r รวมทั้งสองคืนนั้น
  • 2 i พนักงานถามว่า ตามการจองที่เข้ามาถึงตอนนี้ คืนที่ i มีแขกพักกี่คน

หน้า 19.5 ตอบคำถามแบบนี้ได้เมื่อการจองเข้ามาครบก่อนแล้วค่อยถาม แต่ข้อนี้คำถามแทรกอยู่ระหว่างการจอง และต้องตอบทันทีตามการจองที่มีอยู่ ณ ตอนที่ถาม

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 200000

อีก Q บรรทัด บรรทัดละหนึ่งเหตุการณ์ในรูปแบบข้างบน โดยที่ 1 ≤ l ≤ r ≤ N, 1 ≤ g ≤ 109 และ 1 ≤ i ≤ N

ข้อมูลออก

ทุกเหตุการณ์แบบ 2 ให้พิมพ์จำนวนแขกหนึ่งบรรทัด
