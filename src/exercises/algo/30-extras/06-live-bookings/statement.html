โฮสเทลริมทะเลเปิดให้จองห้องพักล่วงหน้า N คืน หมายเลขคืนที่ 1 ถึง N ทุกคืนต้องจ่ายค่าทำความสะอาดตามจำนวนแขกที่พักคืนนั้น ระบบจองออนไลน์รับเหตุการณ์ Q ครั้งเรียงตามเวลา แต่ละครั้งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • 1 l r g มีการจองใหม่ แขก g คนพักตั้งแต่คืนที่ l ถึงคืนที่ r รวมทั้งสองคืนนั้น
  • 2 l r ฝ่ายบัญชีถามว่า ตามการจองที่เข้ามาถึงตอนนี้ คืนที่ l ถึงคืนที่ r รวมกันมีแขกพักกี่คนคืน คือนำจำนวนแขกของแต่ละคืนในช่วงนั้นมาบวกกัน

คำถามแทรกอยู่ระหว่างการจอง และต้องตอบทันทีตามการจองที่มีอยู่ ณ ตอนที่ถาม

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 200000

อีก Q บรรทัด บรรทัดละหนึ่งเหตุการณ์ในรูปแบบข้างบน โดยที่ 1 ≤ l ≤ r ≤ N และ 1 ≤ g ≤ 10000

ข้อมูลออก

ทุกเหตุการณ์แบบ 2 ให้พิมพ์จำนวนแขกรวมของช่วงนั้นหนึ่งบรรทัด
