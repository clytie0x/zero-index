ร้านขนมเขียนสูตรเค้กไว้ N ขั้นตอน หมายเลข 1 ถึง N บางขั้นต้องรอขั้นอื่นเสร็จก่อน เช่น ต้องร่อนแป้งก่อนผสม ต้องอบก่อนแต่งหน้า เงื่อนไขมีทั้งหมด M ข้อ ข้อหนึ่งเขียนเป็นคู่ a b แปลว่าต้องทำขั้น a ให้เสร็จก่อนเริ่มขั้น b

พ่อครัวทำทีละขั้น ทุกครั้งที่จะเริ่มขั้นใหม่ เขาเลือกขั้นที่ หมายเลขน้อยที่สุด ในบรรดาขั้นที่ยังไม่ได้ทำและทุกขั้นที่ต้องรอเสร็จหมดแล้ว ให้หาลำดับที่พ่อครัวจะทำ ถ้าสูตรเขียนเงื่อนไขวนกันจนทำครบทุกขั้นไม่ได้ ให้ตอบ -1

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ M คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 0 ≤ M ≤ 200000

อีก M บรรทัด บรรทัดละสองจำนวน a และ b โดยที่ 1 ≤ a, b ≤ N และ a ≠ b เงื่อนไขเดียวกันอาจเขียนซ้ำได้

ข้อมูลออก

บรรทัดเดียว เป็นหมายเลขขั้นตอนตามลำดับที่ทำ คั่นด้วยช่องว่าง หรือ -1 ถ้าทำครบไม่ได้
