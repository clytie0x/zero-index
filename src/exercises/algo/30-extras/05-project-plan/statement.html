ชมรมหุ่นยนต์ของโรงเรียนแตกงานสร้างหุ่นยนต์แข่งออกเป็น N งาน หมายเลข 1 ถึง N งานที่ i ใช้เวลา di วัน บางงานต้องรอให้งานอื่นเสร็จก่อนจึงเริ่มได้ เช่น ต้องออกแบบโครงก่อนตัดโลหะ เงื่อนไขมี M ข้อ ข้อหนึ่งเป็นคู่ a b แปลว่างาน b เริ่มได้หลังจากงาน a เสร็จแล้วเท่านั้น

ชมรมมีสมาชิกมากพอ งานที่เงื่อนไขครบแล้วเริ่มพร้อมกันได้ทันทีกี่งานก็ได้ ถ้าเริ่มวันแรกพร้อมกัน ทั้งโครงการจะเสร็จเร็วที่สุดเมื่อผ่านไปกี่วัน รับประกันว่าเงื่อนไขไม่วนกัน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ M คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 0 ≤ M ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ d1 ถึง dN โดยที่ 1 ≤ di ≤ 109

อีก M บรรทัด บรรทัดละสองจำนวน a และ b โดยที่ 1 ≤ a, b ≤ N และ a ≠ b

ข้อมูลออก

จำนวนวันที่น้อยที่สุดที่ทำครบทุกงาน
