ร้านเครื่องเขียนหน้าโรงเรียนจดกำไรรายวันไว้ N วัน วันที่ i ได้กำไร ai บาท วันไหนขาดทุนจะจดเป็นค่าติดลบ เจ้าของร้านอยากรู้ว่าช่วงวันติดกันช่วงไหนที่กำไรรวมมากที่สุด ช่วงต้องมีอย่างน้อยหนึ่งวัน

ถ้ามีหลายช่วงที่กำไรรวมเท่ากัน ให้ตอบช่วงที่เริ่มเร็วที่สุด ถ้ายังเริ่มวันเดียวกัน ให้ตอบช่วงที่จบเร็วที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ a1 ถึง aN โดยที่ -109 ≤ ai ≤ 109

ข้อมูลออก

บรรทัดแรกคือกำไรรวมที่มากที่สุด บรรทัดที่สองคือวันเริ่มและวันจบของช่วงนั้น คั่นด้วยช่องว่าง
