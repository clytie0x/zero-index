ริมบึงมีก้อนหินวางเรียงเป็นแถวตรง N ก้อน เรียกว่าก้อนที่ 1 ถึง N กบตัวหนึ่งเริ่มอยู่บนฝั่ง ซึ่งนับเป็นตำแหน่ง 0 แต่ละครั้งกบกระโดดไปข้างหน้าได้ 1 2 หรือ 3 ก้อน และไม่เคยกระโดดถอยหลัง กบต้องไปหยุดที่ก้อนที่ N พอดี ถามว่ากบมีวิธีกระโดดกี่วิธี สองวิธีถือว่าต่างกันถ้าลำดับระยะที่กระโดดต่างกัน เช่น 1 แล้ว 3 กับ 3 แล้ว 1 เป็นคนละวิธี

คำตอบอาจใหญ่มาก ให้ตอบเป็นเศษจากการหารด้วย 1000000007

ข้อมูลเข้า

บรรทัดเดียว มีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000000

ข้อมูลออก
