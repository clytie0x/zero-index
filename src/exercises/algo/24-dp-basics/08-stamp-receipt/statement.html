ร้านไปรษณีย์มีแสตมป์ N แบบ แบบที่ i ราคา pi บาท แต่ละแบบมีกี่ดวงก็ได้ ลูกค้าต้องติดแสตมป์ให้ราคารวมพอดี X บาท ใช้น้อยดวงที่สุด และพนักงานต้องพิมพ์ใบเสร็จบอกว่าใช้แสตมป์ราคาอะไรบ้าง

ใบเสร็จเรียงราคาจากมากไปน้อย ถ้ามีหลายชุดที่ใช้จำนวนดวงน้อยที่สุดเท่ากัน ให้เทียบใบเสร็จของแต่ละชุดทีละตำแหน่งจากซ้าย แล้วเลือกชุดที่ตำแหน่งแรกที่ต่างกันมีราคามากกว่า เช่น ราคา 4 บาทด้วยแสตมป์ 1 2 3 บาท ใช้ 2 ดวงได้ทั้ง 3 1 และ 2 2 ต้องตอบ 3 1

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ X คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100 และ 1 ≤ X ≤ 100000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ p1 ถึง pN ไม่ซ้ำกันและไม่ได้เรียงมา โดยที่ 1 ≤ pi ≤ 100000

ข้อมูลออก

ถ้าติดให้ราคาพอดี X บาทไม่ได้ ให้พิมพ์ -1 บรรทัดเดียว
