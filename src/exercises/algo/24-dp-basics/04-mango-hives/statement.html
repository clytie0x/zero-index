สวนมะม่วงของโรงเรียนปลูกต้นมะม่วงเรียงเป็นแถวเดียว N ต้น ต้นที่ i มีผลสุก ai ลูก นักเรียนจะเขย่าต้นมะม่วงเพื่อเก็บผล เขย่าต้นไหนก็ได้ผลสุกของต้นนั้นทั้งหมด แต่ต้นที่ปลูกติดกันมีรังผึ้งเกาะกิ่งที่พันกันอยู่ ถ้าเขย่าสองต้นที่ติดกัน ผึ้งจะแตกรัง จึงห้ามเขย่าต้นที่ i กับต้นที่ i + 1 ทั้งคู่ ให้หาว่าเก็บมะม่วงได้มากที่สุดกี่ลูก

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ a1 ถึง aN โดยที่ 0 ≤ ai ≤ 109

ข้อมูลออก

จำนวนมะม่วงที่เก็บได้มากที่สุด
