บันไดขึ้นจุดชมวิวมี N ขั้น เรียกว่าขั้นที่ 1 ถึง N แต่ละขั้นสูงไม่เท่ากัน ขั้นที่ i ทำให้เหนื่อย ci หน่วยเมื่อเหยียบ น้องเริ่มยืนที่พื้น ซึ่งไม่ทำให้เหนื่อย แต่ละก้าวขึ้นได้ 1 หรือ 2 ขั้น และต้องไปหยุดที่ขั้นที่ N ซึ่งต้องเหยียบด้วย ความเหนื่อยรวมคือผลรวมของ ci ทุกขั้นที่เหยียบ ให้หาความเหนื่อยรวมที่น้อยที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ c1 ถึง cN โดยที่ 0 ≤ ci ≤ 109

ข้อมูลออก

ความเหนื่อยรวมที่น้อยที่สุด
