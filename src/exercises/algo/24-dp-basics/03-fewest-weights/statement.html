ห้องแล็บวิทยาศาสตร์มีตุ้มน้ำหนักสำหรับตาชั่งสองแขน N แบบ แบบที่ i หนัก wi กรัม แต่ละแบบมีมากพอที่จะใช้กี่ลูกก็ได้ ครูต้องการวางตุ้มบนจานข้างเดียวให้หนักรวมพอดี X กรัม โดยใช้ตุ้มน้อยลูกที่สุด ให้หาว่าต้องใช้กี่ลูก ถ้าวางให้หนักพอดี X กรัมไม่ได้เลย ให้ตอบ -1

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ X คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100 และ 1 ≤ X ≤ 100000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ w1 ถึง wN ไม่ซ้ำกัน โดยที่ 1 ≤ wi ≤ 100000

ข้อมูลออก

จำนวนตุ้มที่น้อยที่สุด หรือ -1 ถ้าทำไม่ได้
