หอพักนักเรียนมีนักเรียน N คน หมายเลข 1 ถึง N และมีเพื่อนสนิทกัน M คู่ เป็นเพื่อนกันทั้งสองทาง วันที่ 0 นักเรียนหมายเลข S ได้ยินข่าวลือเรื่องหนึ่ง ทุกวันหลังจากนั้น ทุกคนที่รู้ข่าวแล้วจะเล่าให้เพื่อนสนิททุกคนของตัวเองฟัง คนที่ได้ฟังในวันที่ d จะเริ่มเล่าต่อในวันที่ d + 1

ให้หาว่าสุดท้ายแล้วมีนักเรียนรู้ข่าวนี้กี่คน นับ S ด้วย และคนสุดท้ายที่รู้ข่าวได้ฟังในวันที่เท่าไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N M และ S คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000, 0 ≤ M ≤ 200000 และ 1 ≤ S ≤ N

อีก M บรรทัด แต่ละบรรทัดมีจำนวนเต็ม a และ b แปลว่า a กับ b เป็นเพื่อนสนิทกัน โดยที่ a ≠ b และไม่มีคู่ไหนซ้ำ

ข้อมูลออก

บรรทัดเดียว มีจำนวนคนที่รู้ข่าว และวันที่คนสุดท้ายได้ฟัง คั่นด้วยช่องว่าง ถ้าไม่มีใครได้ฟังต่อจาก S เลย วันนั้นคือ 0
