โรงเรียนจะแบ่งนักเรียน N คน หมายเลข 1 ถึง N เป็นสองสีสำหรับงานกีฬาสี คือสีแดงกับสีน้ำเงิน ทุกคนต้องอยู่สีใดสีหนึ่งพอดี ครูมีรายชื่อคู่ที่ห้ามอยู่สีเดียวกัน M คู่ เพราะเป็นคู่แข่งกันในรายการเดียวกัน นอกจากนี้ยังมีนักกีฬาตัวแทน K คนที่ลงทะเบียนสีไว้กับเขตการศึกษาแล้ว เปลี่ยนสีไม่ได้

ชุดกีฬาสีแดงเหลือน้อย ครูจึงอยากให้สีแดงมีคนน้อยที่สุดเท่าที่ทำได้ โดยยังไม่ผิดเงื่อนไขของคู่ใดเลย และนักกีฬาตัวแทนทุกคนได้สีที่ลงทะเบียนไว้ ให้หาว่าสีแดงมีคนน้อยที่สุดได้กี่คน หรือบอกว่าแบ่งไม่ได้เลย

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N M และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000, 0 ≤ M ≤ 200000 และ 0 ≤ K ≤ N

อีก M บรรทัด แต่ละบรรทัดมีจำนวนเต็ม a และ b แปลว่า a กับ b ห้ามอยู่สีเดียวกัน โดยที่ a ≠ b และไม่มีคู่ไหนซ้ำ

อีก K บรรทัด แต่ละบรรทัดมีหมายเลขนักกีฬาตัวแทน ตามด้วยตัวอักษร R ถ้าลงทะเบียนสีแดง หรือ B ถ้าลงทะเบียนสีน้ำเงิน คั่นด้วยช่องว่าง ไม่มีใครลงทะเบียนซ้ำ
