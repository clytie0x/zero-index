ภาพถ่ายดาวเทียมของหมู่เกาะแห่งหนึ่งแปลงเป็นแผนที่ R แถว C คอลัมน์ ช่อง # เป็นแผ่นดิน ช่อง . เป็นน้ำ แผ่นดินสองช่องอยู่บนเกาะเดียวกันถ้าเดินจากช่องหนึ่งไปอีกช่องได้ โดยก้าวทีละช่องไปทางบน ล่าง ซ้าย หรือขวา และเหยียบแต่แผ่นดิน ช่องที่แตะกันแค่มุมแบบทแยงไม่นับว่าติดกัน เกาะมีรูปร่างแบบไหนก็ได้ และอาจมีทะเลสาบอยู่ข้างใน

ให้นับว่ามีเกาะกี่เกาะ และเกาะที่ใหญ่ที่สุดมีแผ่นดินกี่ช่อง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C คั่นด้วยช่องว่าง โดยที่ 1 ≤ R, C ≤ 1000

อีก R บรรทัด บรรทัดละ C ตัวอักษรติดกัน แต่ละตัวเป็น # หรือ .

ข้อมูลออก

บรรทัดเดียว มีจำนวนเกาะ และจำนวนช่องของเกาะที่ใหญ่ที่สุด คั่นด้วยช่องว่าง ถ้าไม่มีแผ่นดินเลยให้พิมพ์ 0 0
