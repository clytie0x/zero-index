เกมทายสัตว์เก็บคำถามไว้เป็น binary tree มี N โหนด หมายเลข 1 ถึง N แต่ละโหนดมีลูกซ้าย (ตอบใช่) และลูกขวา (ตอบไม่ใช่) ได้อย่างละไม่เกินหนึ่ง ผู้พัฒนาเกมอยากตรวจว่าเก็บต้นไม้ถูกไหม จึงอยากได้หมายเลขโหนดเรียงตามลำดับ preorder inorder และ postorder

ข้อมูลเข้าไม่ได้บอกว่าโหนดไหนเป็นราก รากคือโหนดเดียวที่ไม่ได้เป็นลูกของโหนดใด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

อีก N บรรทัด บรรทัดที่ v มีจำนวนเต็มสองตัว คือหมายเลขลูกซ้ายและลูกขวาของโหนด v ถ้าไม่มีลูกทางนั้นจะเป็น 0 ข้อมูลเป็น binary tree เสมอ

ข้อมูลออก

สามบรรทัด บรรทัดแรกคือหมายเลขโหนดตามลำดับ preorder บรรทัดที่สองตามลำดับ inorder บรรทัดที่สามตามลำดับ postorder แต่ละบรรทัดคั่นหมายเลขด้วยช่องว่างหนึ่งช่อง
