หมู่บ้านแห่งหนึ่งทำแผนผังเครือญาติย้อนไปถึงต้นตระกูลคนเดียว ทุกคนในแผนผังมีหมายเลข 1 ถึง N และทุกคนยกเว้นต้นตระกูลมีพ่อหรือแม่ในแผนผังหนึ่งคน ต้นตระกูลเป็นรุ่นที่ 0 ลูกของต้นตระกูลเป็นรุ่นที่ 1 หลานเป็นรุ่นที่ 2 ไปเรื่อยๆ ให้นับว่าแต่ละรุ่นมีกี่คน

แผนผังบางสายสืบต่อกันยาวมาก จำนวนรุ่นจึงอาจมากถึง N

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว ตัวที่ i คือหมายเลขพ่อหรือแม่ของคนที่ i ต้นตระกูลมีค่านี้เป็น 0 มีต้นตระกูลคนเดียวพอดี และข้อมูลเป็นต้นไม้เสมอ

ข้อมูลออก

บรรทัดเดียว ถ้ารุ่นที่ลึกที่สุดคือรุ่นที่ H ให้พิมพ์จำนวนเต็ม H + 1 ตัว ตัวที่ k (เริ่มนับที่ 0) คือจำนวนคนในรุ่นที่ k คั่นด้วยช่องว่างหนึ่งช่อง
