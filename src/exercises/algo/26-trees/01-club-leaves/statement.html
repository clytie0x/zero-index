ชมรมดาราศาสตร์มีสมาชิก N คน หมายเลข 1 ถึง N ทุกคนยกเว้นประธานมีหัวหน้าทีมโดยตรงหนึ่งคน ผังของชมรมจึงเป็นต้นไม้ที่มีประธานเป็นราก ประธานไม่จำเป็นต้องเป็นคนหมายเลข 1

ชมรมอยากรู้สองอย่าง อย่างแรก มีสมาชิกกี่คนที่ไม่มีลูกทีมเลย คือไม่ได้เป็นหัวหน้าโดยตรงของใคร อย่างที่สอง ผังมีกี่ชั้น นับเป็นจำนวนทอดจากประธานลงไปถึงสมาชิกที่อยู่ลึกที่สุด ประธานอยู่ลึก 0 ลูกทีมโดยตรงของประธานอยู่ลึก 1 ไปเรื่อยๆ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

บรรทัดที่สองมีจำนวนเต็ม N ตัว ตัวที่ i คือหมายเลขหัวหน้าโดยตรงของสมาชิกคนที่ i ประธานมีค่านี้เป็น 0 มีประธานคนเดียวพอดี และข้อมูลเป็นต้นไม้เสมอ

ข้อมูลออก

บรรทัดแรกพิมพ์จำนวนสมาชิกที่ไม่มีลูกทีม บรรทัดที่สองพิมพ์ความลึกที่มากที่สุด
