ห้องสมุดเก็บรหัสหนังสือไว้ใน binary search tree ตามหน้า 26.4 เริ่มจากต้นไม้ว่าง แล้วทำคำสั่ง Q คำสั่งตามลำดับ

  • + x ใส่รหัส x ด้วยการเดินลงจากราก x น้อยกว่าคีย์ของโหนดไปซ้าย มากกว่าไปขวา จนเจอที่ว่าง แล้วแขวนโหนดใหม่ไว้ตรงนั้น รับประกันว่า x ยังไม่มีในต้นไม้
  • - x ลบรหัส x ซึ่งรับประกันว่ามีอยู่ ถ้าโหนดนั้นไม่มีลูกให้ลบทิ้ง ถ้ามีลูกตัวเดียวให้ลูกขึ้นมาแทนที่ ถ้ามีลูกสองตัว ให้หาคีย์ที่น้อยที่สุดในต้นไม้ย่อยขวาของมัน ลอกคีย์นั้นมาใส่โหนดนี้ แล้วลบคีย์นั้นออกจากต้นไม้ย่อยขวาด้วยกติกาเดียวกัน
  • ? x พิมพ์ความลึกของโหนดที่มีรหัส x รากลึก 0 ถ้าไม่มีรหัสนี้ในต้นไม้ให้พิมพ์ -1

ทำครบทุกคำสั่งแล้ว ให้พิมพ์รหัสทั้งหมดในต้นไม้ตามลำดับ preorder

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 5000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน โดยที่ 1 ≤ x ≤ 109

ข้อมูลออก

ทุกคำสั่ง ? ให้พิมพ์คำตอบหนึ่งบรรทัดตามลำดับ บรรทัดสุดท้ายคือรหัสตามลำดับ preorder คั่นด้วยช่องว่างหนึ่งช่อง ถ้าต้นไม้ว่างให้พิมพ์ empty
