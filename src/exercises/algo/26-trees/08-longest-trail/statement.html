อุทยานแห่งหนึ่งมีจุดพัก N จุด หมายเลข 1 ถึง N เชื่อมกันด้วยทางเดินป่า N - 1 เส้น จากจุดหนึ่งไปอีกจุดหนึ่งมีทางเดียวเสมอ ผังทางเดินจึงเป็นต้นไม้ อุทยานเก็บผังไว้โดยเลือกจุดหนึ่งเป็นศูนย์บริการ แล้วบอกว่าจุดอื่นแต่ละจุดต่อกับจุดถัดไปทางศูนย์บริการจุดไหน และทางเดินช่วงนั้นยาวกี่เมตร

อุทยานจะจัดงานวิ่งเทรลจากจุดพักหนึ่งไปอีกจุดพักหนึ่งตามทางเดินที่มี และอยากได้เส้นทางที่ยาวที่สุดเท่าที่เป็นไปได้ จุดเริ่มและจุดจบเป็นจุดไหนก็ได้ ไม่จำเป็นต้องผ่านศูนย์บริการ ให้หาความยาวของเส้นทางนั้น

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว ตัวที่ i คือหมายเลขจุดถัดไปทางศูนย์บริการของจุดที่ i ศูนย์บริการมีค่านี้เป็น 0 มีศูนย์บริการจุดเดียวพอดี และข้อมูลเป็นต้นไม้เสมอ

บรรทัดที่สามมีจำนวนเต็ม N ตัว ตัวที่ i คือความยาวเป็นเมตรของทางเดินจากจุดที่ i ไปยังจุดถัดไปทางศูนย์บริการ ของศูนย์บริการเป็น 0 ของจุดอื่นอยู่ระหว่าง 1 ถึง 109
