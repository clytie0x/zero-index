ระบบลงทะเบียนวิ่งมาราธอนเก่าเครื่องหนึ่งเก็บหมายเลขนักวิ่งไว้ใน binary search tree ที่ไม่ปรับสมดุล แบบเดียวกับหน้า 26.4 เริ่มจากต้นไม้ว่าง แล้วใส่หมายเลขนักวิ่ง N คนตามลำดับที่มาลงทะเบียน การใส่ x คือเดินลงจากราก x น้อยกว่าคีย์ของโหนดไปซ้าย มากกว่าไปขวา จนเจอที่ว่าง แล้วแขวนโหนดใหม่ไว้ตรงนั้น หมายเลขไม่ซ้ำกัน

ผู้ดูแลระบบสงสัยว่าทำไมบางวันระบบช้ามาก จึงอยากรู้ว่านักวิ่งแต่ละคนถูกแขวนไว้ที่ความลึกเท่าไร รากลึก 0

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือหมายเลขนักวิ่งตามลำดับที่ใส่ ไม่ซ้ำกัน และอยู่ระหว่าง 1 ถึง 109

ข้อมูลออก

บรรทัดเดียว มีจำนวนเต็ม N ตัว ตัวที่ i คือความลึกของนักวิ่งคนที่ i ตอนที่ถูกใส่ คั่นด้วยช่องว่างหนึ่งช่อง
