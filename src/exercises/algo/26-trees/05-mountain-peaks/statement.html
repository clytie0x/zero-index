อุทยานแห่งชาติมีจุดชมวิว N จุด หมายเลข 1 ถึง N เชื่อมกันด้วยทางเดินเป็นต้นไม้ จุดหนึ่งเป็นทางเข้าอุทยาน ทุกจุดอื่นมีจุดก่อนหน้าหนึ่งจุดซึ่งอยู่ใกล้ทางเข้ากว่าหนึ่งช่วงทางเดิน จุดที่ i สูงจากระดับน้ำทะเล hi เมตร

นักท่องเที่ยวเดินจากทางเข้าไปยังจุดใดจุดหนึ่งตามทางเดียวที่มี อุทยานจะติดป้ายจุดชมวิวดีเด่นให้จุด v ถ้าจุด v สูงกว่าทุกจุดบนทางจากทางเข้ามาถึง v (ไม่นับ v เอง) อย่างเคร่งครัด ทางเข้าได้ป้ายเสมอ ให้นับว่าต้องทำป้ายกี่ป้าย

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว ตัวที่ i คือหมายเลขจุดก่อนหน้าของจุดที่ i ทางเข้ามีค่านี้เป็น 0 มีทางเข้าจุดเดียวพอดี และข้อมูลเป็นต้นไม้เสมอ

บรรทัดที่สามมีจำนวนเต็ม N ตัว คือ h1 ถึง hN โดยที่ 1 ≤ hi ≤ 109

ข้อมูลออก

จำนวนจุดชมวิวดีเด่น
