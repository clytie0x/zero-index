ครูให้นักเรียนฝึกเขียน max-heap ในอาเรย์ตามหน้า 26.5 แล้วอยากได้โปรแกรมเฉลยที่พิมพ์อาเรย์ออกมาให้เทียบทีละขั้น heap เก็บในอาเรย์ช่อง 1 ถึง K เมื่อ K คือจำนวนค่าในฮีป ลูกของช่อง i คือช่อง 2i และ 2i + 1 พ่อของช่อง i คือช่อง i / 2 ปัดเศษทิ้ง โปรแกรมต้องทำตามกติกานี้ทุกตัวอักษร

  • สร้างฮีป ใส่ค่าเริ่มต้น N ค่าลงช่อง 1 ถึง N ตามลำดับ แล้วจมลงทีละช่อง ตั้งแต่ช่อง N / 2 (ปัดเศษทิ้ง) ย้อนลงมาจนถึงช่อง 1
  • จมลงที่ช่อง i ถ้าช่อง i ไม่มีลูกให้หยุด ไม่งั้นเลือกลูกซ้าย แต่ถ้ามีลูกขวาและลูกขวามากกว่าลูกซ้ายอย่างเคร่งครัดให้เลือกลูกขวาแทน ถ้าค่าที่ช่อง i น้อยกว่าลูกที่เลือกอย่างเคร่งครัด ให้สลับสองช่องนี้แล้วจมลงต่อที่ช่องของลูก ไม่งั้นหยุด
  • ใส่ x ต่อ x ไว้ที่ช่อง K + 1 แล้วลอยขึ้น คือถ้ายังไม่ใช่ช่อง 1 และพ่อน้อยกว่าตัวมันอย่างเคร่งครัด ให้สลับกับพ่อแล้วลอยขึ้นต่อ
  • หยิบออก จดค่าที่ช่อง 1 ไว้ ย้ายค่าที่ช่อง K มาไว้ช่อง 1 ลดขนาดลงหนึ่ง แล้วจมลงที่ช่อง 1 ถ้าฮีปยังไม่ว่าง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 100000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือค่าเริ่มต้นตามลำดับ แต่ละค่าอยู่ระหว่าง 1 ถึง 109

บรรทัดที่สามมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 100000

อีก Q บรรทัด แต่ละบรรทัดเป็นคำสั่ง + x คือใส่ x (1 ≤ x ≤ 109) หรือ - คือหยิบออก รับประกันว่าไม่มีการหยิบออกตอนที่ฮีปว่าง

ข้อมูลออก

บรรทัดแรกคืออาเรย์หลังสร้างฮีป ช่อง 1 ถึง N คั่นด้วยช่องว่างหนึ่งช่อง

ทุกคำสั่งหยิบออกให้พิมพ์ค่าที่หยิบได้หนึ่งบรรทัด ตามลำดับคำสั่ง
