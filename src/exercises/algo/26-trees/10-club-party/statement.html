ชมรมหุ่นยนต์มีสมาชิก N คน หมายเลข 1 ถึง N ทุกคนยกเว้นประธานมีหัวหน้าทีมโดยตรงหนึ่งคน ผังของชมรมจึงเป็นต้นไม้ ชมรมจะจัดงานเลี้ยงปลายปี และรู้ว่าถ้าเชิญสมาชิกคนที่ i มา งานจะสนุกขึ้น fi คะแนน

ปัญหาคือ ไม่มีใครอยากมางานพร้อมหัวหน้าทีมโดยตรงของตัวเอง ชมรมจึงตั้งกติกาว่า ห้ามเชิญทั้งสมาชิกคนหนึ่งและหัวหน้าทีมโดยตรงของเขาพร้อมกัน ส่วนหัวหน้าของหัวหน้ามาพร้อมกันได้ ให้หาว่าเลือกเชิญได้ความสนุกรวมมากที่สุดเท่าไร จะไม่เชิญใครเลยก็ได้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว ตัวที่ i คือหมายเลขหัวหน้าทีมโดยตรงของคนที่ i ประธานมีค่านี้เป็น 0 มีประธานคนเดียวพอดี และข้อมูลเป็นต้นไม้เสมอ

บรรทัดที่สามมีจำนวนเต็ม N ตัว คือ f1 ถึง fN โดยที่ 0 ≤ fi ≤ 109
