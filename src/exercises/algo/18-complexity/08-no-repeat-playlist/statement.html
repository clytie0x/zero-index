แอปฟังเพลงเก็บประวัติเพลงที่น้องเปิดฟัง N เพลงตามลำดับ เพลงแต่ละเพลงมีรหัสเป็นจำนวนเต็ม เพลงเดียวกันอาจถูกเปิดหลายครั้ง แอปอยากทำสรุปท้ายปีว่าช่วงที่ฟังเพลงติดกันโดยไม่มีเพลงไหนซ้ำเลยยาวที่สุดกี่เพลง ถ้ามีหลายช่วงที่ยาวเท่ากัน ให้ตอบช่วงที่เริ่มเร็วที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีรหัสเพลงที่เปิด ตั้งแต่เพลงที่ 1 ถึงเพลงที่ N คั่นด้วยช่องว่าง แต่ละค่าเป็นจำนวนเต็มตั้งแต่ 1 ถึง 1000000

ข้อมูลออก

บรรทัดเดียว มีความยาวของช่วงที่ยาวที่สุด ตามด้วยลำดับของเพลงแรกในช่วงนั้น (นับเพลงแรกของประวัติเป็นเพลงที่ 1) คั่นด้วยช่องว่าง
