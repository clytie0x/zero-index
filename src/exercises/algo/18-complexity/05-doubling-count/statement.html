น้องอยากรู้ว่าโค้ดนี้ทำ count++ กี่ครั้ง แต่ถ้ารันตรงๆ เมื่อ N ใหญ่จะรอไม่ไหว ให้เขียนโปรแกรมที่ตอบจำนวนนั้นได้เร็ว

long long count = 0;
for (long long i = 1; i <= N; i++) {
    for (long long j = 1; j <= i; j *= 2) {
        count++;
    }
}

ตัวอย่างเช่น N = 5 รอบที่ i = 1 ลูปในวน 1 รอบ i = 2 และ 3 วน 2 รอบ i = 4 และ 5 วน 3 รอบ รวมเป็น 1 + 2 + 2 + 3 + 3 = 11

ข้อมูลเข้า

บรรทัดเดียว มีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000000000000000 (1015)

ข้อมูลออก

จำนวนครั้งที่ทำ count++
