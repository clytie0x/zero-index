ร้านขนมหน้าโรงเรียนมีคิวเดียว ช่วงพักกลางวันมีเหตุการณ์เกิดขึ้น N ครั้งตามลำดับ แต่ละครั้งเป็นอย่างใดอย่างหนึ่ง

  • 1 x นักเรียนเลขประจำตัว x มาต่อท้ายคิว
  • 2 แม่ค้าขายขนมให้คนที่อยู่หัวคิว แล้วคนนั้นออกจากคิวไป

ทุกครั้งที่ขาย ให้พิมพ์เลขประจำตัวของคนที่ได้ขนม ถ้าตอนนั้นไม่มีใครในคิว ให้พิมพ์ empty แทน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000000

อีก N บรรทัด แต่ละบรรทัดเป็นเหตุการณ์ในรูปแบบข้างบน เลขประจำตัว x เป็นจำนวนเต็มตั้งแต่ 1 ถึง 1000000000 รับประกันว่ามีเหตุการณ์ 2 อย่างน้อยหนึ่งครั้ง

ข้อมูลออก

หนึ่งบรรทัดต่อเหตุการณ์ 2 หนึ่งครั้ง ตามลำดับ เป็นเลขประจำตัวของคนที่ได้ขนม หรือ empty
