ครูจะจับนักเรียน N คนเป็นคู่ทำโครงงาน และอยากให้คะแนนเก็บของสองคนในคู่รวมกันได้ K พอดี เพื่อให้ทุกคู่มีกำลังเท่ากัน ให้หาว่ามีคู่ของนักเรียนสองคนที่ต่างกันกี่คู่ที่คะแนนรวมเท่ากับ K คู่ของคนที่ i กับคนที่ j นับเป็นคู่เดียวกับคู่ของคนที่ j กับคนที่ i

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 2 ≤ K ≤ 2000000

บรรทัดที่สองมีคะแนนของนักเรียน N คน คั่นด้วยช่องว่าง แต่ละค่าเป็นจำนวนเต็มตั้งแต่ 1 ถึง 1000000

ข้อมูลออก

จำนวนคู่ที่คะแนนรวมเท่ากับ K
