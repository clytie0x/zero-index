ร้านของขวัญวางสินค้าเรียงเป็นแถว N ชิ้น ชิ้นที่ i ราคา pi บาท น้องมีเงิน K บาท และอยากซื้อของสามชิ้นที่ต่างกัน โดยใช้เงินหมดพอดี ให้หาว่ามีวิธีเลือกของสามชิ้นกี่แบบ การเลือกชิ้นเดียวกันในลำดับต่างกันนับเป็นแบบเดียว ของสองชิ้นที่ราคาเท่ากันนับเป็นคนละชิ้น

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 3 ≤ N ≤ 5000 และ 3 ≤ K ≤ 3000000

บรรทัดที่สองมีราคา p1 ถึง pN คั่นด้วยช่องว่าง แต่ละค่าเป็นจำนวนเต็มตั้งแต่ 1 ถึง 1000000

ข้อมูลออก

จำนวนแบบของการเลือกของสามชิ้นที่ราคารวมเท่ากับ K
