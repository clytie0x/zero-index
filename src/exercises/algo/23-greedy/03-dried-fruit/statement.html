ร้านผลไม้อบแห้งมีผลไม้ N ชนิด ชนิดที่ i เหลืออยู่ wi กรัม ถ้าขายหมดทั้งหมดได้ vi บาท ร้านตักขายเป็นกรัม ตักชนิดไหนไปเท่าไรก็ได้ไม่เกินที่มี และคิดราคาตามสัดส่วน เช่นตักไปครึ่งหนึ่งของที่มี ก็ได้ราคาครึ่งหนึ่งของ vi น้องจะจัดกล่องของขวัญที่ใส่ได้ไม่เกิน W กรัม และอยากให้ของในกล่องมีราคารวมสูงที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ W คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 1 ≤ W ≤ 1011

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม wi และ vi โดยที่ 1 ≤ wi, vi ≤ 106

ข้อมูลออก

ราคารวมที่สูงที่สุดเป็นบาท ทศนิยม 2 ตำแหน่ง ชุดทดสอบเลือกไว้แล้วว่าคำตอบจริงไม่อยู่ใกล้กึ่งกลางระหว่างสองค่าที่ปัดได้
