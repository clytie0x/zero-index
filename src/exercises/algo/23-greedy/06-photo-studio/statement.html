ร้านถ่ายรูปติดบัตรหน้าโรงเรียนมีช่างภาพ K คน วันเปิดเทอมมีนักเรียน N คนมารอพร้อมกันตั้งแต่ร้านเปิด คนที่ i ใช้เวลาถ่าย ti นาที ช่างภาพแต่ละคนถ่ายได้ทีละคน ถ่ายเสร็จแล้วรับคนต่อไปได้ทันที เจ้าของร้านจัดได้เองว่าใครถ่ายกับช่างคนไหน และลำดับไหน เวลารอของนักเรียนคนหนึ่งคือเวลาตั้งแต่ร้านเปิดจนเริ่มถ่ายของเขา ให้หาผลรวมของเวลารอของทุกคนที่น้อยที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ K ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ t1 ถึง tN โดยที่ 1 ≤ ti ≤ 106

ข้อมูลออก

ผลรวมของเวลารอที่น้อยที่สุดเป็นนาที
