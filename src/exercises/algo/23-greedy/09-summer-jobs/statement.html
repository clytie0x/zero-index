ช่วงปิดเทอม น้องกับเพื่อนรับจ้างทำงานพิเศษเป็นทีม มีผู้จ้าง N รายเสนองานมา ทุกงานใช้เวลาหนึ่งวันพอดี ทีมทำได้วันละไม่เกิน C งาน เริ่มทำได้ตั้งแต่วันที่ 1 งานที่ i ต้องทำในวันที่ di หรือก่อนหน้านั้น และได้ค่าจ้าง pi บาท งานที่ไม่รับไม่ต้องทำ ให้หาค่าจ้างรวมที่มากที่สุดที่ทีมได้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ C คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ C ≤ 109

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม di และ pi โดยที่ 1 ≤ di ≤ 109 และ 1 ≤ pi ≤ 109

ข้อมูลออก

ค่าจ้างรวมที่มากที่สุดเป็นบาท
