ช่วงปิดเทอม ครูจะนัดนักเรียน N คนมาติวสอบเข้า นักเรียนคนที่ i ว่างตั้งแต่วันที่ ai ถึงวันที่ bi รวมทั้งสองวันนั้น วันไหนที่ครูนัด นักเรียนทุกคนที่ว่างวันนั้นจะมา ครูอยากให้นักเรียนทุกคนได้มาติวอย่างน้อยหนึ่งครั้ง โดยนัดให้น้อยวันที่สุด ให้หาว่าต้องนัดอย่างน้อยกี่วัน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม ai และ bi โดยที่ 1 ≤ ai ≤ bi ≤ 109

ข้อมูลออก

จำนวนวันที่น้อยที่สุดที่ต้องนัด
