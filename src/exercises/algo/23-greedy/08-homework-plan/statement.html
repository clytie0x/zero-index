ใกล้สอบปลายภาค น้องมีรายงานค้างอยู่ N ชิ้น ชิ้นที่ i ต้องใช้เวลาทำ ti วันเต็ม และครูกำหนดส่งภายในสิ้นวันที่ di น้องเริ่มทำได้ตั้งแต่วันที่ 1 ทำทีละชิ้นจนเสร็จแล้วค่อยเริ่มชิ้นต่อไป ไม่มีวันหยุดพัก ถ้าชิ้นใดทำเสร็จสิ้นวันที่ f ซึ่งเลยกำหนดส่ง ชิ้นนั้นสาย f - di วัน ชิ้นที่เสร็จทันถือว่าสาย 0 วัน ครูหักคะแนนตามชิ้นที่สายมากที่สุด น้องจึงอยากเลือกลำดับการทำให้ชิ้นที่สายมากที่สุดสายน้อยที่สุด ให้หาว่าสายน้อยที่สุดได้กี่วัน ถ้าส่งทันทุกชิ้นได้ให้ตอบ 0

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม ti และ di โดยที่ 1 ≤ ti ≤ 109 และ 1 ≤ di ≤ 1014

ข้อมูลออก

จำนวนวันที่สายน้อยที่สุดของชิ้นที่สายมากที่สุด
