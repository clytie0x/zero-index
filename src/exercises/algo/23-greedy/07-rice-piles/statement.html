โรงสีข้าวรับซื้อข้าวเปลือกจากชาวนา N ราย กองไว้ N กองบนลาน กองที่ i หนัก wi กิโลกรัม ก่อนสีต้องรวมทุกกองให้เป็นกองเดียว รถตักรวมได้ครั้งละสองกอง การรวมกองหนัก x กับกองหนัก y เสียค่าน้ำมัน x + y บาท ได้กองใหม่หนัก x + y ซึ่งเอาไปรวมกับกองอื่นต่อได้ ให้หาค่าน้ำมันรวมที่น้อยที่สุด ถ้ามีกองเดียวตั้งแต่แรก ค่าน้ำมันเป็น 0

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ w1 ถึง wN โดยที่ 1 ≤ wi ≤ 109

ข้อมูลออก

ค่าน้ำมันรวมที่น้อยที่สุดเป็นบาท
