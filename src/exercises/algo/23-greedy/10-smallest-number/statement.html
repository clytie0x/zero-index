เกมในคาบคณิตศาสตร์ ครูเขียนตัวเลข N หลักบนกระดาน แล้วให้นักเรียนลบหลักออกให้ครบ K หลักพอดี หลักที่เหลือเลื่อนมาชิดกันโดยลำดับไม่เปลี่ยน ใครได้ตัวเลขที่เหลือน้อยที่สุดเป็นผู้ชนะ เช่น 1432219 ลบ 3 หลัก ลบ 4 3 และ 2 ตัวแรกออก เหลือ 1219 ซึ่งน้อยที่สุดแล้ว ถ้าเหลือเลข 0 นำหน้า ให้ถือว่าเป็นตัวเลขตามปกติ เช่น 0200 คือ 200 ให้หาตัวเลขที่น้อยที่สุดที่เป็นไปได้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 0 ≤ K < N

บรรทัดที่สองเป็นตัวเลข N หลักติดกัน ไม่ขึ้นต้นด้วย 0

ข้อมูลออก

ตัวเลขที่น้อยที่สุดที่เหลือ ไม่มีเลข 0 นำหน้า ถ้าเหลือแต่เลข 0 ให้พิมพ์ 0
