ร้านดอกไม้มีริบบิ้นอยู่ N ม้วน ม้วนที่ i ยาว Li เซนติเมตร งานรับปริญญาสัปดาห์หน้ามีช่อดอกไม้ K ช่อ ทุกช่อต้องผูกริบบิ้นหนึ่งเส้นที่ยาวเท่ากันทุกช่อ และยาวเป็นจำนวนเต็มเซนติเมตร ริบบิ้นแต่ละเส้นต้องตัดมาจากม้วนเดียว ห้ามเอาเศษสองม้วนมาต่อกัน เศษที่เหลือจากการตัดทิ้งได้

ริบบิ้นยิ่งยาวช่อยิ่งสวย ให้หาว่าตัดให้ได้อย่างน้อย K เส้นโดยแต่ละเส้นยาวที่สุดได้กี่เซนติเมตร ถ้าตัดเส้นละ 1 เซนติเมตรแล้วยังไม่ถึง K เส้น ให้ตอบ 0

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 1 ≤ K ≤ 109

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ L1 ถึง LN โดยที่ 1 ≤ Li ≤ 109

ข้อมูลออก

ความยาวที่มากที่สุดเป็นเซนติเมตร หรือ 0
