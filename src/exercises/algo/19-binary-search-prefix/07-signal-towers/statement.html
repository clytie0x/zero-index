ถนนชนบทเส้นหนึ่งเป็นเส้นตรง มีจุดที่ได้รับอนุญาตให้ตั้งเสาสัญญาณ N จุด จุดที่ i อยู่ห่างจากต้นถนน xi เมตร ไม่มีสองจุดไหนอยู่ตำแหน่งเดียวกัน บริษัทต้องตั้งเสา C ต้นบนจุดเหล่านี้ จุดละไม่เกินหนึ่งต้น เสาที่อยู่ใกล้กันจะรบกวนสัญญาณกัน บริษัทจึงอยากให้ระยะห่างของเสาคู่ที่อยู่ใกล้กันที่สุดมากที่สุดเท่าที่ทำได้ ให้หาระยะนั้น

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ C คั่นด้วยช่องว่าง โดยที่ 2 ≤ C ≤ N ≤ 100000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ x1 ถึง xN ไม่ได้เรียงมา และไม่ซ้ำกัน โดยที่ 0 ≤ xi ≤ 109

ข้อมูลออก

ระยะห่างของเสาคู่ที่ใกล้กันที่สุด ที่มากที่สุดเท่าที่ทำได้
