โรงงานขนมมีเตาอบ N เตา ทุกเตาเริ่มอบพร้อมกันที่นาทีที่ 0 และอบต่อเนื่องไม่หยุด เตาที่ i อบขนมเสร็จหนึ่งถาดทุก ti นาที คือเสร็จถาดแรกที่นาทีที่ ti ถาดที่สองที่นาทีที่ 2ti ไปเรื่อยๆ วันนี้มีออร์เดอร์ M ถาด ให้หาว่าต้องใช้เวลาน้อยที่สุดกี่นาทีจึงได้ขนมครบ M ถาด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ M คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 1 ≤ M ≤ 109

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ t1 ถึง tN โดยที่ 1 ≤ ti ≤ 109

ข้อมูลออก

จำนวนนาทีที่น้อยที่สุด
