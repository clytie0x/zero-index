น้องจดไว้ว่าตลอด N วันที่ผ่านมา วันที่ i อ่านหนังสือไป ai หน้า บางวันไม่ได้อ่านเลย เพื่อนๆ ในชมรมอยากเทียบกันว่า ถ้าเริ่มนับตั้งแต่วันที่ s จะต้องถึงวันที่เท่าไรน้องจึงอ่านรวมได้อย่างน้อย t หน้า มีคำถามแบบนี้ Q ข้อ

คำตอบของคำถามหนึ่งข้อคือวันที่ d ที่น้อยที่สุด ที่ d ≥ s และ as + as+1 + ... + ad ≥ t ถ้าอ่านถึงวันที่ N แล้วยังไม่ถึง t หน้า ให้ตอบ -1

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ a1 ถึง aN โดยที่ 0 ≤ ai ≤ 10000

อีก Q บรรทัด แต่ละบรรทัดมีจำนวนเต็ม s และ t คั่นด้วยช่องว่าง โดยที่ 1 ≤ s ≤ N และ 1 ≤ t ≤ 109

ข้อมูลออก

Q บรรทัด ตอบตามลำดับคำถาม บรรทัดละหนึ่งข้อ เป็นวันที่ d หรือ -1
