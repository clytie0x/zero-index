ช่างปูกระเบื้องมีกระเบื้องแผ่นสี่เหลี่ยมจัตุรัสขนาดเท่ากัน n แผ่น ลูกค้าอยากได้ลานที่ปูเป็นรูปสี่เหลี่ยมจัตุรัสเต็มผืน ขนาด k × k แผ่น ให้หาว่าลานใหญ่ที่สุดที่ปูได้มีด้านยาวกี่แผ่น กระเบื้องที่เหลือเก็บไว้ใช้งานอื่น ช่างมีงานแบบนี้ T งาน ให้ตอบทุกงาน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม T โดยที่ 1 ≤ T ≤ 100000

อีก T บรรทัด แต่ละบรรทัดมีจำนวนเต็ม n หนึ่งตัว โดยที่ 0 ≤ n ≤ 1018

ข้อมูลออก

T บรรทัด ตอบตามลำดับงาน บรรทัดละหนึ่งงาน เป็นจำนวนเต็ม k ที่มากที่สุดที่ k × k ≤ n
