สวนผักของโรงเรียนมีต้นไม้ปลูกเรียงเป็นแถว N ต้น หมายเลข 1 ถึง N ช่วงปิดเทอม ต้นที่ i ต้องได้น้ำรวมอย่างน้อย needi ลิตรจึงจะรอด ครูวางแผนรดน้ำไว้ Q ครั้งตามลำดับ ครั้งที่ j รดต้นตั้งแต่ต้นที่ l ถึงต้นที่ r ต้นละ w ลิตร ครูอยากรู้ว่าต้องรดตามแผนไปกี่ครั้งแรก ทุกต้นจึงได้น้ำครบตามที่ต้องการ จะได้หยุดรดหลังจากนั้นเพื่อประหยัดน้ำ

คำตอบคือ k ที่น้อยที่สุดที่หลังจากรดครั้งที่ 1 ถึง k แล้ว ทุกต้นได้น้ำรวมอย่างน้อย needi ลิตร ถ้าทุกต้นต้องการ 0 ลิตรตั้งแต่แรก คำตอบคือ 0 ถ้ารดครบทั้ง Q ครั้งแล้วยังมีต้นที่ได้น้ำไม่พอ ให้ตอบ -1

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ need1 ถึง needN โดยที่ 0 ≤ needi ≤ 1014

อีก Q บรรทัด บรรทัดที่ j มีจำนวนเต็ม l r และ w ของการรดครั้งที่ j คั่นด้วยช่องว่าง โดยที่ 1 ≤ l ≤ r ≤ N และ 1 ≤ w ≤ 109

ข้อมูลออก

จำนวนครั้งที่น้อยที่สุด หรือ -1
