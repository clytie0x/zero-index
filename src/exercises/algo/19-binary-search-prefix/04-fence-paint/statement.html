รั้วไม้ของโรงเรียนมีไม้เรียงกัน N แผ่น หมายเลข 1 ถึง N วันอาสามีนักเรียนมาช่วยทาสีกันแดด Q กลุ่ม กลุ่มที่ j ทาไม้ตั้งแต่แผ่นที่ l ถึงแผ่นที่ r ทับลงไปอีก c ชั้น สีกันแดดจะได้ผลเมื่อหนาอย่างน้อย K ชั้น หลังทุกกลุ่มทาเสร็จ ให้นับว่ามีไม้กี่แผ่นที่สียังหนาไม่ถึง K ชั้น ซึ่งต้องนัดมาทาซ่อมอีกวัน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N Q และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000, 1 ≤ Q ≤ 200000 และ 1 ≤ K ≤ 1015

อีก Q บรรทัด แต่ละบรรทัดมีจำนวนเต็ม l r และ c คั่นด้วยช่องว่าง โดยที่ 1 ≤ l ≤ r ≤ N และ 1 ≤ c ≤ 109

ข้อมูลออก

จำนวนแผ่นที่สีหนาน้อยกว่า K ชั้น
