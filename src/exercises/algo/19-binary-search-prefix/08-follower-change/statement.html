น้องทำช่องวิดีโอ และจดว่ายอดผู้ติดตามเปลี่ยนไปเท่าไรในแต่ละวันตลอด N วัน วันที่ i เปลี่ยนไป ai คน ถ้ามีคนเลิกติดตามมากกว่าคนติดตามใหม่ ai จะติดลบ น้องอยากรู้ว่ามีกี่ช่วงวันติดกันที่ยอดผู้ติดตามรวมแล้วเปลี่ยนไป K คนพอดี

ช่วงวันคือคู่ l กับ r ที่ 1 ≤ l ≤ r ≤ N และยอดที่เปลี่ยนรวมคือ al + al+1 + ... + ar ช่วงที่ l หรือ r ต่างกันนับเป็นคนละช่วง แม้ผลรวมจะมาจากวันชุดที่ดูคล้ายกัน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ -1015 ≤ K ≤ 1015

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ a1 ถึง aN โดยที่ -109 ≤ ai ≤ 109

ข้อมูลออก

จำนวนช่วงวันที่ยอดเปลี่ยนรวมเท่ากับ K พอดี
