เพื่อน N คนอยู่บนถนนเส้นตรงเส้นเดียวกัน คนที่ i อยู่ห่างจากต้นถนน xi เมตร และเคลื่อนที่ได้เร็วที่สุด vi เมตรต่อวินาที บางคนเดิน บางคนปั่นจักรยาน ทุกคนออกเดินทางพร้อมกัน เพื่อไปพบกันที่จุดนัดจุดเดียวบนถนน จุดนัดจะอยู่ตรงไหนก็ได้ ไม่จำเป็นต้องเป็นจำนวนเต็ม คนที่ไปถึงก่อนรอได้ ให้หาว่าทุกคนมาพร้อมหน้ากันได้เร็วที่สุดภายในกี่วินาที

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 100000
