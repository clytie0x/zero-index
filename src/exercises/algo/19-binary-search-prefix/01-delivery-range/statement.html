ร้านน้ำแข็งส่งของให้ลูกค้าที่อยู่ริมถนนเส้นตรงเส้นเดียว บ้านลูกค้า N หลังอยู่ที่ตำแหน่ง x1, x2, ..., xN กิโลเมตรจากหลักกิโลเมตรศูนย์ ตำแหน่งติดลบคืออยู่อีกฝั่งของหลัก บ้านหลายหลังอาจอยู่ตำแหน่งเดียวกันได้ เช่น ห้องในตึกเดียวกัน

ร้านวางแผนส่งของ Q วัน วันหนึ่งรถจะจอดที่ตำแหน่ง p และน้ำแข็งละลายเร็ว จึงส่งได้เฉพาะบ้านที่อยู่ห่างจากรถไม่เกิน d กิโลเมตร ไม่ว่าทางซ้ายหรือทางขวา ให้หาว่าแต่ละวันส่งของถึงบ้านได้กี่หลัง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 200000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือตำแหน่งของบ้าน โดยที่ -109 ≤ xi ≤ 109

อีก Q บรรทัด แต่ละบรรทัดมีจำนวนเต็ม p และ d คั่นด้วยช่องว่าง โดยที่ -109 ≤ p ≤ 109 และ 0 ≤ d ≤ 109

ข้อมูลออก

Q บรรทัด ตอบตามลำดับวัน บรรทัดละหนึ่งวัน เป็นจำนวนบ้านที่อยู่ห่างจาก p ไม่เกิน d
