เขียนเครื่องคิดเลขที่รับโจทย์ในรูป A op B แล้วพิมพ์ผลลัพธ์ op เป็นเครื่องหมายหนึ่งในห้าตัวนี้

opผลลัพธ์
+A บวก B
-A ลบ B
*A คูณ B
/A หาร B แบบปัดเศษทิ้ง เหมือน / ของจำนวนเต็มในภาษา C
%เศษจากการหาร A ด้วย B

ถ้า op เป็น / หรือ % แล้ว B เป็น 0 ให้พิมพ์ error แทน

ข้อมูลเข้า

บรรทัดเดียว มีจำนวนเต็ม A ตามด้วยเครื่องหมาย op และจำนวนเต็ม B คั่นกันด้วยช่องว่าง โดยที่ 0 ≤ A, B ≤ 1000000000

ข้อมูลออก

ผลลัพธ์ของการคำนวณ หรือ error
