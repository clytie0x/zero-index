วิชาคอมพิวเตอร์มีคะแนนเก็บเต็ม 40 คะแนน และคะแนนสอบปลายภาคเต็ม 60 คะแนน นักเรียนจะผ่านวิชานี้เมื่อคะแนนรวมทั้งสองส่วนได้ตั้งแต่ 50 คะแนนขึ้นไป ให้บอกว่านักเรียนคนหนึ่งผ่านหรือไม่

ข้อมูลเข้า

บรรทัดเดียว มีจำนวนเต็ม A คือคะแนนเก็บ และ B คือคะแนนสอบปลายภาค คั่นด้วยช่องว่าง โดยที่ 0 ≤ A ≤ 40 และ 0 ≤ B ≤ 60

ข้อมูลออก

พิมพ์ pass ถ้าผ่าน หรือ fail ถ้าไม่ผ่าน
