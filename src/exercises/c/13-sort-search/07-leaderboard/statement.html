การแข่งขันเขียนโปรแกรมของโรงเรียนมีผู้เข้าแข่ง N คน เมื่อหมดเวลา แต่ละคนมีจำนวนข้อที่ทำผ่าน และเวลาปรับ (penalty) เป็นนาที กรรมการจัดตารางอันดับตามกติกานี้

  • ทำผ่านมากข้อกว่า อยู่ก่อน
  • ถ้าทำผ่านเท่ากัน เวลาปรับน้อยกว่า อยู่ก่อน
  • ถ้าทั้งสองอย่างเท่ากัน ถือว่าได้อันดับเดียวกัน แต่ในตารางให้เรียงตามชื่อตามลำดับพจนานุกรม

อันดับของแต่ละคนคือ 1 บวกจำนวนคนที่ทำได้ดีกว่าคนนั้นจริงๆ เช่น ถ้ามีสองคนเสมอกันที่อันดับ 2 คนถัดไปจะได้อันดับ 4 ไม่ใช่ 3

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 50000)

อีก N บรรทัด บรรทัดละหนึ่งคน มีชื่อ จำนวนข้อที่ทำผ่าน และเวลาปรับ คั่นด้วยช่องว่าง ชื่อเป็นตัวพิมพ์เล็กภาษาอังกฤษยาว 1 ถึง 10 ตัว และไม่มีชื่อซ้ำกัน จำนวนข้อเป็นจำนวนเต็มตั้งแต่ 0 ถึง 10 เวลาปรับเป็นจำนวนเต็มตั้งแต่ 0 ถึง 100000

ข้อมูลออก

N บรรทัดตามลำดับในตาราง บรรทัดละหนึ่งคน มีอันดับ ตามด้วยช่องว่าง แล้วตามด้วยชื่อ
