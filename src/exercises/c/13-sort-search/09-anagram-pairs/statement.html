ชมรมภาษาอังกฤษจัดเกมสลับอักษร นักเรียนส่งคำมาทั้งหมด N คำ สองคำเป็นคู่สลับอักษร (anagram) ถ้าใช้ตัวอักษรชุดเดียวกัน แต่ละตัวมีจำนวนเท่ากัน แค่เรียงคนละลำดับ เช่น listen กับ silent หรือ stop กับ pots แต่ lose กับ loose ไม่ใช่ เพราะจำนวนตัว o ไม่เท่ากัน คำที่เหมือนกันทุกตัวก็ถือว่าเป็นคู่สลับอักษรกัน

ให้นับว่ามีกี่คู่ (i, j) ที่ i < j และคำที่ i กับคำที่ j เป็นคู่สลับอักษรกัน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 100000)

อีก N บรรทัด บรรทัดละหนึ่งคำ แต่ละคำเป็นตัวพิมพ์เล็กภาษาอังกฤษยาว 1 ถึง 8 ตัว

ข้อมูลออก

จำนวนคู่ที่เป็นคู่สลับอักษร
