การสอบคัดเลือกเข้าโรงเรียนแห่งหนึ่งมีผู้สมัคร N คน คะแนนเต็ม 100 ผู้สมัครแต่ละคนได้คะแนนเป็นจำนวนเต็ม เมื่อเรียงคะแนนของทุกคนจากมากไปน้อย คนแรกในรายการคืออันดับที่ 1 คนถัดไปคืออันดับที่ 2 ไปเรื่อยๆ ถ้ามีคนได้คะแนนเท่ากัน ใครอยู่ก่อนก็ได้ เพราะคะแนนที่ตำแหน่งนั้นเท่าเดิม

โรงเรียนมีคำถาม Q ข้อ แต่ละข้อถามว่าผู้สมัครอันดับที่ k ได้คะแนนเท่าไร เช่น ถ้ารับ 300 คน ก็อยากรู้คะแนนของอันดับที่ 300 ซึ่งเป็นคะแนนต่ำสุดที่ยังได้เข้าเรียน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง (1 ≤ N ≤ 200000 และ 1 ≤ Q ≤ 1000)

บรรทัดที่สองมีคะแนนของผู้สมัคร N คน คั่นด้วยช่องว่าง แต่ละคะแนนเป็นจำนวนเต็มตั้งแต่ 0 ถึง 100

อีก Q บรรทัด บรรทัดละหนึ่งจำนวนเต็ม k (1 ≤ k ≤ N)

ข้อมูลออก

Q บรรทัด บรรทัดที่ i คือคะแนนของผู้สมัครอันดับที่ k ของคำถามข้อที่ i
