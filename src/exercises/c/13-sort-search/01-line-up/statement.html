ครูพละให้นักเรียน N คนเข้าแถวหน้าเสาธงโดยเรียงจากคนที่เตี้ยที่สุดไปคนที่สูงที่สุด ครูจดส่วนสูงของทุกคนเป็นเซนติเมตรตามลำดับที่เดินมาถึง ให้พิมพ์ส่วนสูงเรียงตามลำดับในแถว

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 1000)

บรรทัดที่สองมีส่วนสูงของนักเรียน N จำนวน คั่นด้วยช่องว่าง แต่ละจำนวนเป็นจำนวนเต็มตั้งแต่ 100 ถึง 200

ข้อมูลออก

บรรทัดเดียว ส่วนสูงทั้ง N จำนวนเรียงจากน้อยไปมาก คั่นด้วยช่องว่างหนึ่งช่อง
