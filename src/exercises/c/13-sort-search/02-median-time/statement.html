งานวิ่งการกุศลของโรงเรียนมีนักวิ่ง N คน เครื่องจับเวลาบันทึกเวลาที่แต่ละคนใช้เป็นวินาที ตามลำดับเลขบิบ ไม่ได้เรียงตามเวลา ผู้จัดอยากประกาศว่านักวิ่ง "ทั่วไป" ใช้เวลาเท่าไร จึงต้องการค่ากลาง คือเวลาของคนที่อยู่ตรงกลางพอดีเมื่อเรียงเวลาของทุกคนจากน้อยไปมาก N เป็นเลขคี่เสมอ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็มคี่ N (1 ≤ N ≤ 999)

บรรทัดที่สองมีเวลาของนักวิ่ง N คน คั่นด้วยช่องว่าง แต่ละค่าเป็นจำนวนเต็มตั้งแต่ 1 ถึง 100000

ข้อมูลออก

ค่ากลางของเวลาทั้ง N ค่า
