กล้องที่ด่านเก็บค่าผ่านทางอ่านทะเบียนรถทุกคันที่ผ่านในวันหนึ่ง แล้วแปลงเป็นรหัสตัวเลข รถคันเดียวกันได้รหัสเดิมทุกครั้ง และรถบางคันผ่านด่านหลายรอบ วันนี้กล้องอ่านได้ N ครั้ง ให้หาว่ามีรถที่ต่างกันกี่คัน และรถคันที่ผ่านบ่อยที่สุดผ่านกี่ครั้ง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 100000)

บรรทัดที่สองมีรหัสที่อ่านได้ N รหัสตามลำดับเวลา คั่นด้วยช่องว่าง แต่ละรหัสเป็นจำนวนเต็มตั้งแต่ 1 ถึง 109

ข้อมูลออก

บรรทัดเดียว มีจำนวนรถที่ต่างกัน ตามด้วยช่องว่าง แล้วตามด้วยจำนวนครั้งที่รถคันที่ผ่านบ่อยที่สุดผ่านด่าน
