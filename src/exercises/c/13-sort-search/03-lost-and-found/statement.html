ห้องเก็บของหายของโรงเรียนวางกล่องเรียงเป็นแถวยาว N กล่อง กล่องที่ 1 อยู่ซ้ายสุด แต่ละกล่องติดป้ายเลขรหัสของสิ่งของในกล่อง ของหลายชิ้นอาจมีรหัสเดียวกันได้ เช่น ขวดน้ำรุ่นเดียวกัน นักเรียนคนหนึ่งมาถามหาของรหัส X ให้บอกว่ามีกล่องที่ติดรหัส X กี่กล่อง และอยู่กล่องที่เท่าไรบ้าง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ X คั่นด้วยช่องว่าง (1 ≤ N ≤ 1000 และ 1 ≤ X ≤ 109)

บรรทัดที่สองมีรหัสบนกล่องที่ 1 ถึงกล่องที่ N คั่นด้วยช่องว่าง แต่ละรหัสเป็นจำนวนเต็มตั้งแต่ 1 ถึง 109

ข้อมูลออก

บรรทัดแรกพิมพ์จำนวนกล่องที่ติดรหัส X

ถ้าจำนวนนั้นมากกว่า 0 บรรทัดที่สองพิมพ์ลำดับของกล่องเหล่านั้นจากซ้ายไปขวา คั่นด้วยช่องว่างหนึ่งช่อง ถ้าไม่มีกล่องใดเลย ให้พิมพ์แค่บรรทัดแรก
