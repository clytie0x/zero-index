ร้านข้าวแกงวางจานที่ล้างแล้วซ้อนกันเป็นตั้งเดียว จานแต่ละใบมีหมายเลขเขียนไว้ใต้จาน คนล้างจานวางจานใบใหม่ไว้บนสุดเสมอ และแม่ครัวหยิบจานจากบนสุดเสมอ ให้จำลองตั้งจานตามคำสั่ง Q คำสั่ง แต่ละคำสั่งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • PUSH x วางจานหมายเลข x ไว้บนสุด
  • POP หยิบจานบนสุดออกไป ให้พิมพ์หมายเลขจานใบนั้น ถ้าไม่มีจานเหลือเลยให้พิมพ์ EMPTY
  • TOP ดูจานบนสุดโดยไม่หยิบออก ให้พิมพ์หมายเลขจานใบนั้น ถ้าไม่มีจานให้พิมพ์ EMPTY
  • SIZE พิมพ์จำนวนจานที่อยู่ในตั้ง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 100000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน หมายเลขจาน x เป็นจำนวนเต็ม 1 ≤ x ≤ 1000000000 รับประกันว่ามีคำสั่ง POP TOP หรือ SIZE อย่างน้อยหนึ่งคำสั่ง

ข้อมูลออก

สำหรับคำสั่ง POP TOP และ SIZE แต่ละคำสั่ง ให้พิมพ์คำตอบหนึ่งบรรทัด ตามลำดับของคำสั่ง
