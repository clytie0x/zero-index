ร้านข้าวมันไก่หน้าตลาดมีแม่ครัวคนเดียว ทำได้ทีละจาน และมีเก้าอี้ให้ลูกค้านั่งรอ K ตัว วันนี้มีลูกค้า N คน ลูกค้าคนที่ i มาถึงร้านที่เวลา ti และจานของเขาใช้เวลาทำ si นาที ลูกค้าเรียงตามลำดับที่มาถึง ถ้ามาถึงเวลาเดียวกัน คนที่อยู่ก่อนในข้อมูลเข้าถือว่ามาก่อน

ร้านทำงานตามกฎนี้

  • แม่ครัวทำจานให้ลูกค้าตามลำดับที่เข้าแถวรอ พอทำจานหนึ่งเสร็จ ลูกค้าคนนั้นรับจานแล้วออกจากร้านทันที แล้วแม่ครัวเริ่มทำจานของคนหัวแถวต่อทันที คนที่ได้เริ่มทำจานแล้วลุกจากเก้าอี้
  • เมื่อลูกค้ามาถึงที่เวลา t ให้ทำทุกอย่างที่เกิดขึ้นที่เวลา t หรือก่อนหน้านั้นให้เสร็จก่อน รวมถึงจานที่ทำเสร็จตรงเวลา t พอดี จากนั้น
    • ถ้าแม่ครัวว่างและไม่มีใครรอ แม่ครัวเริ่มทำจานของเขาทันที
    • ไม่อย่างนั้น ถ้ามีคนนั่งรออยู่น้อยกว่า K คน เขานั่งรอต่อท้ายแถว
    • ไม่อย่างนั้น เก้าอี้เต็ม เขากลับบ้านไปเลย

ให้หาว่าลูกค้าแต่ละคนได้รับจานที่เวลาเท่าไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ K ≤ N ≤ 100000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม ti และ si คั่นด้วยช่องว่าง โดยที่ 0 ≤ t1 ≤ t2 ≤ ... ≤ tN ≤ 1000000000 และ 1 ≤ si ≤ 100000

ข้อมูลออก

N บรรทัด บรรทัดที่ i คือเวลาที่ลูกค้าคนที่ i ได้รับจาน ถ้าเขากลับบ้านเพราะเก้าอี้เต็ม ให้พิมพ์ -1
