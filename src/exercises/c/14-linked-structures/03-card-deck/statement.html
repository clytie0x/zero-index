นักมายากลถือไพ่หนึ่งสำรับคว่ำหน้าไว้ ไพ่แต่ละใบมีหมายเลขไม่ซ้ำกัน ระหว่างการแสดง เขาวางไพ่เพิ่มหรือหยิบไพ่ออกได้ทั้งด้านบนและด้านล่างของสำรับ เริ่มต้นสำรับยังไม่มีไพ่ ให้จำลองสำรับตามคำสั่ง Q คำสั่ง แต่ละคำสั่งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • TOP x วางไพ่หมายเลข x ไว้บนสุดของสำรับ
  • BOTTOM x สอดไพ่หมายเลข x ไว้ใต้สุดของสำรับ
  • DRAWTOP หยิบไพ่ใบบนสุดออก ให้พิมพ์หมายเลขของมัน ถ้าสำรับไม่มีไพ่ให้พิมพ์ EMPTY
  • DRAWBOTTOM หยิบไพ่ใบล่างสุดออก ให้พิมพ์หมายเลขของมัน ถ้าสำรับไม่มีไพ่ให้พิมพ์ EMPTY

จบการแสดงแล้ว ให้พิมพ์ไพ่ที่เหลือทั้งสำรับเรียงจากบนสุดลงไปล่างสุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 100000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน หมายเลขไพ่ x เป็นจำนวนเต็ม 1 ≤ x ≤ 1000000000

ข้อมูลออก

สำหรับคำสั่ง DRAWTOP และ DRAWBOTTOM แต่ละคำสั่ง ให้พิมพ์คำตอบหนึ่งบรรทัดตามลำดับ

บรรทัดสุดท้ายพิมพ์หมายเลขไพ่ที่เหลือจากบนสุดถึงล่างสุด คั่นด้วยช่องว่างหนึ่งช่อง ถ้าไม่เหลือไพ่เลยให้พิมพ์ EMPTY
