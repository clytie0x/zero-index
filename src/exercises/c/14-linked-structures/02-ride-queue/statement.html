รถไฟเหาะในสวนสนุกมีแถวรอขึ้นแถวเดียว คนที่มาใหม่ต่อท้ายแถว รถไฟแต่ละเที่ยวมีที่นั่งไม่เท่ากัน เพราะบางเที่ยวมีที่นั่งที่ปิดซ่อม คนหัวแถวได้ขึ้นก่อนเสมอ ให้จำลองแถวตามคำสั่ง Q คำสั่ง แต่ละคำสั่งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • JOIN x คนที่ถือบัตรหมายเลข x มาต่อท้ายแถว
  • RIDE k รถไฟเที่ยวใหม่มีที่นั่ง k ที่ คนจากหัวแถวขึ้นไปนั่งทีละคนจนกว่าที่นั่งจะเต็มหรือแถวจะหมด ให้พิมพ์หมายเลขบัตรของทุกคนที่ได้ขึ้นเที่ยวนี้ตามลำดับในบรรทัดเดียว คั่นด้วยช่องว่างหนึ่งช่อง ถ้าไม่มีใครในแถวเลยให้พิมพ์ EMPTY
  • COUNT พิมพ์จำนวนคนที่ยังรออยู่ในแถว

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 100000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน โดยที่ 1 ≤ x ≤ 1000000000 และ 1 ≤ k ≤ 100000 รับประกันว่ามีคำสั่ง RIDE หรือ COUNT อย่างน้อยหนึ่งคำสั่ง

ข้อมูลออก

สำหรับคำสั่ง RIDE และ COUNT แต่ละคำสั่ง ให้พิมพ์คำตอบหนึ่งบรรทัด ตามลำดับของคำสั่ง
