ถนนเส้นหนึ่งวิ่งจากทิศตะวันตกไปทิศตะวันออก มีตึก N หลังเรียงกันริมถนน หมายเลข 1 ถึง N จากตะวันตกไปตะวันออก ตึกหลังที่ i สูง hi เมตร ช่างภาพจะขึ้นไปถ่ายวิวทางทิศตะวันออกจากดาดฟ้าของตึกทุกหลัง ตึกที่เตี้ยกว่าหรือสูงเท่ากับตึกที่ยืนอยู่ไม่บังวิว แต่ตึกหลังแรกที่สูงกว่าจะบังทุกอย่างที่อยู่ข้างหลังมัน

ให้หาว่าสำหรับตึกแต่ละหลัง ตึกหลังแรกทางทิศตะวันออกที่สูงกว่ามันอย่างเคร่งครัดคือหลังหมายเลขอะไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 500000

บรรทัดที่สองมีจำนวนเต็ม N ตัว คือ h1 ถึง hN คั่นด้วยช่องว่าง โดยที่ 1 ≤ hi ≤ 1000000000

ข้อมูลออก

บรรทัดเดียว มีจำนวนเต็ม N ตัว คั่นด้วยช่องว่างหนึ่งช่อง ตัวที่ i คือหมายเลขของตึกหลังแรกทางทิศตะวันออกของตึก i ที่สูงกว่าตึก i ถ้าไม่มีให้ตอบ 0
