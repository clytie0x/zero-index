เด็ก N คนนั่งเป็นวงกลม มีหมายเลข 1 ถึง N เรียงตามเข็มนาฬิกา เด็กหมายเลข N นั่งติดกับเด็กหมายเลข 1 เกมเริ่มโดยเด็กหมายเลข 1 ถือลูกบอล แต่ละรอบเล่นแบบนี้

  1. คนที่ถือลูกบอลส่งต่อให้คนถัดไปตามเข็มนาฬิกาที่ยังอยู่ในวง ส่งต่อกันไปทั้งหมด K - 1 ครั้ง
  2. คนที่ถือลูกบอลอยู่ตอนนี้ออกจากวง และยื่นลูกบอลให้คนถัดไปตามเข็มนาฬิกาที่ยังอยู่ในวง

เล่นไปจนทุกคนออกจากวง ให้หาว่าเด็กออกจากวงในลำดับใด

ข้อมูลเข้า

บรรทัดเดียว มีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 5000 และ 1 ≤ K ≤ 1000000000

ข้อมูลออก

บรรทัดเดียว มีหมายเลขของเด็ก N คนตามลำดับที่ออกจากวง คั่นด้วยช่องว่างหนึ่งช่อง
