เครื่องคิดเลขรุ่นเก่ารุ่นหนึ่งไม่มีปุ่มวงเล็บ ผู้ใช้ต้องป้อนนิพจน์แบบ postfix คือเขียนเครื่องหมายไว้หลังตัวเลขสองตัวที่มันใช้ เช่น (8 - 3) * 4 ป้อนเป็น 8 3 - 4 * ให้เขียนโปรแกรมคำนวณนิพจน์ postfix ที่ป้อนเข้ามา

นิพจน์มีเครื่องหมายสี่แบบ คือ + - * และ / การหารให้ผลเป็นจำนวนเต็มแบบเดียวกับ / ของภาษา C คือตัดเศษทิ้งไปทาง 0 เช่น 7 หาร 2 ได้ 3 และ -7 หาร 2 ได้ -3

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N คือจำนวนตัวเลขและเครื่องหมายรวมกัน โดยที่ 1 ≤ N ≤ 100000

บรรทัดที่สองมีตัวเลขและเครื่องหมาย N ตัว คั่นด้วยช่องว่าง ตัวเลขทุกตัวเป็นจำนวนเต็มตั้งแต่ 0 ถึง 1000000000 ไม่มีเครื่องหมายลบนำหน้า

รับประกันว่านิพจน์ถูกต้อง ไม่มีการหารด้วยศูนย์ และผลระหว่างทางทุกค่ารวมถึงคำตอบ มีค่าสัมบูรณ์ไม่เกิน 1018
