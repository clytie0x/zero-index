ลานสับเปลี่ยนรถไฟมีขบวนรถอยู่หนึ่งขบวน ตอนเริ่มมีตู้ N ตู้ หมายเลข 1 ถึง N เรียงจากหัวขบวนไปท้ายขบวน เจ้าหน้าที่ได้รับคำสั่งงาน Q คำสั่ง ทำตามลำดับ แต่ละคำสั่งเป็นแบบใดแบบหนึ่งต่อไปนี้

  • I x y พ่วงตู้ใหม่หมายเลข y ไว้ข้างหลังตู้หมายเลข x ทันที ถ้า x เป็น 0 แปลว่าพ่วงตู้ y ไว้หน้าสุดของขบวน รับประกันว่าตู้ x อยู่ในขบวน และตู้ y ไม่ได้อยู่ในขบวนตอนนั้น ตู้ y อาจเป็นตู้ที่เคยถูกปลดออกไปแล้วก็ได้
  • D x ปลดตู้หมายเลข x ออกจากขบวน ตู้ที่อยู่ข้างหน้าและข้างหลังมันต่อกันตามเดิม รับประกันว่าตู้ x อยู่ในขบวน

ให้หาว่าทำครบทุกคำสั่งแล้ว ขบวนรถเรียงตู้อย่างไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 1 ≤ Q ≤ 200000

อีก Q บรรทัด บรรทัดละหนึ่งคำสั่งตามรูปแบบข้างบน หมายเลขตู้ทุกหมายเลขเป็นจำนวนเต็มตั้งแต่ 1 ถึง 300000

ข้อมูลออก

บรรทัดเดียว มีหมายเลขตู้ทั้งหมดในขบวนเรียงจากหัวไปท้าย คั่นด้วยช่องว่างหนึ่งช่อง ถ้าไม่มีตู้เหลือเลยให้พิมพ์ EMPTY
