โปรแกรมตารางคำนวณต้องตรวจวงเล็บในสูตรก่อนคำนวณ สูตรประกอบด้วยตัวอักษรภาษาอังกฤษ ตัวเลข เครื่องหมาย + - * / และวงเล็บสามชนิด คือ ( ) [ ] และ { } สูตรที่วงเล็บถูกต้องคือ วงเล็บปิดทุกตัวคู่กับวงเล็บเปิดชนิดเดียวกันตัวล่าสุดที่ยังไม่ถูกปิด และไม่มีวงเล็บเปิดเหลือค้างเมื่อจบสูตร ตัวอักษรอื่นที่ไม่ใช่วงเล็บไม่มีผลกับการตรวจ

ถ้าสูตรผิด โปรแกรมต้องบอกตำแหน่งที่ผิดด้วย ตำแหน่งนับจาก 1 ที่ตัวอักษรแรกของสูตร

  • ถ้าอ่านจากซ้ายไปขวาแล้วเจอวงเล็บปิดที่ไม่มีวงเล็บเปิดค้างอยู่เลย หรือวงเล็บเปิดตัวล่าสุดที่ค้างอยู่เป็นคนละชนิด ตำแหน่งที่ผิดคือตำแหน่งของวงเล็บปิดตัวนั้น
  • ถ้าอ่านจนจบโดยไม่เจอปัญหาข้อแรก แต่ยังมีวงเล็บเปิดค้างอยู่ ตำแหน่งที่ผิดคือตำแหน่งของวงเล็บเปิดตัวซ้ายสุดที่ยังค้างอยู่

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม T คือจำนวนสูตร โดยที่ 1 ≤ T ≤ 1000

อีก T บรรทัด บรรทัดละหนึ่งสูตร ไม่มีช่องว่างในสูตร แต่ละสูตรยาว 1 ถึง 100000 ตัวอักษร และทุกสูตรยาวรวมกันไม่เกิน 1000000 ตัวอักษร

ข้อมูลออก

T บรรทัด ตอบสูตรละหนึ่งบรรทัดตามลำดับ ถ้าวงเล็บถูกต้องให้พิมพ์ OK ถ้าผิดให้พิมพ์ ERROR ตามด้วยช่องว่างและตำแหน่งที่ผิด
