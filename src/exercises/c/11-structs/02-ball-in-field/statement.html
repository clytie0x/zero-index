สนามฟุตซอลเป็นสี่เหลี่ยมผืนผ้าที่ด้านขนานกับแกน x และแกน y มุมซ้ายล่างอยู่ที่ (X1, Y1) มุมขวาบนอยู่ที่ (X2, Y2) หลังซ้อมเสร็จมีลูกบอลกระจายอยู่ N ลูก ลูกที่ i อยู่ที่ (x, y) โค้ชอยากรู้ว่ามีลูกบอลอยู่ในสนามกี่ลูก อยู่บนเส้นขอบสนามพอดีกี่ลูก และอยู่นอกสนามกี่ลูก ลูกบอลถือเป็นจุดหนึ่งจุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม X1 Y1 X2 Y2 คั่นด้วยช่องว่าง โดยที่ X1 < X2 และ Y1 < Y2

บรรทัดที่สองมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

อีก N บรรทัด แต่ละบรรทัดมีจำนวนเต็ม x และ y ของลูกบอลหนึ่งลูก

พิกัดทุกตัวอยู่ระหว่าง -10000 ถึง 10000

ข้อมูลออก

บรรทัดเดียว มีจำนวนลูกที่อยู่ในสนาม จำนวนลูกที่อยู่บนเส้นขอบ และจำนวนลูกที่อยู่นอกสนาม คั่นด้วยช่องว่าง
