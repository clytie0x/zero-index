ลานจอดรถติดกล้องวงจรปิด N ตัว กล้องแต่ละตัวมองเห็นพื้นที่เป็นสี่เหลี่ยมผืนผ้าที่ด้านขนานกับแกน x และแกน y ช่างที่ติดตั้งจดพื้นที่ของกล้องแต่ละตัวไว้เป็นพิกัดของมุมสองมุมที่อยู่ตรงข้ามกัน แต่ไม่ได้จดว่ามุมไหนเป็นมุมไหน อาจเป็นมุมซ้ายล่างกับมุมขวาบน หรือมุมซ้ายบนกับมุมขวาล่าง และจดมุมไหนก่อนก็ได้

ฝ่ายรักษาความปลอดภัยอยากรู้ว่า พื้นที่ส่วนที่ กล้องทุกตัว มองเห็นพร้อมกันมีขนาดกี่ตารางหน่วย ถ้าไม่มีพื้นที่แบบนั้น หรือส่วนที่ทุกตัวเห็นเป็นแค่เส้นหรือจุด ให้ตอบ 0

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 100000

อีก N บรรทัด แต่ละบรรทัดมีจำนวนเต็ม x1 y1 x2 y2 คั่นด้วยช่องว่าง หมายถึงกล้องตัวหนึ่งเห็นสี่เหลี่ยมที่มีมุมตรงข้ามกันอยู่ที่ (x1, y1) และ (x2, y2) รับประกันว่า x1 ≠ x2 และ y1 ≠ y2 พิกัดทุกตัวอยู่ระหว่าง -109 ถึง 109

ข้อมูลออก

พื้นที่ส่วนที่กล้องทุกตัวมองเห็น
