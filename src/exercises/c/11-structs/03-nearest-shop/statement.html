บ้านของน้องอยู่ที่พิกัด (X, Y) รอบบ้านมีร้านสะดวกซื้อ N ร้าน แต่ละร้านมีชื่อและพิกัดของตัวเอง น้องอยากรู้ว่าร้านไหนอยู่ใกล้บ้านที่สุด เมื่อวัดระยะเป็นเส้นตรง ถ้ามีหลายร้านใกล้เท่ากัน ให้ตอบร้านที่อยู่ก่อนในข้อมูลเข้า

เพื่อไม่ต้องพิมพ์ทศนิยม ให้ตอบ กำลังสองของระยะทาง แทนระยะทาง ระหว่างจุด (x1, y1) กับ (x2, y2) คือ (x1 - x2)2 + (y1 - y2)2

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม X Y คั่นด้วยช่องว่าง

บรรทัดที่สองมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

อีก N บรรทัด แต่ละบรรทัดมีชื่อร้าน และพิกัด x y ของร้าน คั่นด้วยช่องว่าง ชื่อร้านเป็นตัวอักษรภาษาอังกฤษหรือตัวเลขยาว 1 ถึง 20 ตัว ไม่มีช่องว่าง

พิกัดทุกตัวอยู่ระหว่าง -109 ถึง 109 ร้านอาจอยู่ที่เดียวกับบ้าน หรือที่เดียวกับร้านอื่นก็ได้

ข้อมูลออก

บรรทัดเดียว มีชื่อร้านที่ใกล้ที่สุด และกำลังสองของระยะทางจากบ้านถึงร้านนั้น คั่นด้วยช่องว่าง
