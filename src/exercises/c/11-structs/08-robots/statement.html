โกดังขนาดใหญ่ใช้หุ่นยนต์ N ตัวขนของบนพื้นที่แบ่งเป็นช่องตาราง ช่องแต่ละช่องมีพิกัดเป็นจำนวนเต็ม (x, y) หุ่นยนต์แต่ละตัวมีตำแหน่งเริ่มต้น และหันหน้าไปทางทิศใดทิศหนึ่งในสี่ทิศ คือ N เหนือ E ตะวันออก S ใต้ และ W ตะวันตก เดินไปทางเหนือหนึ่งช่อง y เพิ่มหนึ่ง เดินไปทางตะวันออกหนึ่งช่อง x เพิ่มหนึ่ง ทิศใต้และตะวันตกลดลงในทำนองเดียวกัน

ศูนย์ควบคุมส่งคำสั่ง Q คำสั่งตามลำดับ แต่ละคำสั่งสั่งหุ่นยนต์ทีละตัว มีสามแบบ

  • i F K หุ่นยนต์ตัวที่ i เดินตรงไปข้างหน้าตามทิศที่หันอยู่ K ช่อง
  • i L หุ่นยนต์ตัวที่ i หมุนตัวไปทางซ้าย 90 องศา อยู่ที่ช่องเดิม
  • i R หุ่นยนต์ตัวที่ i หมุนตัวไปทางขวา 90 องศา อยู่ที่ช่องเดิม

หุ่นยนต์เดินผ่านกันและอยู่ช่องเดียวกันได้ หลังทำครบทุกคำสั่ง ให้รายงานตำแหน่งและทิศของหุ่นยนต์ทุกตัว และนับว่ามีหุ่นยนต์กี่คู่ที่หยุดอยู่ในช่องเดียวกัน ถ้ามีสามตัวอยู่ช่องเดียวกัน นับเป็น 3 คู่

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q โดยที่ 1 ≤ N ≤ 1000 และ 0 ≤ Q ≤ 100000

อีก N บรรทัด บรรทัดที่ i มีจำนวนเต็ม x y และตัวอักษร d คั่นด้วยช่องว่าง เป็นตำแหน่งและทิศเริ่มต้นของหุ่นยนต์ตัวที่ i โดยที่ -109 ≤ x, y ≤ 109 และ d เป็นหนึ่งใน N E S W

อีก Q บรรทัด แต่ละบรรทัดเป็นคำสั่งหนึ่งคำสั่งตามรูปแบบข้างบน โดยที่ 1 ≤ i ≤ N และ 1 ≤ K ≤ 109

ข้อมูลออก

N บรรทัดแรก บรรทัดที่ i มีพิกัด x y และทิศสุดท้ายของหุ่นยนต์ตัวที่ i คั่นด้วยช่องว่าง บรรทัดสุดท้ายพิมพ์จำนวนคู่ของหุ่นยนต์ที่อยู่ในช่องเดียวกัน
