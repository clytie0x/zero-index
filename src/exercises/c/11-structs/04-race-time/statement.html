งานวิ่งการกุศลปล่อยตัวนักวิ่งเป็นกลุ่ม กลุ่มละเวลาไม่เท่ากัน เพื่อไม่ให้แออัดที่จุดเริ่ม ชิปที่ข้อเท้าของนักวิ่งแต่ละคนบันทึกเวลาออกตัวและเวลาเข้าเส้นชัยเป็นชั่วโมง นาที วินาที ผู้ชนะคือคนที่ ใช้เวลาวิ่งน้อยที่สุด ไม่ใช่คนที่เข้าเส้นก่อน ถ้ามีหลายคนใช้เวลาเท่ากัน ให้คนที่เข้าเส้นชัยก่อนชนะ ถ้ายังเท่ากันอีก ให้คนที่อยู่ก่อนในข้อมูลเข้าชนะ

ให้หาว่าใครชนะ และใช้เวลาวิ่งเท่าไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

อีก N บรรทัด แต่ละบรรทัดมีชื่อนักวิ่ง ตามด้วยจำนวนเต็มหกตัว คือชั่วโมง นาที วินาที ของเวลาออกตัว แล้วตามด้วยชั่วโมง นาที วินาที ของเวลาเข้าเส้นชัย ทุกอย่างคั่นด้วยช่องว่าง ชื่อเป็นตัวอักษรภาษาอังกฤษยาว 1 ถึง 20 ตัว ชั่วโมงอยู่ระหว่าง 0 ถึง 23 นาทีและวินาทีอยู่ระหว่าง 0 ถึง 59 ทุกคนวิ่งจบในวันเดียวกัน และเวลาเข้าเส้นชัยมาหลังเวลาออกตัวเสมอ

ข้อมูลออก

บรรทัดเดียว มีชื่อผู้ชนะ ตามด้วยเวลาที่ใช้เป็นชั่วโมง นาที และวินาที คั่นด้วยช่องว่าง นาทีและวินาทีต้องอยู่ระหว่าง 0 ถึง 59
