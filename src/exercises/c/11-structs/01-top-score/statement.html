ห้องเรียนมีนักเรียน N คน แต่ละคนมีชื่อและคะแนนสอบปลายภาค ครูจะมอบรางวัลให้คนที่ได้คะแนนสูงสุด ถ้ามีหลายคนได้คะแนนสูงสุดเท่ากัน รางวัลเป็นของคนที่ส่งข้อสอบก่อน ซึ่งก็คือคนที่อยู่ก่อนในข้อมูลเข้า ส่วนคนอื่นที่ได้คะแนนเท่ากันจะได้เกียรติบัตร ให้หาว่าใครได้รางวัล และมีนักเรียนกี่คนที่ได้คะแนนสูงสุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

อีก N บรรทัด แต่ละบรรทัดมีชื่อของนักเรียนหนึ่งคน และคะแนน S คั่นด้วยช่องว่าง ชื่อเป็นตัวอักษรภาษาอังกฤษยาว 1 ถึง 20 ตัว ไม่มีช่องว่าง และ 0 ≤ S ≤ 100 ชื่ออาจซ้ำกันได้

ข้อมูลออก

บรรทัดแรกพิมพ์ชื่อและคะแนนของคนที่ได้รางวัล คั่นด้วยช่องว่าง บรรทัดที่สองพิมพ์จำนวนนักเรียนที่ได้คะแนนสูงสุด รวมคนที่ได้รางวัลด้วย
