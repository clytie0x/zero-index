งานวัดแจกตั๋วจับรางวัล N ใบ ตั๋วแต่ละใบมีเลขเป็นจำนวนเต็ม กติกาคือเอาเลขโดดทุกหลักของเลขบนตั๋วมาบวกกัน ใบที่ได้ผลบวกมากที่สุดเป็นผู้ชนะ เช่น ตั๋วเลข 4096 ได้ 4 + 0 + 9 + 6 = 19 ถ้ามีหลายใบที่ได้ผลบวกมากที่สุดเท่ากัน ใบที่มีเลขน้อยที่สุดเป็นผู้ชนะ ตั๋วหลายใบอาจมีเลขซ้ำกันได้

ให้หาเลขบนตั๋วที่ชนะ และผลบวกเลขโดดของตั๋วใบนั้น

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 100000

บรรทัดที่สองมีเลขบนตั๋ว N ใบ คั่นด้วยช่องว่าง แต่ละเลขเป็นจำนวนเต็มตั้งแต่ 0 ถึง 1000000000

ข้อมูลออก

บรรทัดเดียว มีเลขบนตั๋วที่ชนะ และผลบวกเลขโดดของตั๋วใบนั้น คั่นด้วยช่องว่าง
