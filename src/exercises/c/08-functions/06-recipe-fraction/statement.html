สูตรขนมของคุณยายเขียนปริมาณวัตถุดิบเป็นเศษส่วนของถ้วยตวงทั้งหมด เช่น แป้ง 3/4 ถ้วย น้ำตาล 1/3 ถ้วย กะทิ 5/6 ถ้วย หลานอยากรู้ว่าวัตถุดิบทั้ง N อย่างรวมกันเป็นกี่ถ้วย โดยตอบเป็นเศษส่วนอย่างต่ำ

เศษส่วนอย่างต่ำ p/q คือเศษส่วนที่ p กับ q ไม่มีตัวหารร่วมอื่นนอกจาก 1 เช่น 6/4 ต้องตอบเป็น 3/2 ถ้าผลรวมเป็นจำนวนเต็มพอดี ให้ตอบเป็นจำนวนเต็มเฉยๆ เช่น 2/1 ให้ตอบ 2

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 20

อีก N บรรทัดต่อมา บรรทัดละหนึ่งเศษส่วนในรูป a/b ไม่มีช่องว่าง โดยที่ 1 ≤ a ≤ 1000 และ 1 ≤ b ≤ 20 เศษส่วนในข้อมูลเข้าอาจยังไม่เป็นอย่างต่ำ และอาจมากกว่าหนึ่งถ้วยก็ได้

ข้อมูลออก

ผลรวมเป็นเศษส่วนอย่างต่ำในรูป p/q หรือพิมพ์ p อย่างเดียวถ้า q เป็น 1
