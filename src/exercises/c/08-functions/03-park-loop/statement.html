ทุกเย็นน้องวิ่งรอบสวนสาธารณะ โดยวิ่งผ่านจุดพัก N จุดตามลำดับ เริ่มจากจุดที่ 1 ไปจุดที่ 2 จุดที่ 3 จนถึงจุดที่ N แล้ววิ่งกลับมาที่จุดที่ 1 อีกครั้งเพื่อจบรอบ ระหว่างสองจุดวิ่งเป็นเส้นตรงเสมอ จุดแต่ละจุดบอกเป็นพิกัด (x, y) หน่วยเป็นเมตร ระยะระหว่างจุด (x1, y1) กับ (x2, y2) คือรากที่สองของ (x2 - x1)2 + (y2 - y1)2

ให้หาระยะทางรวมของหนึ่งรอบ และระยะของช่วงที่ยาวที่สุดในรอบนั้น ช่วงหนึ่งคือการวิ่งจากจุดหนึ่งไปจุดถัดไป รวมถึงช่วงสุดท้ายที่วิ่งจากจุดที่ N กลับมาจุดที่ 1 ถ้ามีจุดเดียว น้องยืนอยู่กับที่ ระยะทั้งสองเป็น 0

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

อีก N บรรทัดต่อมา บรรทัดที่ i มีจำนวนเต็ม x และ y ของจุดที่ i คั่นด้วยช่องว่าง โดยที่ -10000 ≤ x, y ≤ 10000 จุดหลายจุดอาจอยู่ที่เดียวกันได้

ข้อมูลออก

บรรทัดแรกพิมพ์ระยะทางรวมของหนึ่งรอบ บรรทัดที่สองพิมพ์ระยะของช่วงที่ยาวที่สุด ทั้งสองค่าเป็นทศนิยม 2 ตำแหน่ง
