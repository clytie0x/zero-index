ร้านป้ายหน้าโรงเรียนรับทำป้ายชื่อติดโต๊ะ ป้ายทุกแผ่นมีกรอบเป็นเครื่องหมาย # ล้อมรอบชื่อ และเว้นที่ว่างระหว่างกรอบกับชื่อ P ช่องทุกด้าน ทั้งซ้าย ขวา บน และล่าง ให้เขียนโปรแกรมพิมพ์ป้ายของชื่อ S

ถ้าชื่อยาว L ตัวอักษร ป้ายจะกว้าง L + 2P + 2 ตัวอักษร และสูง 2P + 3 บรรทัด ดังนี้

  • บรรทัดแรกและบรรทัดสุดท้ายเป็น # เต็มความกว้าง
  • P บรรทัดถัดจากบรรทัดแรก และ P บรรทัดก่อนบรรทัดสุดท้าย ขึ้นต้นและลงท้ายด้วย # ตรงกลางเป็นช่องว่างทั้งหมด
  • บรรทัดกลางขึ้นต้นด้วย # ตามด้วยช่องว่าง P ช่อง ชื่อ S ช่องว่าง P ช่อง และ #

ข้อมูลเข้า

บรรทัดเดียว มีชื่อ S และจำนวนเต็ม P คั่นด้วยช่องว่าง S ประกอบด้วยตัวอักษรภาษาอังกฤษหรือตัวเลขเท่านั้น ยาว 1 ถึง 50 ตัว และ 0 ≤ P ≤ 5

ข้อมูลออก

ป้ายชื่อ 2P + 3 บรรทัด ตามรูปแบบข้างบน
