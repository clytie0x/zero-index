ข้อสอบย่อยวิชาวิทยาศาสตร์มีคะแนนเต็ม T คะแนน น้องได้ S คะแนน ระบบรายงานผลต้องแสดงคะแนนคู่กับเปอร์เซ็นต์ เช่น ได้ 45 จาก 60 แสดงเป็น 45/60 = 75.00% ให้เขียนโปรแกรมพิมพ์บรรทัดนี้

ข้อมูลเข้า

บรรทัดเดียว มีจำนวนเต็ม S และ T คั่นด้วยช่องว่าง โดยที่ 1 ≤ T ≤ 1000 และ 0 ≤ S ≤ T

ข้อมูลออก

บรรทัดเดียว ประกอบด้วย S เครื่องหมาย / T ช่องว่าง เครื่องหมาย = ช่องว่าง แล้วตามด้วยเปอร์เซ็นต์ที่เป็นทศนิยม 2 ตำแหน่งและเครื่องหมาย % ชุดทดสอบเลือกไว้ไม่ให้เปอร์เซ็นต์ตกตรงครึ่งของการปัดเศษ
