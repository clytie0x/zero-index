ทีมจักรยานของโรงเรียนจดเวลาออกตัวกับเวลาถึงเส้นชัยเป็นนาฬิกาแบบ 24 ชั่วโมง และวัดระยะทางเป็นกิโลเมตร ให้หาว่าใช้เวลากี่ชั่วโมงกี่นาที และความเร็วเฉลี่ยกี่กิโลเมตรต่อชั่วโมง ความเร็วเฉลี่ยคือระยะทางหารด้วยเวลาที่ใช้เป็นชั่วโมง

ข้อมูลเข้า

  • บรรทัดแรกเป็นเวลาออกตัว ในรูปแบบ HH:MM
  • บรรทัดที่สองเป็นเวลาถึงเส้นชัย ในรูปแบบ HH:MM
  • บรรทัดที่สามเป็นระยะทาง D กิโลเมตร เป็นจำนวนจริงที่มีทศนิยมไม่เกิน 1 ตำแหน่ง (0.1 ≤ D ≤ 1000.0)

ชั่วโมงและนาทีเป็นเลขสองหลักเสมอ (00 ≤ HH ≤ 23, 00 ≤ MM ≤ 59) ทั้งสองเวลาอยู่ในวันเดียวกัน และเวลาถึงเส้นชัยช้ากว่าเวลาออกตัวอย่างน้อย 1 นาที

ข้อมูลออก

  • บรรทัดแรกเป็นเวลาที่ใช้ในรูปแบบ H:MM คือจำนวนชั่วโมงแบบไม่เติม 0 ข้างหน้า เครื่องหมาย : และจำนวนนาทีเป็นเลขสองหลักเสมอ
  • บรรทัดที่สองเป็นความเร็วเฉลี่ย ทศนิยม 2 ตำแหน่ง ชุดทดสอบเลือกไว้ไม่ให้ความเร็วตกตรงครึ่งของการปัดเศษ
