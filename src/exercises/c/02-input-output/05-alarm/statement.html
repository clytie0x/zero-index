นาฬิกาข้อมือของน้องแสดงเวลาแบบ 24 ชั่วโมง น้องอยากตั้งปลุกในอีก K นาทีข้างหน้า ให้หาว่านาฬิกาจะปลุกตอนกี่โมง ถ้าเลยเที่ยงคืนไปแล้วก็ให้นับต่อในวันถัดไป จะเลยไปกี่วันก็ได้ ตอบแค่เวลาบนหน้าปัด

ข้อมูลเข้า

  • บรรทัดแรกเป็นเวลาปัจจุบันในรูปแบบ HH:MM ชั่วโมงและนาทีเป็นเลขสองหลักเสมอ (00 ≤ HH ≤ 23, 00 ≤ MM ≤ 59)
  • บรรทัดที่สองเป็นจำนวนเต็ม K (0 ≤ K ≤ 1000000)

ข้อมูลออก

เวลาที่นาฬิกาปลุก ในรูปแบบ HH:MM ชั่วโมงและนาทีเป็นเลขสองหลักเสมอ
