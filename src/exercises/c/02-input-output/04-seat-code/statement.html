สนามสอบติดรหัสที่นั่งไว้บนโต๊ะ รหัสประกอบด้วยเลขห้อง ขีด ตัวอักษรของแถว และเลขที่นั่งสองหลัก เช่น ห้อง 402 แถว B ที่นั่ง 7 ได้รหัส 402-B07 ให้สร้างรหัสที่นั่งจากข้อมูลที่ได้

ข้อมูลเข้า

สามบรรทัด

  • บรรทัดแรกเป็นเลขห้อง R (100 ≤ R ≤ 999)
  • บรรทัดที่สองเป็นตัวอักษรภาษาอังกฤษพิมพ์ใหญ่หนึ่งตัว บอกแถว
  • บรรทัดที่สามเป็นเลขที่นั่ง S (1 ≤ S ≤ 99)

ข้อมูลออก

รหัสที่นั่งหนึ่งบรรทัด เลขที่นั่งเป็นเลขสองหลักเสมอ
