น้องอนุบาลกำลังท่องสูตรคูณ ครูอยากได้แผ่นท่องของแม่ N ตั้งแต่ N คูณ 1 ไปจนถึง N คูณ M ให้พิมพ์สูตรคูณแม่ N ทีละบรรทัด

ข้อมูลเข้า

บรรทัดเดียว มีจำนวนเต็ม N และ M คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 1000 และ 1 ≤ M ≤ 1000

ข้อมูลออก

M บรรทัด บรรทัดที่ i อยู่ในรูป N x i = ผลคูณ โดยมีช่องว่างหนึ่งช่องคั่นระหว่างทุกส่วนตามตัวอย่าง
