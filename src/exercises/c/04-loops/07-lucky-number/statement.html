หมอดูคนหนึ่งหาเลขนำโชคจากเลขทะเบียนรถ N ด้วยการบวกทุกหลักของ N เข้าด้วยกัน ถ้าผลยังมีตั้งแต่สองหลักขึ้นไปก็บวกทุกหลักของผลนั้นต่ออีก ทำไปเรื่อยๆ จนเหลือเลขหลักเดียว เช่น 9875 บวกทุกหลักได้ 29 บวกต่อได้ 11 บวกต่ออีกได้ 2 ซึ่งเป็นเลขหลักเดียว เลขนำโชคคือ 2

ให้พิมพ์ทุกเลขที่ได้ระหว่างทาง ตั้งแต่ N จนถึงเลขนำโชค

ข้อมูลเข้า

จำนวนเต็ม N หนึ่งตัว (0 ≤ N ≤ 1018)

ข้อมูลออก

บรรทัดเดียว เริ่มด้วย N แล้วตามด้วยเลขที่ได้จากการบวกหลักแต่ละครั้งตามลำดับ คั่นด้วยช่องว่างหนึ่งช่อง ถ้า N เป็นเลขหลักเดียวอยู่แล้ว ให้พิมพ์ N ตัวเดียว
