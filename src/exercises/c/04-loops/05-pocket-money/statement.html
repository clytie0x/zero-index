น้องจดบัญชีค่าขนมเป็นตัวเลขทีละรายการ ตัวเลขที่เป็นบวกคือเงินที่ได้รับ ตัวเลขที่ติดลบคือเงินที่จ่ายออกไป เมื่อจดครบแล้วน้องเขียน 0 ปิดท้ายไว้ ให้หาว่าได้รับเงินรวมเท่าไร จ่ายไปรวมเท่าไร และเหลือเงินสุทธิเท่าไร

ข้อมูลเข้า

จำนวนเต็มเรียงกันอยู่ในหนึ่งบรรทัดหรือหลายบรรทัด คั่นด้วยช่องว่างหรือการขึ้นบรรทัดใหม่ ตัวสุดท้ายคือ 0 ซึ่งบอกว่าจบข้อมูล และไม่ใช่รายการ ตัวเลขก่อนหน้า 0 มีไม่เกิน 1000 ตัว (อาจไม่มีเลยก็ได้) แต่ละตัวไม่ใช่ 0 และอยู่ระหว่าง -1000 ถึง 1000

ข้อมูลออก

สามบรรทัด บรรทัดแรกคือเงินที่ได้รับรวม บรรทัดที่สองคือเงินที่จ่ายรวม พิมพ์เป็นค่าบวก บรรทัดที่สามคือเงินรับรวมลบเงินจ่ายรวม ซึ่งติดลบได้
