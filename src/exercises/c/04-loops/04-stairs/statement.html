ให้วาดบันไดสูง N ขั้นด้วยเครื่องหมาย * โดยชิดขวา แถวที่ 1 มีดาว 1 ดวง แถวที่ 2 มี 2 ดวง ไปจนถึงแถวที่ N มี N ดวง ดาวตัวขวาสุดของทุกแถวต้องอยู่คอลัมน์เดียวกัน ให้ใช้ช่องว่างนำหน้าเพื่อดันดาวไปทางขวา และห้ามมีช่องว่างหลังดาวตัวสุดท้ายของแถว

ข้อมูลเข้า

จำนวนเต็ม N หนึ่งตัว (1 ≤ N ≤ 100)

ข้อมูลออก

N บรรทัด เป็นรูปบันไดตามตัวอย่าง
