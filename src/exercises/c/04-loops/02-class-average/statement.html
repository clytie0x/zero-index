ห้องเรียนหนึ่งมีนักเรียน N คน สอบวิชาคณิตศาสตร์ได้คะแนนเต็ม 100 ครูอยากรู้คะแนนเฉลี่ยของห้อง และจำนวนนักเรียนที่สอบผ่าน ซึ่งคือคนที่ได้ตั้งแต่ 50 คะแนนขึ้นไป

ข้อมูลเข้า

บรรทัดแรกเป็นจำนวนเต็ม N (1 ≤ N ≤ 1000)

บรรทัดที่สองมีจำนวนเต็ม N ตัว คั่นด้วยช่องว่าง เป็นคะแนนของนักเรียนแต่ละคน แต่ละตัวอยู่ระหว่าง 0 ถึง 100
