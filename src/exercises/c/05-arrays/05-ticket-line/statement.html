แถวซื้อตั๋วคอนเสิร์ตมี N คน แต่ละคนถือบัตรคิวคนละเลข แล้วเกิดเหตุสองอย่างตามลำดับ

  1. คนที่ยืนลำดับที่ P ออกจากแถวไป คนข้างหลังเขาขยับขึ้นมาคนละหนึ่งที่
  2. คนถือบัตรเลข X เข้ามาแทรก ให้ตัวเองเป็นคนลำดับที่ Q ของแถว ลำดับนี้นับในแถวที่มีคนออกไปแล้ว ถ้า Q = N แปลว่าเขาไปต่อท้ายแถว

ให้พิมพ์เลขบัตรของทุกคนในแถว เรียงจากหัวแถว หลังเกิดเหตุทั้งสองอย่าง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

บรรทัดที่สองมีเลขบัตร N ตัว เรียงจากหัวแถว คั่นด้วยช่องว่าง แต่ละตัวเป็นจำนวนเต็มตั้งแต่ 1 ถึง 1000000

บรรทัดที่สามมีจำนวนเต็ม P Q และ X คั่นด้วยช่องว่าง โดยที่ 1 ≤ P ≤ N, 1 ≤ Q ≤ N และ 1 ≤ X ≤ 1000000

ข้อมูลออก

บรรทัดเดียว มีเลขบัตร N ตัว เรียงจากหัวแถว คั่นด้วยช่องว่างหนึ่งช่อง
