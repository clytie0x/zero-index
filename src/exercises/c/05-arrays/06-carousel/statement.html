ม้าหมุนในสวนสนุกมีม้า N ตัว วางเป็นวงกลมที่ตำแหน่ง 1 ถึง N ตำแหน่ง N อยู่ติดกับตำแหน่ง 1 ม้าแต่ละตัวมีหมายเลขของตัวเอง ทุกครั้งที่ม้าหมุนขยับ ม้าที่ตำแหน่ง i ย้ายไปตำแหน่ง i + 1 และม้าที่ตำแหน่ง N ย้ายไปตำแหน่ง 1 ให้หาว่าหลังจากขยับไป K ครั้ง ม้าที่ตำแหน่ง 1 ถึง N มีหมายเลขอะไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 0 ≤ K ≤ 1000000000

บรรทัดที่สองมีหมายเลขม้าที่ตำแหน่ง 1 ถึง N ก่อนเริ่มหมุน คั่นด้วยช่องว่าง แต่ละตัวเป็นจำนวนเต็มตั้งแต่ 1 ถึง 1000000

ข้อมูลออก

บรรทัดเดียว มีหมายเลขม้าที่ตำแหน่ง 1 ถึง N หลังขยับครบ K ครั้ง คั่นด้วยช่องว่างหนึ่งช่อง
