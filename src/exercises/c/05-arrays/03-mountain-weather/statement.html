สถานีตรวจอากาศบนยอดเขาบันทึกอุณหภูมิตอนตีห้าไว้ N วัน เรียกว่าวันที่ 1 ถึงวันที่ N ให้หาวันที่อุ่นที่สุดและวันที่หนาวที่สุด ถ้าอุณหภูมิสูงสุดเกิดหลายวัน ให้ตอบวันแรกสุด แต่ถ้าอุณหภูมิต่ำสุดเกิดหลายวัน ให้ตอบวันหลังสุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

บรรทัดที่สองมีอุณหภูมิของวันที่ 1 ถึงวันที่ N คั่นด้วยช่องว่าง แต่ละค่าเป็นจำนวนเต็มตั้งแต่ -50 ถึง 50

ข้อมูลออก

บรรทัดแรกพิมพ์อุณหภูมิสูงสุด ตามด้วยวันแรกสุดที่ได้อุณหภูมินั้น

บรรทัดที่สองพิมพ์อุณหภูมิต่ำสุด ตามด้วยวันหลังสุดที่ได้อุณหภูมินั้น
