ถนนสายหนึ่งเป็นเส้นตรง มีป้ายรถเมล์ N ป้าย หมายเลข 1 ถึง N เรียงจากต้นถนนไปท้ายถนน ระยะทางจากป้ายที่ i ไปป้ายที่ i + 1 คือ Di เมตร มีผู้โดยสารถามคำถาม Q ข้อ แต่ละข้อถามว่าป้าย A กับป้าย B ห่างกันกี่เมตร หมายเลข A อาจมากกว่า B ก็ได้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 2 ≤ N ≤ 100000 และ 1 ≤ Q ≤ 100000

บรรทัดที่สองมีจำนวนเต็ม N - 1 ตัว คือ D1 ถึง DN-1 คั่นด้วยช่องว่าง โดยที่ 1 ≤ Di ≤ 100000

อีก Q บรรทัด แต่ละบรรทัดมีจำนวนเต็ม A และ B คั่นด้วยช่องว่าง โดยที่ 1 ≤ A, B ≤ N

ข้อมูลออก

Q บรรทัด ตอบคำถามตามลำดับ บรรทัดละหนึ่งข้อ เป็นระยะทางระหว่างป้าย A กับป้าย B หน่วยเมตร
