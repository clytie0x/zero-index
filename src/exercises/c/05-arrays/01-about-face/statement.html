หน้าเสาธงมีนักเรียนเข้าแถวตอนเรียงหนึ่ง N คน แต่ละคนมีเลขประจำตัว ครูสั่งกลับหลังหัน คนที่เคยอยู่ท้ายแถวจึงกลายเป็นหัวแถว ให้พิมพ์เลขประจำตัวของนักเรียนเรียงจากหัวแถวใหม่ไปท้ายแถวใหม่

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

บรรทัดที่สองมีเลขประจำตัว N ตัว คั่นด้วยช่องว่าง เรียงจากหัวแถวเดิมไปท้ายแถวเดิม แต่ละตัวเป็นจำนวนเต็มตั้งแต่ 1 ถึง 99999

ข้อมูลออก

บรรทัดเดียว มีเลขประจำตัว N ตัว เรียงจากหัวแถวใหม่ คั่นด้วยช่องว่างหนึ่งช่อง
