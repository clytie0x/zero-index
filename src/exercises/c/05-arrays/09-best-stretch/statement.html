ร้านน้ำปั่นจดกำไรของแต่ละวันไว้ N วัน เรียกว่าวันที่ 1 ถึงวันที่ N วันที่ขาดทุนจดเป็นค่าติดลบ เจ้าของร้านอยากรู้ว่าช่วง K วันติดกันช่วงไหนที่กำไรรวมสูงที่สุด ถ้ามีหลายช่วงที่กำไรรวมเท่ากัน ให้ตอบช่วงที่เริ่มเร็วที่สุด

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ K คั่นด้วยช่องว่าง โดยที่ 1 ≤ K ≤ N ≤ 200000

บรรทัดที่สองมีกำไรของวันที่ 1 ถึงวันที่ N คั่นด้วยช่องว่าง แต่ละค่าเป็นจำนวนเต็มตั้งแต่ -100000 ถึง 100000

ข้อมูลออก

บรรทัดเดียว มีกำไรรวมที่สูงที่สุด ตามด้วยวันแรกของช่วงนั้น คั่นด้วยช่องว่าง
