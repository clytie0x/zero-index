เกมออนไลน์เกมหนึ่งมีผู้เล่น N คน แต่ละคนมีแต้มสะสมเป็นจำนวนเต็มตั้งแต่ 0 ถึง 1000000 ทีมงานกำลังวางแผนแจกรางวัลตามช่วงแต้ม จึงถามคำถาม Q ข้อ แต่ละข้อถามว่ามีผู้เล่นกี่คนที่มีแต้มตั้งแต่ A ถึง B รวมทั้ง A และ B ด้วย

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 1 ≤ Q ≤ 100000

บรรทัดที่สองมีแต้มของผู้เล่น N คน คั่นด้วยช่องว่าง

อีก Q บรรทัด แต่ละบรรทัดมีจำนวนเต็ม A และ B คั่นด้วยช่องว่าง โดยที่ 0 ≤ A ≤ B ≤ 1000000

ข้อมูลออก

Q บรรทัด ตอบคำถามตามลำดับ บรรทัดละหนึ่งข้อ เป็นจำนวนผู้เล่นที่มีแต้มตั้งแต่ A ถึง B
