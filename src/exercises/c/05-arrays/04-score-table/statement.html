โรงเรียนจัดสอบวัดระดับ คะแนนเต็ม 100 มีนักเรียนเข้าสอบ N คน ฝ่ายวิชาการอยากได้ตารางว่าแต่ละคะแนนมีนักเรียนได้กี่คน เรียงจากคะแนนสูงไปคะแนนต่ำ ใส่เฉพาะคะแนนที่มีคนได้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 100000

บรรทัดที่สองมีคะแนนของนักเรียน N คน คั่นด้วยช่องว่าง แต่ละคะแนนเป็นจำนวนเต็มตั้งแต่ 0 ถึง 100

ข้อมูลออก

บรรทัดละหนึ่งคะแนน แต่ละบรรทัดมีคะแนน ตามด้วยจำนวนนักเรียนที่ได้คะแนนนั้น คั่นด้วยช่องว่าง เรียงจากคะแนนมากไปน้อย พิมพ์เฉพาะคะแนนที่มีนักเรียนได้อย่างน้อยหนึ่งคน
