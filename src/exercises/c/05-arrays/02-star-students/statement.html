ครูประกาศว่า ใครได้คะแนนสอบไม่ต่ำกว่าค่าเฉลี่ยของห้อง จะได้ดาวคนละหนึ่งดวง ห้องนี้มีนักเรียน N คน ให้หาว่ามีกี่คนที่ได้ดาว ค่าเฉลี่ยคือผลรวมคะแนนของทุกคนหารด้วย N โดยไม่ปัดเศษ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 1000

บรรทัดที่สองมีคะแนนของนักเรียน N คน คั่นด้วยช่องว่าง แต่ละคะแนนเป็นจำนวนเต็มตั้งแต่ 0 ถึง 100

ข้อมูลออก

จำนวนนักเรียนที่ได้คะแนนมากกว่าหรือเท่ากับค่าเฉลี่ย
