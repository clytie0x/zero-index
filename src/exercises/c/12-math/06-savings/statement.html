ธนาคารโรงเรียนจัดโครงการออมเงิน นักเรียนแต่ละคนเลือกแผนของตัวเอง วันแรกหยอดกระปุก A บาท แล้วทุกวันถัดไปหยอดมากกว่าวันก่อนหน้า D บาท หยอดติดต่อกัน N วัน คุณครูมีแผนของนักเรียน Q คน อยากรู้ว่าเมื่อครบกำหนด กระปุกของแต่ละคนจะมีเงินกี่บาท

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 100000

อีก Q บรรทัด แต่ละบรรทัดมีจำนวนเต็ม A D N คั่นด้วยช่องว่าง โดยที่ 1 ≤ A ≤ 109 และ 0 ≤ D ≤ 1000 และ 1 ≤ N ≤ 108

ข้อมูลออก

Q บรรทัด บรรทัดที่ i เป็นจำนวนเงินในกระปุกของนักเรียนคนที่ i
