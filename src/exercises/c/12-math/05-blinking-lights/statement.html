ป้ายไฟหน้าโรงเรียนมีหลอดไฟ N หลอด ทุกหลอดกะพริบพร้อมกันที่วินาทีที่ 0 หลังจากนั้นหลอดที่ i กะพริบทุก Ti วินาที คือกะพริบที่วินาทีที่ Ti, 2Ti, 3Ti ไปเรื่อยๆ ให้หาว่าหลังวินาทีที่ 0 ทุกหลอดจะกะพริบพร้อมกันอีกครั้งเป็นครั้งแรกที่วินาทีที่เท่าไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 100

บรรทัดที่สองมีจำนวนเต็ม T1 ถึง TN คั่นด้วยช่องว่าง โดยที่ 1 ≤ Ti ≤ 109

ข้อมูลออก
