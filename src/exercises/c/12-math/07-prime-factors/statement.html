ครูคณิตศาสตร์ออกข้อสอบให้เขียนจำนวนเต็มเป็นผลคูณของจำนวนเฉพาะ และต้องการเฉลยของตัวเลข Q ตัว ให้เขียนแต่ละตัวในรูป

N = p1^e1 * p2^e2 * ... * pk^ek

โดยที่ p1 < p2 < ... < pk เป็นจำนวนเฉพาะ และ e1 ถึง ek เป็นเลขชี้กำลังที่มากกว่า 0 ตัวประกอบที่มีเลขชี้กำลังเป็น 1 ไม่ต้องเขียน ^1 เช่น 360 เขียนเป็น 360 = 2^3 * 3^2 * 5 และ 97 ซึ่งเป็นจำนวนเฉพาะเขียนเป็น 97 = 97

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 10

อีก Q บรรทัด บรรทัดละหนึ่งจำนวน คือจำนวนเต็ม N โดยที่ 2 ≤ N ≤ 1012

ข้อมูลออก

Q บรรทัด ตามรูปแบบข้างบน มีช่องว่างหนึ่งช่องทั้งสองข้างของ = และ * ไม่มีช่องว่างรอบ ^
