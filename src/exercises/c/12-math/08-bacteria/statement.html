ห้องแล็บชีววิทยาเลี้ยงแบคทีเรียหลายสายพันธุ์ ทุกการทดลองเริ่มจากแบคทีเรีย 1 ตัว แบคทีเรียสายพันธุ์หนึ่งแบ่งตัวทุกชั่วโมง แต่ละตัวกลายเป็น A ตัว นักวิทยาศาสตร์มีคำถาม Q ข้อ แต่ละข้อถามว่าสายพันธุ์ที่แบ่งเป็น A ตัว เมื่อผ่านไป N ชั่วโมงจะมีแบคทีเรียกี่ตัว ตัวเลขใหญ่มาก จึงให้ตอบเป็นเศษจากการหารด้วย 1000000007

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม Q โดยที่ 1 ≤ Q ≤ 100000

อีก Q บรรทัด แต่ละบรรทัดมีจำนวนเต็ม A และ N คั่นด้วยช่องว่าง โดยที่ 1 ≤ A ≤ 1018 และ 0 ≤ N ≤ 1018

ข้อมูลออก

Q บรรทัด บรรทัดที่ i เป็นจำนวนแบคทีเรียของคำถามที่ i หารด้วย 1000000007 เหลือเศษเท่าไร
