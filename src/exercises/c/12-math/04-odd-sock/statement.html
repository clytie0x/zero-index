หอพักนักกีฬาซักถุงเท้ารวมกันในตะกร้าใบใหญ่ มีถุงเท้า N ข้าง แต่ละข้างมีรหัสสีเป็นจำนวนเต็ม ถุงเท้าสีเดียวกันจับคู่กันได้ หลังจับคู่จนหมด ทุกสีจับคู่ได้ลงตัวพอดี ยกเว้นสีเดียวที่เหลือถุงเท้าค้างอยู่ข้างเดียว ให้หาว่าสีนั้นคือรหัสอะไร

พูดอีกแบบคือ ทุกรหัสสีปรากฏเป็นจำนวนครั้งที่เป็นเลขคู่ ยกเว้นรหัสเดียวที่ปรากฏเป็นจำนวนครั้งที่เป็นเลขคี่

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N เป็นเลขคี่ โดยที่ 1 ≤ N ≤ 999999

บรรทัดที่สองมีรหัสสีของถุงเท้า N ข้าง คั่นด้วยช่องว่าง แต่ละตัวเป็นจำนวนเต็มตั้งแต่ 0 ถึง 1000000000

ข้อมูลออก

รหัสสีที่ปรากฏเป็นจำนวนครั้งที่เป็นเลขคี่
