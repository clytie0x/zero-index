ครูเก็บคะแนนเก็บของนักเรียนไว้ในตาราง R แถว C คอลัมน์ แถวที่ 1 ถึง R คือนักเรียนตามลำดับในสมุด คอลัมน์คือการบ้านแต่ละชิ้น ระหว่างเทอมมีนักเรียนย้ายลำดับในสมุดหลายครั้ง ครูจึงสั่ง Q ครั้ง แต่ละครั้งบอกเลขแถว a กับ b ให้แถวทั้งสองสลับกันทั้งแถว ถ้า a เท่ากับ b ตารางไม่เปลี่ยน ให้พิมพ์ตารางหลังสลับครบทุกครั้ง

ขนาดของตารางรู้ตอนรันเท่านั้น และบางตารางมีแถวน้อยแต่ยาวมาก

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R C และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ R, C และ R × C ≤ 100000 และ 1 ≤ Q ≤ 100000

อีก R บรรทัดต่อมา บรรทัดละ C จำนวน คือคะแนนในแต่ละแถว แต่ละจำนวนอยู่ระหว่าง 0 ถึง 100

อีก Q บรรทัดต่อมา บรรทัดละสองจำนวน a และ b โดยที่ 1 ≤ a, b ≤ R

ข้อมูลออก

R บรรทัด บรรทัดละ C จำนวนคั่นด้วยช่องว่างหนึ่งช่อง คือตารางหลังสลับครบ Q ครั้ง
