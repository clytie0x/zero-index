ปีใหม่นี้โรงเรียนให้ทุกห้องจับฉลากแลกของขวัญ ห้องที่มีนักเรียน n คนใช้เลขที่ 1 ถึง n ทุกคนจับฉลากได้ชื่อเพื่อนในห้องหนึ่งคน แล้วซื้อของขวัญให้คนนั้น ฉลากแต่ละใบมีชื่อไม่ซ้ำกัน ทุกคนจึงได้รับของขวัญจากคนอื่นพอดีหนึ่งชิ้น บางคนอาจจับได้ชื่อตัวเองก็ได้ ฝ่ายกิจกรรมมีรายการว่าใครจับได้ชื่อใคร แต่อยากรู้กลับกันว่าแต่ละคนจะได้รับของขวัญจากใคร

ข้อนี้ให้ฝึกจองอาเรย์ตามขนาดของแต่ละห้องตอนรัน และคืนหน่วยความจำเมื่อใช้เสร็จ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม T คือจำนวนห้อง (1 ≤ T ≤ 20000) แต่ละห้องมีสองบรรทัด บรรทัดแรกมีจำนวนเต็ม n (1 ≤ n ≤ 100000) บรรทัดที่สองมีจำนวนเต็ม n ตัว ตัวที่ i คือเลขที่ของเพื่อนที่นักเรียนเลขที่ i จับได้ ทุกเลขอยู่ระหว่าง 1 ถึง n และไม่ซ้ำกัน ผลรวมของ n ทุกห้องไม่เกิน 100000

ข้อมูลออก

T บรรทัด บรรทัดที่ k เป็นของห้องที่ k มีจำนวนเต็ม n ตัวคั่นด้วยช่องว่าง ตัวที่ j คือเลขที่ของคนที่ให้ของขวัญกับนักเรียนเลขที่ j
