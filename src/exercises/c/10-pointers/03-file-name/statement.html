ชื่อโฟลเดอร์ก็มีจุดได้ เช่น backup.old/notes ไฟล์นี้ชื่อ notes และไม่มีนามสกุล

ข้อนี้ให้ฝึกเขียนฟังก์ชัน char *find_last(char *s, char c) ที่คืน pointer ไปยังตัว c ตัวสุดท้ายในสตริง s หรือคืน NULL ถ้าไม่มี c เลย

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 1000) อีก N บรรทัดต่อมา บรรทัดละหนึ่ง path ยาว 1 ถึง 100 ตัว ประกอบด้วยตัวอักษรภาษาอังกฤษ ตัวเลข _ - . และ / ไม่มีช่องว่าง path ไม่ขึ้นต้นและไม่ลงท้ายด้วย / ไม่มี / สองตัวติดกัน ชื่อไฟล์ไม่ขึ้นต้นและไม่ลงท้ายด้วยจุด

ข้อมูลออก

N บรรทัด บรรทัดที่ i มีชื่อของไฟล์ที่ i ตามด้วยช่องว่าง แล้วตามด้วยนามสกุล ถ้าไฟล์ไม่มีนามสกุล ให้พิมพ์ - แทนนามสกุล
