ห้องสอบมีที่นั่ง N ตัว หมายเลข 1 ถึง N ตอนเริ่มสอบ ที่นั่งแต่ละตัวมีนักเรียนนั่งอยู่หนึ่งคน แต่ละคนมีเลขประจำตัวของตัวเอง ระหว่างสอบ กรรมการคุมสอบสั่งย้ายที่ Q ครั้ง แต่ละครั้งบอกเลขที่นั่ง a กับ b แล้วให้นักเรียนสองคนที่นั่งอยู่ตรงนั้นสลับที่กัน ถ้า a เท่ากับ b ก็ไม่มีใครต้องย้าย ให้หาว่าเมื่อย้ายครบทุกครั้งแล้ว ที่นั่ง 1 ถึง N มีใครนั่งอยู่

ข้อนี้ให้ฝึกเขียนฟังก์ชันสลับค่าที่รับ pointer สองตัว แล้วใช้ฟังก์ชันนั้นทุกครั้งที่สลับ

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 1 ≤ Q ≤ 100000

บรรทัดที่สองมีเลขประจำตัวของนักเรียนที่นั่ง 1 ถึง N ตามลำดับ แต่ละเลขเป็นจำนวนเต็มตั้งแต่ 1 ถึง 1000000000 และไม่ซ้ำกัน

อีก Q บรรทัดต่อมา บรรทัดละสองจำนวน a และ b โดยที่ 1 ≤ a, b ≤ N

ข้อมูลออก

บรรทัดเดียว มีเลขประจำตัวของนักเรียนที่นั่ง 1 ถึง N หลังย้ายครบ Q ครั้ง คั่นด้วยช่องว่างหนึ่งช่อง
