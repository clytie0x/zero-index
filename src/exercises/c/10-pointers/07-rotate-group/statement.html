หน้าเสาธงมีนักเรียนเข้าแถวตอนเรียงหนึ่ง N คน ตำแหน่ง 1 ถึง N แต่ละคนมีเลขประจำตัว ครูพละฝึกการเปลี่ยนแถว Q ครั้ง แต่ละครั้งครูเลือกกลุ่มที่ยืนติดกันตั้งแต่ตำแหน่ง l ถึง r แล้วสั่งว่า "คนหัวกลุ่มเดินไปต่อท้ายกลุ่ม" ซ้ำ k ครั้ง คนนอกกลุ่มอยู่ที่เดิม ให้หาว่าหลังฝึกครบ Q ครั้ง แต่ละตำแหน่งมีใครยืนอยู่

เช่น กลุ่ม 1 2 3 4 5 สั่งซ้ำ 2 ครั้งได้ 3 4 5 1 2

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 1 ≤ Q ≤ 500

บรรทัดที่สองมีเลขประจำตัวของคนที่ตำแหน่ง 1 ถึง N แต่ละเลขเป็นจำนวนเต็มตั้งแต่ 1 ถึง 1000000

อีก Q บรรทัดต่อมา บรรทัดละสามจำนวน l r k โดยที่ 1 ≤ l ≤ r ≤ N และ 0 ≤ k ≤ 1000000000

ข้อมูลออก

บรรทัดเดียว มีเลขประจำตัวของคนที่ตำแหน่ง 1 ถึง N หลังฝึกครบ คั่นด้วยช่องว่างหนึ่งช่อง
