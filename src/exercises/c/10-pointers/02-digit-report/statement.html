ครูคณิตศาสตร์ให้ตัวเลขมา T ตัว ทุกตัวต้องทำรายงานสี่อย่าง คือ มีกี่หลัก เลขโดดทุกหลักรวมกันได้เท่าไร เลขโดดที่น้อยที่สุด และเลขโดดที่มากที่สุด เช่น 2569 มี 4 หลัก รวมกันได้ 22 เลขโดดน้อยสุดคือ 2 มากสุดคือ 9

ข้อนี้ให้ฝึกเขียนฟังก์ชันที่ส่งผลกลับหลายค่า คือ void digit_report(long long x, int *count, int *sum, int *low, int *high) แล้วให้ main เรียกฟังก์ชันนี้หนึ่งครั้งต่อหนึ่งตัวเลข

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม T (1 ≤ T ≤ 1000) อีก T บรรทัดต่อมา บรรทัดละหนึ่งจำนวน X โดยที่ 0 ≤ X ≤ 1000000000000000000 (1018) ตัวเลขไม่มีเลข 0 นำหน้า

ข้อมูลออก

T บรรทัด บรรทัดที่ i มีจำนวนหลัก ผลรวมของเลขโดด เลขโดดที่น้อยที่สุด และเลขโดดที่มากที่สุดของตัวเลขตัวที่ i คั่นด้วยช่องว่าง
