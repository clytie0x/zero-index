ร้านดอกไม้มีริบบิ้น N ม้วน ม้วนที่ i ยาว ai เซนติเมตร เจ้าของร้านอยากตัดริบบิ้นทุกม้วนเป็นชิ้นที่ยาวเท่ากันทุกชิ้น ความยาวของชิ้นเป็นจำนวนเต็มเซนติเมตร และต้องไม่เหลือเศษจากม้วนไหนเลย เพื่อให้ผูกช่อดอกไม้ได้สวย อยากได้ชิ้นที่ยาวที่สุดเท่าที่ทำได้ ให้หาว่าชิ้นยาวเท่าไร และได้ทั้งหมดกี่ชิ้น

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N โดยที่ 1 ≤ N ≤ 100000

บรรทัดที่สองมีจำนวนเต็ม a1 ถึง aN คั่นด้วยช่องว่าง โดยที่ 1 ≤ ai ≤ 109

ข้อมูลออก

บรรทัดแรกพิมพ์ความยาวของชิ้นที่ยาวที่สุด บรรทัดที่สองพิมพ์จำนวนชิ้นทั้งหมดที่ตัดได้
