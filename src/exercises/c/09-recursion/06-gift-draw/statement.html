งานปีใหม่ของห้อง เพื่อน n คนหมายเลข 1 ถึง n ต่างคนต่างเอาของขวัญมาคนละหนึ่งชิ้น แล้วจับฉลากแลกกัน ทุกคนได้ของขวัญคนละหนึ่งชิ้น ของขวัญทุกชิ้นมีคนได้ และไม่มีใครได้ของขวัญที่ตัวเองเอามา ครูอยากเห็นผลจับฉลากทุกแบบที่เป็นไปได้

ผลจับฉลากหนึ่งแบบเขียนเป็นตัวเลข n ตัว g1 g2 ... gn โดย gi คือหมายเลขของเพื่อนที่เอาของขวัญชิ้นที่คนที่ i ได้มา

ข้อมูลเข้า

จำนวนเต็ม n หนึ่งตัว โดยที่ 1 ≤ n ≤ 8

ข้อมูลออก

ผลจับฉลากทุกแบบ บรรทัดละหนึ่งแบบ ในบรรทัดพิมพ์ g1 ถึง gn คั่นด้วยช่องว่างหนึ่งช่อง เรียงแบบพจนานุกรม คือเทียบตัวแรกก่อน ถ้าเท่ากันค่อยเทียบตัวถัดไป แบบที่น้อยกว่าพิมพ์ก่อน ถ้าไม่มีผลจับฉลากที่เป็นไปได้เลย ให้พิมพ์ none
