ห้องสอบมีที่นั่งเรียงเป็นแถวเดียว n ที่ กติกาของห้องสอบคือห้ามมีนักเรียนสองคนนั่งติดกัน จะมีคนนั่งกี่คนก็ได้ รวมถึงไม่มีใครนั่งเลย ครูอยากเห็นทุกแบบที่เป็นไปได้ ให้เขียนแต่ละแบบเป็นสตริงยาว n ตัว ตัวที่ i แทนที่นั่งที่ i โดย 1 คือมีคนนั่ง และ 0 คือว่าง

ข้อมูลเข้า

จำนวนเต็ม n หนึ่งตัว โดยที่ 1 ≤ n ≤ 20

ข้อมูลออก

พิมพ์ทุกแบบที่ไม่มี 1 สองตัวติดกัน บรรทัดละหนึ่งแบบ เรียงแบบพจนานุกรมโดยถือว่า 0 มาก่อน 1 บรรทัดสุดท้ายพิมพ์จำนวนแบบทั้งหมด
