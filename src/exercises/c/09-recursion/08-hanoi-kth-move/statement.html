พิพิธภัณฑ์วิทยาศาสตร์มีหุ่นยนต์ย้ายหอคอยฮานอยโชว์ทั้งวัน หอคอยมีแผ่นกลม n แผ่น หมายเลข 1 ถึง n จากเล็กไปใหญ่ เริ่มต้นทุกแผ่นอยู่ที่หลัก A หุ่นยนต์ย้ายทั้งหมดไปหลัก C ตามขั้นตอนนี้ทุกประการ

ย้าย m แผ่นจากหลัก X ไปหลัก Y โดยมีหลัก Z เป็นที่พัก ทำดังนี้

  1. ถ้า m เป็น 0 ไม่ต้องทำอะไร
  2. ย้าย m - 1 แผ่นจากหลัก X ไปหลัก Z โดยมีหลัก Y เป็นที่พัก
  3. ย้ายแผ่นหมายเลข m จากหลัก X ไปหลัก Y หนึ่งครั้ง
  4. ย้าย m - 1 แผ่นจากหลัก Z ไปหลัก Y โดยมีหลัก X เป็นที่พัก

หุ่นยนต์เริ่มด้วยการย้าย n แผ่นจากหลัก A ไปหลัก C โดยมีหลัก B เป็นที่พัก ซึ่งเป็นขั้นตอนเดียวกับโปรแกรมหอคอยฮานอยในหน้า 9.5 ผู้ชมถามคำถาม Q ข้อ แต่ละข้อถามว่าการย้ายครั้งที่ K หุ่นยนต์ย้ายแผ่นหมายเลขอะไร จากหลักไหนไปหลักไหน

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม n และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ n ≤ 60 และ 1 ≤ Q ≤ 1000

อีก Q บรรทัด แต่ละบรรทัดมีจำนวนเต็ม K หนึ่งตัว โดยที่ 1 ≤ K ≤ 2n - 1

ข้อมูลออก

Q บรรทัด ตอบคำถามตามลำดับ แต่ละบรรทัดมีหมายเลขแผ่น หลักต้นทาง และหลักปลายทางของการย้ายครั้งที่ K คั่นด้วยช่องว่าง หลักเขียนเป็นตัวอักษร A B หรือ C
