ป้ายหน้าห้องคอมพิวเตอร์แสดงตัวเลขด้วยหลอดไฟเรียงเป็นแถว หลอดที่ติดแทน 1 หลอดที่ดับแทน 0 อ่านเป็นเลขฐานสอง เช่น เลข 13 แสดงเป็น 1101 เพราะ 13 = 8 + 4 + 1 ให้แปลงจำนวนเต็ม N เป็นเลขฐานสองที่ป้ายต้องแสดง โดยไม่มีหลอดดับนำหน้า ยกเว้น N เป็น 0 ซึ่งป้ายแสดงหลอดดับหลอดเดียว

ข้อมูลเข้า

จำนวนเต็ม N หนึ่งตัว โดยที่ 0 ≤ N ≤ 1018

ข้อมูลออก

เลขฐานสองของ N ในบรรทัดเดียว ไม่มีเลข 0 นำหน้า ถ้า N เป็น 0 ให้พิมพ์ 0
