หน้าสนามสอบติดรายชื่อผู้มีสิทธิ์สอบ N คน เรียงตามเลขประจำตัวสอบจากน้อยไปมาก เลขประจำตัวไม่ซ้ำกัน มีผู้ปกครอง Q คนมาถามเจ้าหน้าที่ แต่ละคนบอกเลขประจำตัวของลูกหนึ่งเลข เจ้าหน้าที่ต้องตอบว่าเลขนั้นอยู่ลำดับที่เท่าไรในรายชื่อ โดยคนแรกในรายชื่อคือลำดับที่ 1 ถ้าไม่มีเลขนั้นในรายชื่อให้ตอบ 0

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N และ Q คั่นด้วยช่องว่าง โดยที่ 1 ≤ N ≤ 100000 และ 1 ≤ Q ≤ 100000

บรรทัดที่สองมีเลขประจำตัวสอบ N ตัว เรียงจากน้อยไปมาก ไม่ซ้ำกัน แต่ละตัวอยู่ระหว่าง 1 ถึง 109

อีก Q บรรทัด แต่ละบรรทัดมีเลขที่ถูกถามหนึ่งตัว อยู่ระหว่าง 1 ถึง 109

ข้อมูลออก

Q บรรทัด ตอบคำถามตามลำดับ บรรทัดละหนึ่งข้อ เป็นลำดับในรายชื่อ หรือ 0 ถ้าไม่มี
