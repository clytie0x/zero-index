บันไดขึ้นอาคารเรียนมี n ขั้น หมายเลข 1 ถึง n น้องยืนอยู่ที่พื้นซึ่งนับเป็นขั้น 0 ก้าวหนึ่งครั้งขึ้นได้ 1 ขั้น 2 ขั้น หรือ 3 ขั้น บันไดเก่าแล้ว มีบางขั้นชำรุดซึ่งห้ามเหยียบ แต่ก้าวข้ามได้ ให้นับว่ามีกี่วิธีที่จะขึ้นไปหยุดที่ขั้น n พอดี สองวิธีถือว่าต่างกันถ้าลำดับของขั้นที่เหยียบต่างกัน

เช่น บันได 4 ขั้นที่ไม่มีขั้นชำรุดเลย มี 7 วิธี คือก้าว 1+1+1+1, 1+1+2, 1+2+1, 2+1+1, 2+2, 1+3 และ 3+1

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม n และ k คั่นด้วยช่องว่าง คือจำนวนขั้นและจำนวนขั้นที่ชำรุด โดยที่ 1 ≤ n ≤ 70 และ 0 ≤ k ≤ n - 1

ถ้า k มากกว่า 0 บรรทัดที่สองมีหมายเลขขั้นที่ชำรุด k ตัว ไม่ซ้ำกัน คั่นด้วยช่องว่าง แต่ละตัวอยู่ระหว่าง 1 ถึง n - 1 ขั้น n ไม่ชำรุดเสมอ ถ้า k เป็น 0 จะไม่มีบรรทัดนี้

ข้อมูลออก

จำนวนวิธีขึ้นไปถึงขั้น n รับประกันว่าคำตอบไม่เกิน 3 × 1018
