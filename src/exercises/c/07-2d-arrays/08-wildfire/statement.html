เจ้าหน้าที่อุทยานจำลองไฟป่าบนแผนที่ R แถว C คอลัมน์ ช่อง # คือต้นไม้ ช่อง * คือช่องที่กำลังไหม้ ช่อง . คือพื้นโล่งที่ไม่มีอะไรให้ไหม้ ทุกนาทีทุกช่องเปลี่ยนพร้อมกันตามกฎนี้

  • ช่องที่กำลังไหม้ * มอดลงกลายเป็นพื้นโล่ง .
  • ต้นไม้ # ที่มีช่องติดกันทางด้านบน ล่าง ซ้าย หรือขวา กำลังไหม้อยู่ตอนต้นนาที จะติดไฟกลายเป็น *
  • ช่องอื่นเหมือนเดิม

ให้หาว่าเมื่อผ่านไป K นาที แผนที่จะเป็นอย่างไร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R C และ K (1 ≤ R, C ≤ 100 และ 1 ≤ K ≤ 100) อีก R บรรทัดต่อมา บรรทัดละ C ตัวอักษรติดกัน แต่ละตัวเป็น # * หรือ .

ข้อมูลออก

แผนที่หลังผ่านไป K นาที R บรรทัด บรรทัดละ C ตัวอักษรติดกัน
