ครูให้ตารางตัวเลขขนาด N × N มา แล้วให้นักเรียนลากเส้นทแยงสองเส้นเป็นรูปตัว X เส้นแรกจากมุมบนซ้ายไปมุมล่างขวา เส้นที่สองจากมุมบนขวาไปมุมล่างซ้าย ให้หาผลรวมของตัวเลขที่เส้นแรกลากผ่าน ผลรวมของตัวเลขที่เส้นที่สองลากผ่าน และผลรวมของตัวเลขทุกตัวที่ถูกตัว X ทับ ตัวเลขที่ถูกทั้งสองเส้นทับให้นับครั้งเดียว

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม N (1 ≤ N ≤ 100) อีก N บรรทัดต่อมา บรรทัดละ N จำนวน แต่ละจำนวนอยู่ระหว่าง -1000000000 ถึง 1000000000

ข้อมูลออก

สามบรรทัด บรรทัดแรกคือผลรวมบนเส้นจากมุมบนซ้าย บรรทัดที่สองคือผลรวมบนเส้นจากมุมบนขวา บรรทัดที่สามคือผลรวมของตัวเลขทุกตัวที่ถูกตัว X ทับ
