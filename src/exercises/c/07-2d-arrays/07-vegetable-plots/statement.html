สวนผักของโรงเรียนวาดเป็นแผนที่ R แถว C คอลัมน์ ช่อง # ปลูกผัก ช่อง . เป็นทางเดิน ช่อง # ที่ติดกันทางด้านบน ล่าง ซ้าย หรือขวา อยู่ในแปลงเดียวกัน ครูรับรองว่าทุกแปลงเป็นสี่เหลี่ยมผืนผ้าที่ปลูกเต็มทุกช่อง และสองแปลงที่ต่างกันไม่มีด้านติดกันเลย แต่อาจแตะกันที่มุมแบบทแยงได้ ให้นับว่ามีกี่แปลง และแปลงที่ใหญ่ที่สุดมีกี่ช่อง

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C (1 ≤ R, C ≤ 100) อีก R บรรทัดต่อมา บรรทัดละ C ตัวอักษรติดกัน แต่ละตัวเป็น # หรือ .

ข้อมูลออก

บรรทัดเดียว มีจำนวนแปลง และจำนวนช่องของแปลงที่ใหญ่ที่สุด คั่นด้วยช่องว่าง ถ้าไม่มีแปลงเลยให้พิมพ์ 0 0
