เกมกู้ระเบิดมีกระดาน R แถว C คอลัมน์ ช่อง * มีทุ่นระเบิด ช่อง . ปลอดภัย ก่อนเริ่มเกม โปรแกรมต้องเติมตัวเลขลงในทุกช่องที่ปลอดภัย ตัวเลขคือจำนวนทุ่นระเบิดในช่องที่ติดกับช่องนั้นทั้ง 8 ทิศ รวมช่องทแยงด้วย ช่องที่มีทุ่นระเบิดให้คงเป็น * ไว้

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C (1 ≤ R, C ≤ 100) อีก R บรรทัดต่อมา บรรทัดละ C ตัวอักษรติดกัน แต่ละตัวเป็น * หรือ .

ข้อมูลออก

กระดานที่เติมตัวเลขแล้ว R บรรทัด บรรทัดละ C ตัวอักษรติดกัน
