เทศบาลแบ่งแผนที่เมืองเป็นบล็อก R แถว C คอลัมน์ และรู้ว่าแต่ละบล็อกมีคนอาศัยอยู่กี่คน ทีมวางแผนรถรับส่งนักเรียนมีคำถาม Q ข้อ แต่ละข้อถามว่าในพื้นที่สี่เหลี่ยมที่มีบล็อกแถว r1 คอลัมน์ c1 เป็นมุมบนซ้าย และบล็อกแถว r2 คอลัมน์ c2 เป็นมุมล่างขวา มีคนอาศัยอยู่รวมกี่คน แถวและคอลัมน์เริ่มนับจาก 1

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C (1 ≤ R, C ≤ 500) อีก R บรรทัดต่อมา บรรทัดละ C จำนวน คือจำนวนคนในแต่ละบล็อก แต่ละจำนวนอยู่ระหว่าง 0 ถึง 10000 บรรทัดถัดมามีจำนวนเต็ม Q (1 ≤ Q ≤ 50000) อีก Q บรรทัดต่อมา บรรทัดละสี่จำนวน r1 c1 r2 c2 (1 ≤ r1 ≤ r2 ≤ R และ 1 ≤ c1 ≤ c2 ≤ C)

ข้อมูลออก

Q บรรทัด บรรทัดที่ i คือจำนวนคนในพื้นที่ของคำถามที่ i
