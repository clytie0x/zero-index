แผนที่หมู่เกาะเป็นตาราง R แถว C คอลัมน์ ช่อง # คือบก ช่อง . คือน้ำ และทุกที่นอกแผนที่ก็เป็นน้ำ แต่ละช่องเป็นสี่เหลี่ยมจัตุรัสด้านยาว 1 กิโลเมตร ชายฝั่งคือด้านของช่องบกที่ติดกับน้ำ รวมถึงทะเลสาบที่อยู่กลางเกาะด้วย ให้หาความยาวชายฝั่งทั้งหมดเป็นกิโลเมตร

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C (1 ≤ R, C ≤ 100) อีก R บรรทัดต่อมา บรรทัดละ C ตัวอักษรติดกัน แต่ละตัวเป็น # หรือ .

ข้อมูลออก

ความยาวชายฝั่งทั้งหมดเป็นกิโลเมตร
