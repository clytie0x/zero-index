กล้องของชมรมถ่ายภาพบันทึกรูปขาวดำเป็นตารางตัวอักษร R แถว C คอลัมน์ # คือจุดสีดำ . คือจุดสีขาว แต่น้องถือกล้องตะแคงตอนถ่าย รูปจึงออกมานอนอยู่ ให้หมุนรูปไปทางขวา 90 องศา ตามเข็มนาฬิกา มุมบนซ้ายของรูปเดิมจะไปอยู่มุมบนขวาของรูปใหม่

ข้อมูลเข้า

บรรทัดแรกมีจำนวนเต็ม R และ C (1 ≤ R, C ≤ 100) อีก R บรรทัดต่อมา บรรทัดละ C ตัวอักษรติดกัน แต่ละตัวเป็น # หรือ .

ข้อมูลออก

รูปที่หมุนแล้ว C บรรทัด บรรทัดละ R ตัวอักษรติดกัน
