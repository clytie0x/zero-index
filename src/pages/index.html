เขียนโปรแกรมภาษา C ตั้งแต่ศูนย์

เอกสารชุดนี้พาน้องเริ่มจากยังไม่เคยเขียนโปรแกรมเลย ไปจนพร้อมทำโจทย์ระดับ TOI Zero

เรียนตามลำดับนี้

  1. ภาษา C เรียนให้แน่นก่อน ทุกบทใช้ C อย่างเดียว
  2. ภาษา C++ ต่อเมื่อเข้าใจ C ครบแล้ว จะเห็นว่า C++ ต่อยอดจากสิ่งที่รู้อยู่แล้ว

ก่อนเริ่ม

  • ใช้โน้ตบุ๊ก Windows ของตัวเอง
  • ไม่ต้องมีพื้นฐานเขียนโปรแกรมมาก่อน
  • เริ่มที่ บทที่ 0 แล้วไล่ไปทีละหน้า อย่าข้าม

วิธีอ่านให้ได้ผล

พิมพ์โค้ดทุกตัวอย่างเองแล้วรันดู อย่าก๊อปวาง การพิมพ์เองทำให้เจอ error จริง และการแก้ error คือการเรียนที่ได้ผลที่สุด
