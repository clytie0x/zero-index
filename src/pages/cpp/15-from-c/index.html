บทที่ 15 จาก C สู่ C++

จบบทนี้ น้องจะย้ายโปรแกรมภาษา C ที่เขียนมาทั้งหมดไปเป็น C++ ได้ อ่านและพิมพ์ข้อมูลเป็นล้านตัวด้วย cin cout ได้ทันเวลา 1 วินาที จัดทศนิยมได้ตามที่โจทย์สั่ง และจัดการข้อความด้วย string ที่ต่อ เทียบ ตัด และค้นหาได้ในคำสั่งเดียว โจทย์ข้อความที่ใช้อาเรย์ของ char แล้วยาวและพลาดง่ายจะสั้นลงมาก บทนี้เป็นฐานของทุกบทที่เหลือ ตั้งแต่บทที่ 16 ไปทุกโปรแกรมเป็น C++ และใช้ STL

หน้าได้อะไร
15.1 เปลี่ยนจาก .c เป็น .cppทำไมการแข่งขันใช้ C++ สร้างไฟล์ .cpp namespace std bits/stdc++.h ข้อดีข้อเสีย และโค้ด C ที่ C++ ไม่ยอมรับ
15.2 cin และ coutรับและพิมพ์โดยไม่ต้องใช้ %d endl กับ '\n' อ่านจนหมดข้อมูล และทศนิยมด้วย fixed setprecision
15.3 อ่านเขียนให้ทันเวลาวัดเวลาจริงกับข้อมูลล้านตัว สองบรรทัดที่ทำให้เร็วกว่า scanf และทำไมห้ามใช้ปนกัน
15.4 string ของ C++ต่อ เทียบ size substr find getline และกับดัก cin >> ตามด้วย getline
15.5 bool reference และ autobool ส่งตัวแปรให้ฟังก์ชันแก้ด้วย reference ลูปเดินทีละตัว auto และ new delete
