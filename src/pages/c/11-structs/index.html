บทที่ 11 struct

จบบทนี้ น้องจะรวมข้อมูลหลายชนิดที่เป็นของสิ่งเดียวกันไว้เป็นก้อนเดียวได้ เช่น ชื่อ คะแนน และห้องของนักเรียนหนึ่งคน หรือพิกัด x กับ y ของจุดหนึ่งจุด แล้วเก็บก้อนพวกนี้เป็นอาเรย์ คัดลอกทั้งก้อน ส่งเข้าฟังก์ชัน และคืนออกจากฟังก์ชันได้ โจทย์ TOI Zero ช่วงกลางที่ให้ข้อมูลเป็นรายการ เช่น ตารางคะแนนแข่งขัน คลังสินค้า จุดและสี่เหลี่ยมบนระนาบ จะเขียนสั้นลงและผิดยากขึ้นมาก และ struct ยังเป็นฐานของ linked list stack queue ในบทที่ 14 ด้วย

หน้าได้อะไร
11.1 struct คืออะไรทำไมต้องรวมข้อมูลเป็นก้อน ประกาศ struct ใช้ . กำหนดค่าเริ่มต้น คัดลอกทั้งก้อน และ typedef
11.2 อาเรย์ของ structอ่านข้อมูลนักเรียน N คน หาคนคะแนนสูงสุด ค้นหาด้วยชื่อ และสลับข้อมูลทั้งคนในคำสั่งเดียว
11.3 struct ซ้อนกัน ขนาด และ unionจุด เส้นตรง สี่เหลี่ยม พื้นที่ที่สี่เหลี่ยมสองรูปทับกัน sizeof กับ padding และ union แบบสั้นๆ
11.4 struct กับฟังก์ชันและ pointerส่งแบบสำเนาและแบบ pointer ตัวดำเนินการ -> คืน struct จากฟังก์ชัน เปรียบเทียบหลายเกณฑ์ และ struct ที่ชี้หาตัวเอง
