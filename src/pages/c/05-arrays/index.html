บทที่ 5 อาเรย์

จบบทนี้ น้องจะเก็บตัวเลขเป็นร้อยเป็นแสนตัวไว้ในตัวแปรชื่อเดียว แล้ววนกลับมาใช้ซ้ำได้กี่รอบก็ได้ ทำให้ตอบโจทย์ที่ต้องดูข้อมูลทั้งชุดก่อนตัดสินใจได้ เช่น หาว่าใครได้มากสุดและอยู่ลำดับไหน นับว่าแต่ละค่าเกิดกี่ครั้ง ตอบผลรวมของช่วงซ้ำเป็นแสนคำถามให้ทันเวลา และแทรกหรือลบสมาชิกตรงกลางแถว โจทย์แข่งขันส่วนใหญ่ตั้งแต่ระดับนี้ไปมีอาเรย์เป็นส่วนประกอบ บทนี้ยังเป็นที่มาของชื่อเว็บ zero-index ด้วย เพราะช่องแรกของอาเรย์คือช่องที่ 0

หน้าได้อะไร
5.1 อาเรย์และช่องที่ 0ประกาศ กำหนดค่าเริ่มต้น index 0 ถึง N - 1 อ่าน N ตัว พิมพ์ และกลับลำดับ
5.2 ผลรวม มากสุด น้อยสุดผลรวม เทียบกับค่าเฉลี่ย ค่ามากสุดน้อยสุด และตำแหน่งแรกหรือตำแหน่งสุดท้ายของมัน
5.3 นับความถี่ด้วยอาเรย์นับใช้ค่าเป็น index นับคะแนน 0 ถึง 100 หาค่าที่พบบ่อยสุด และเช็กว่าเคยเห็นหรือยัง
5.4 ผลรวมสะสมตอบผลรวมของช่วงด้วยการลบครั้งเดียว และเห็นเวลาที่ต่างกันจริง
5.5 แทรก ลบ และขอบของอาเรย์เลื่อนสมาชิกให้ถูกทิศ อาการจริงของการใช้ช่องที่ไม่มีอยู่ และอาเรย์ใหญ่ที่ต้องอยู่นอก main
