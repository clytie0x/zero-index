บทที่ 2 รับและแสดงผล

จบบทนี้ น้องจะรับข้อมูลเข้าได้ทุกรูปแบบที่โจทย์ TOI Zero ให้มา ทั้งตัวเลขหลายบรรทัด ตัวอักษร ชื่อคน เวลาแบบ 12:30 และวันที่แบบ 21/10/2569 และพิมพ์ผลลัพธ์ได้ตรงตามโจทย์ทุกตัวอักษร ทั้งทศนิยมกี่ตำแหน่ง เลข 0 นำหน้า และตารางที่คอลัมน์ตรงกัน โจทย์ข้อแรกๆ ของการสอบเกือบทุกข้อวัดเรื่องนี้ และคนที่คิดถูกแต่พิมพ์ผิดรูปแบบก็ได้ศูนย์คะแนนเหมือนคนที่คิดผิด

ในบทนี้

หน้าได้อะไร
2.1 แสดงผลด้วย printfตัวกำหนดรูปแบบทุกตัว ทศนิยมกี่ตำแหน่งด้วย %.2f และ escape sequence อย่าง \t \" \\
2.2 จัดความกว้างและตาราง%5d %-5d %05d เวลาแบบ 07:05 และตารางที่คอลัมน์ตรงกัน
2.3 รับข้อมูลด้วย scanfข้อมูลหลายบรรทัด กับดักของ %c รับคำด้วย %s และตัวคั่นอย่าง "%d:%d"
2.4 อ่านโจทย์แบบ graderอ่านโจทย์จริงแล้วเขียนทีละขั้น ทดสอบด้วยการวางข้อมูลเข้า และรู้ว่าผลแบบไหนที่ grader ไม่ให้ผ่าน
