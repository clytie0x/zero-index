บทที่ 3 เงื่อนไข

จบบทนี้ โปรแกรมของน้องจะตัดสินใจเองได้ ให้คำตอบต่างกันตามข้อมูลเข้า เช่น บอกว่าสอบผ่านไหม ตัดเกรด คิดค่าไฟแบบขั้นบันได ตรวจปีอธิกสุรทิน หรือหาค่ามากสุดของสามตัว โจทย์ TOI Zero ช่วงแรกจำนวนมากเป็นแบบนี้ คือโจทย์ที่ไม่ต้องวนซ้ำ แต่ต้องแยกกรณีให้ครบทุกกรณี และถูกทุกค่าตรงขอบ บทนี้จึงเน้นวิธีทดสอบให้ครบทุกกิ่ง และกับดักที่ทำให้คอมไพล์ผ่านแต่ได้คำตอบผิด

ในบทนี้

หน้าได้อะไร
3.1 การเปรียบเทียบและ ifตัวดำเนินการเปรียบเทียบ จริงเป็น 1 เท็จเป็น 0 if else และกับดัก = กับ ==
3.2 else if และ if ซ้อนเลือกหนึ่งจากหลายทาง ตัดเกรด ค่าบริการขั้นบันได และหาค่ามากสุดของสามตัว
3.3 ตรรกะ และ หรือ ไม่&& || ! เขียนช่วงตัวเลข ลำดับการประเมิน ปีอธิกสุรทิน และเทียบทศนิยม
3.4 switch และ ? :เทียบกับค่าคงที่หลายค่า break ที่ห้ามลืม และเลือกค่าในบรรทัดเดียว
